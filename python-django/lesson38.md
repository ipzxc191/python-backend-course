# Инструкция, как можно переделать стилизацию сайта под свой проект:

## Скачать и установить проект

### Скачать ZIP-архив:

1. Откройте страницу репозитория, перейдя по [ссылки](https://github.com/ipzxc191/filmsite-g52-pre-deplotment)
2. Нажмите **Code → Download ZIP** (`<>Code` - cиняя или зеленая кнопка на странице, нажав на которую открывается меню. `Download ZIP` - обычно последний пункт в этом меню).
3. Распакуйте архив в удобное место.
4. Откройте папку проекта в вашей IDE (прим. Visual Studio Code).

## Запуск проекта

### 1. Создайте виртуальное окружение

Откройте новый терминал в открытой папке проекта и напишите команду:

```bash
python -m venv venv
```

### 2. Активируйте виртуальное окружение

После установки у вас в папке появится папка `venv`. Вам нужно запустить виртуальное окружение из этой папки.

На windows это делается командой:

```bash
venv\Scripts\activate
```

На macOS или Linux:

```bash
source venv/bin/activate
```

### 3. Установите зависимости

Для корректной работы сайта вам понадобятся библиотеки, работу с которыми мы изучали на протяжении курса. Их некоторое количество, но все они собраны в файле `requirements.txt`. 

Нужно их установить:

```bash
pip install -r requirements.txt
```

### 4. Запустите проект, что бы открыть его в браузере

У вас в папке есть файл `.env.example`. Его нужно переименовать в просто `.env`. После этого действия проект уже будет готов к запуску, но в идеале внутри файла `.env` нужно отредактировать строчку:

```env
SECRET_KEY=<your_secret_key>
```

**Где получить новый секретный ключ?**

Для этого возвращаемся в терминал и вводим вот эту команду:

```bash
python manage.py shell -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Она сгенерирует вам новый секретный ключ. Нужно скопировать его из терминала и вставить в поле в файле `.env`.

Получится примерно так:

```env
SECRET_KEY=+abcdef=-ghijk@12345@1q2w3e4r
```

---

Далее, когда файл `.env` готов и все библиотеки установлены, вы можете запускать проект.

Для этого введите в терминал вот эту команду:

```bash
python manage.py runserver
```

У вас в терминале появится служебная информация, среди которой будет ссылка на ваш работающий проект:

```bash
...
Starting development server at http://127.0.0.1:8000/
...
```

Открыть сайт теперь можно на нашем компьютере по ссылке, указанной в этой строке (`http://127.0.0.1:8000/`).

Можете попереходить по страницам, посмотреть, что реализовано в проекте, чтобы убедиться, что все работает. Желательно **залогиниться** на сайте через **Администратора**, потому что вам понадобиться менять информацию на самом сайте.

### 5. Залогиниться от админа

Что бы залогиниться как `Администратор`, нажмите на кнопку `войти` и введите вот эти данные:

**login**:
```
admin
```

**password**:
```

```

## Как и что менять для стилизации проекта.

### **Цветовая палитра вашего сайта**:

Начать можно с цветов самого сайта. Они расположены в файле стилей этого проекта. Он находится по адресу:

`static/css/base.css`

Откройте файл и в самом начале вы увидите переменные, которые отвечают за цвета на всем вашем сайте. Именно эти значения нужно будет менять.

```css
:root {
    /* Тёмные поверхности (шапка, полоса фильтров, футер) */
    --color-header-bg: #242424;
    --color-strip-bg: #333333;
    --color-text-on-dark: #F2F2F2;
    --color-text-on-dark-secondary: #B5B5B5;

    /* Светлое тело страницы */
    --color-page-bg: #F3F3F3;
    --color-surface: #FFFFFF;
    --color-text: #1A1A1A;
    --color-text-secondary: #6E6E6E;
    --color-border: #E2E2E2;

    /* Акценты */
    --color-primary: #E0A800;
    --color-primary-hover: #C99400;
    --color-accent: #E0A800;
    --color-peach: #F3E4C8;
    --color-black: #1A1A1A;

    /* Форма и тени */
    --radius: 6px;
    --radius-sm: 4px;
    --shadow-card: 0 2px 8px rgba(0, 0, 0, 0.08);
    --shadow-card-hover: 0 6px 18px rgba(0, 0, 0, 0.12);
}

...
```

Для того, чтобы увидеть результат, нужно просто обновлять страницу, которую вы открыли в браузере (Сервер должен быть запущен см. пункт 4).

---

### **Далее можно начать стилизовать карточки самих фильмов**:

Сама карточка стилизуется с помощью правила для класса `.film-card`. Оно расположено на 376 строке файла стилизации.

```css
...

.film-card {
    background: var(--color-surface);
    border: 1px solid var(--color-border);
    border-radius: var(--radius);
    overflow: hidden;
    box-shadow: var(--shadow-card);
    text-align: center;
    transition: box-shadow 0.15s, transform 0.15s;
}

...
```

Можете изменять сами переменные, которые описывались выше. 

Например, строка `border-radius: var(--radius);` использует переменную `--radius` из цветовой палитры. Ее можно заменить на конкретное значение, например на `50%` и посмотреть на результат, обновив страницу сайта.

В самом файле `static/css/base.css` подписано комментариями, где начинается стилизация каждого блока вашего сайта. Далее можете пробовать менять что хотите, и устанавливать стили на ваш вкус.

### **Количество элементов в сетке**:

В вашем проекте используется **grid-стилизация**, поэтому количество элементов в ряду меняется очень легко.

В правиле немного выше, для класса `.film-grid`, вы можете увидеть строку `grid-template-columns: repeat(3, 1fr);`. Цифра 3 в функции `repeat` говорит о том, сколько элементов будет в строке. Можете поменять на любое значение.

```css
...

.film-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 26px;
    margin-top: 20px;
}

...
```

### **Количество элементов на странице**:

За количество элементов на странице отвечает не только правило для класса `.film-grid`, но и строчки кода в файле `films/views.py`. 

Строка `paginate_by = 6` говорит о том, сколько фильмов будет на странице в общем. Цифру 6 можно поменять на любую другую, например на 10.

Такие строки вы можете встретить в двух классах:

`IndexView` на 192 строке кода в файле `films/views.py`

```python
class IndexView(FilmFilterMixin, PaginationRangeMixin, FilmQuerySetMixin, ListView):
    model = Film
    template_name = 'films/index.html'
    context_object_name = 'films'
    paginate_by = 6

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['title'] = 'Лучшие фильмы всех времён'
        return context
```

В классе `FilmListView` на 255 строке кода в файла `films/views.py`

```python
class FilmListView(FilmQuerySetMixin, PaginationRangeMixin, ListView):
    model = Film
    template_name = 'films/film_list.html'
    context_object_name = 'films'
    paginate_by = 10
```

Это два класса, отвечающие за разные страницы сайта.

- `IndexView` отвечает за главную страницу, которая открывается по адресу `http://127.0.0.1:8000/`
- `FilmListView` отвечает за страницу, на которой расположен каталог вашего сайта `http://127.0.0.1:8000/films/`

Обычно на главной странице меньше элементов, чем на странице каталога.

## Изменения информации на самом сайте

Вы можете добавить/изменить/удалить любую информацию, которая сейчас есть на нашем сайте. Сделать это легче всего через админ-панель вашего сайта. Что бы туда попасть достаточно перейти по адресу:

```bash
`http://127.0.0.1:8000/admin/`
```

У вас откроется страница для входа в панель администратора. Для входа можете использовать информацию из пункта 5 этого материала.

---

В левой части страницы вы можете увидеть все сущности, которыми можно управлять. 

Для удаления всех фильмов достаточно кликнуть в левой панели на `Фильмы`. Откроется список всех фильмов. Можно выбрать все фильмы, поставив галочки на каждом. И далее, немного выше, в поле `Action:` выбрать `Delete selected Фильмы`.

---

Для добавления новых фильмов на этой же странице найдите кнопку `Add Фильм`. Она находится немного правее и выше списка фильмов.

Также для добавления фильма можно использовать адрес: `http://127.0.0.1:8000/films/add/`.

### 8. Где брать материал для новых фильмов.

Я обычно использую сайт [кинопоиск](https://www.kinopoisk.ru/). На нем вы можете найти любой фильм, скачать его постер, трейлер и посмотреть информацию о самом фильме.

### 9. Работа с нейронкой

Вы можете проделать вручную большинство из описанных действий, а можете воспользоваться ИИ для помощи. Особенно это касается стилизации, цветов, карточек фильма. Возможно, она подскажет интересные решения.

Бесплатно (но через специальные программы обхода) вы можете воспользоваться [ChatGPT](https://chatgpt.com/) или любой другой нейронкой. Со стилизацией они обычно справляются отлично. Но помните, чем глубже по описанию промпт, тем лучше нейронка выдаст результат.
