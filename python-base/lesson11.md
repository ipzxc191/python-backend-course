# Урок 11. Индексы и срезы строк

В модуле 1 мы сознательно ограничились обращением к строке только по одному положительному индексу — этого хватало для первого знакомства, но далеко не для всего, что умеет делать Python со строками. Сегодня мы закрываем этот пробел полностью: разберём отрицательные индексы и срезы — способ получить сразу несколько символов подряд, а не один.

## Отрицательные индексы

В прошлом модуле мы находили последний символ строки не самым удобным способом — через `len(строка) - 1`. Python предлагает способ проще: индексы можно указывать не только от начала строки, но и от конца, если использовать отрицательные числа.

```python
word = "Python"

print(word[-1])   # n — последний символ
print(word[-2])   # o — предпоследний символ
```

`-1` всегда означает последний символ строки, `-2` — предпоследний, и так далее. Это устраняет необходимость каждый раз вычислять `len(word) - 1`, если нужен именно последний символ, — `word[-1]` делает то же самое короче и понятнее.

## Срезы: получаем часть строки, а не один символ

Срез (slice) позволяет получить сразу несколько символов подряд — фрагмент строки — а не один символ, как обычный индекс. Синтаксис среза — два числа через двоеточие внутри квадратных скобок: `строка[начало:конец]`.

```python
word = "Python"

print(word[0:3])   # Pyt
print(word[2:5])   # tho
```

Здесь важно как следует запомнить одну деталь, которая почти наверняка собьёт с толку в первый раз: индекс `начало` включается в результат, а индекс `конец` — нет, то есть срез забирает символы вплоть до `конец`, но не включая его. `word[0:3]` берёт символы с индексами `0`, `1`, `2` — но не индекс `3`, хотя число `3` явно присутствует в записи среза. Символов в результате получается ровно `конец - начало`, то есть в данном случае `3 - 0 = 3` символа.

## Сокращённая запись срезов

Если начало среза — самое начало строки, или конец среза — самый её конец, соответствующее число можно вообще не писать:

```python
word = "Python"

print(word[:3])   # Pyt — от начала строки до индекса 3, не включая его
print(word[3:])   # hon — от индекса 3 до самого конца строки
print(word[:])    # Python — вся строка целиком
```

`word[:3]` эквивалентно `word[0:3]`, а `word[3:]` эквивалентно `word[3:len(word)]` — просто короче писать.

## Отрицательные индексы в срезах

Отрицательные индексы точно так же работают и внутри срезов:

```python
word = "Python"

print(word[-3:])    # hon — последние три символа
print(word[:-2])    # Pyth — все символы, кроме последних двух
```

`word[-3:]` означает «начиная с третьего символа с конца и до самого конца строки», а `word[:-2]` — «от начала строки и до второго символа с конца, не включая его».

## Шаг среза

У среза есть и третий, необязательный параметр — шаг: `строка[начало:конец:шаг]`. Он определяет, через сколько символов брать следующий:

```python
word = "Python"

print(word[0:6:2])   # Pto — каждый второй символ
```

Шаг `2` означает «взять символ, затем пропустить один, взять следующий» — отсюда `P`, `t`, `o` (индексы 0, 2, 4).

Особенно полезный частный случай — отрицательный шаг `-1`, который разворачивает строку задом наперёд:

```python
word = "Python"
print(word[::-1])   # nohtyP
```

Здесь и начало, и конец среза не указаны (значит, берётся вся строка целиком), а шаг `-1` означает «идти не слева направо, а справа налево» — в результате получается та же строка, но перевёрнутая. Этот приём вы ещё не раз встретите — например, для проверки, является ли слово палиндромом.

## Срезы не вызывают ошибку при выходе за границы

Здесь стоит явно обратить внимание на разницу в поведении между обычным индексом и срезом. Обращение к несуществующему индексу, как мы помним из модуля 1, вызывает `IndexError`:

```python
word = "Python"
print(word[10])
# IndexError: string index out of range
```

А вот срез с выходом за границы строки ошибки не вызывает вовсе — он просто возвращает столько символов, сколько реально нашлось, вплоть до пустой строки:

```python
word = "Python"
print(word[3:100])   # hon — Python просто берёт всё, что есть, начиная с индекса 3
print(word[100:200]) # '' — пустая строка, символов в этом диапазоне вообще нет
```

Это не ошибка и не особенность, о которой стоит беспокоиться, — так срезы устроены намеренно, и это часто оказывается удобным: не нужно заранее проверять, достаточно ли длинная строка, прежде чем взять от неё, например, первые пять символов — если символов меньше пяти, срез просто вернёт то, что есть.

## Итоги урока

Отрицательные индексы отсчитывают позицию в строке с конца: `-1` — последний символ, `-2` — предпоследний, и так далее. Срез (`строка[начало:конец:шаг]`) возвращает часть строки: границы можно опускать, если нужно взять от самого начала или до самого конца, а конечный индекс среза никогда не включается в результат. Отрицательный шаг `-1` разворачивает строку. В отличие от обычного индекса, срез с выходом за границы строки не вызывает ошибку, а просто возвращает то, что реально нашлось.
