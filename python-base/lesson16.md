# Урок 16. Методы списков

В прошлом уроке мы вскользь упомянули: в отличие от строк, списки изменяемы — их можно менять после создания, не пересоздавая заново. Пришло время увидеть, как именно это работает. Методы списков — это, пожалуй, самый насыщенный практикой урок модуля, и не случайно: именно эти инструменты вы будете использовать в реальном коде постоянно.

## Добавление элементов: append(), insert()

`append()` добавляет новый элемент в конец списка:

```python
fruits = ["яблоко", "банан"]
fruits.append("апельсин")
print(fruits)   # ['яблоко', 'банан', 'апельсин']
```

Обратите внимание: мы не переприсваивали `fruits` — просто вызвали метод, и сам список изменился. Это принципиально отличается от того, как вели себя методы строк в уроке 12, где `word.upper()` без переприсваивания ничего не менял. Списки, в отличие от строк, изменяются **на месте** — сам объект в памяти меняется, а не создаётся новый.

`insert(индекс, значение)` вставляет элемент в конкретную позицию, сдвигая всё, что было после неё, на одну позицию вправо:

```python
fruits = ["яблоко", "банан", "апельсин"]
fruits.insert(1, "манго")
print(fruits)   # ['яблоко', 'манго', 'банан', 'апельсин']
```

Элемент `"манго"` встал на позицию с индексом 1, а «банан» и «апельсин», которые там были и после неё, сдвинулись на один шаг дальше.

## Удаление элементов: remove(), pop()

Здесь легко перепутать два метода, потому что оба удаляют элемент, но делают это по разным признакам — и путаница между ними одна из самых частых ошибок с методами списков.

`remove(значение)` удаляет **первое найденное вхождение указанного значения** — вы передаёте не индекс, а само значение, которое нужно найти и убрать:

```python
fruits = ["яблоко", "банан", "апельсин", "банан"]
fruits.remove("банан")
print(fruits)   # ['яблоко', 'апельсин', 'банан']
```

Обратите внимание: удалился только первый `"банан"`, а второй остался — `remove()` находит первое совпадение и останавливается, не трогая остальные. Если указанного значения в списке нет вообще, `remove()` вызовет ошибку:

```python
fruits = ["яблоко", "банан"]
fruits.remove("груша")
# ValueError: list.remove(x): x not in list
```

`pop(индекс)`, напротив, удаляет элемент **по индексу**, а не по значению, и, в отличие от всех методов до этого момента, ещё и **возвращает** удалённый элемент, а не просто изменяет список:

```python
fruits = ["яблоко", "банан", "апельсин"]
removed = fruits.pop(0)

print(removed)   # яблоко
print(fruits)     # ['банан', 'апельсин']
```

Если вызвать `pop()` совсем без аргумента, по умолчанию удаляется и возвращается последний элемент списка:

```python
fruits = ["яблоко", "банан", "апельсин"]
last = fruits.pop()

print(last)    # апельсин
print(fruits)   # ['яблоко', 'банан']
```

Короткое правило, чтобы не путать эти два метода: `remove()` — «убери вот это значение, где бы оно ни было», `pop()` — «убери то, что стоит на этой позиции, и отдай мне его».

## Сортировка: sort()

`sort()` сортирует список по возрастанию, изменяя его на месте:

```python
numbers = [5, 2, 8, 1, 9]
numbers.sort()
print(numbers)   # [1, 2, 5, 8, 9]
```

Чтобы отсортировать по убыванию, достаточно передать именованный аргумент `reverse=True`:

```python
numbers = [5, 2, 8, 1, 9]
numbers.sort(reverse=True)
print(numbers)   # [9, 8, 5, 2, 1]
```

`sort()` точно так же работает и со списками строк, сортируя их по алфавиту — по тому же принципу, что мы уже видели при сравнении строк через `>`/`<` в уроке 7:

```python
names = ["Дмитрий", "Анна", "Виктор"]
names.sort()
print(names)   # ['Анна', 'Виктор', 'Дмитрий']
```

### Забегая вперёд: sorted() — та же сортировка, но без изменения списка

Здесь уместно вспомнить урок 12, где мы разбирали разницу между методом и функцией. `sort()` — это метод, и он всегда меняет список на месте. Но у Python есть и полноценная **функция** `sorted()`, решающая ту же задачу иначе — она не трогает исходный список, а возвращает **новый**, отсортированный:

```python
numbers = [5, 2, 8, 1, 9]
sorted_numbers = sorted(numbers)

print(sorted_numbers)   # [1, 2, 5, 8, 9] — новый, отсортированный список
print(numbers)           # [5, 2, 8, 1, 9] — исходный список не изменился
```

Сравните синтаксис: `numbers.sort()` — вызов метода через точку, у самого списка; `sorted(numbers)` — вызов обычной функции, куда список передаётся как аргумент, точно так же, как мы передавали значения в `len()` или `print()`. Разница в синтаксисе здесь не случайна — она напрямую отражает разницу в поведении: метод действует на сам объект и меняет его, функция принимает объект как данные и отдаёт новый результат, не трогая исходный.

Мы не будем углубляться в `sorted()` прямо сейчас — подробно разберём её, включая сортировку по собственному правилу через параметр `key`, в уроке 45. Пока достаточно запомнить сам факт: если нужно отсортировать список, не меняя исходный (например, чтобы использовать и оригинальный порядок, и отсортированный одновременно), нужен `sorted()`, а не `sort()`.

## Разворот на месте: reverse()

Метод `reverse()` разворачивает список в обратном порядке, тоже изменяя его на месте:

```python
numbers = [1, 2, 3, 4, 5]
numbers.reverse()
print(numbers)   # [5, 4, 3, 2, 1]
```

В прошлом уроке мы для этой же цели пользовались срезом `[::-1]` — важно понимать разницу между этими двумя подходами. Срез `[::-1]` создаёт **новый** список, никак не трогая исходный, а метод `reverse()` меняет **сам** исходный список:

```python
numbers = [1, 2, 3]

reversed_by_slice = numbers[::-1]
print(numbers)             # [1, 2, 3] — не изменился
print(reversed_by_slice)   # [3, 2, 1] — новый список

numbers.reverse()
print(numbers)   # [3, 2, 1] — а вот теперь изменился сам
```

Оба способа рабочие, но выбор зависит от того, нужно ли сохранить исходный порядок в отдельной переменной или можно изменить сам список напрямую.

## Подсчёт и поиск: count(), index()

`count(значение)` возвращает, сколько раз указанное значение встречается в списке:

```python
numbers = [1, 2, 2, 3, 2, 4]
print(numbers.count(2))   # 3
```

`index(значение)` возвращает индекс первого вхождения значения — по своей сути похоже на `find()` у строк из урока 12, но с важным отличием в поведении при отсутствии значения:

```python
fruits = ["яблоко", "банан", "апельсин"]
print(fruits.index("апельсин"))   # 2
```

В отличие от `find()`, который при отсутствии подстроки возвращал `-1`, `index()` при отсутствии значения в списке вызывает ошибку:

```python
fruits = ["яблоко", "банан"]
print(fruits.index("груша"))
# ValueError: 'груша' is not in list
```

Если есть риск, что искомого значения может не быть в списке, стоит сначала проверить его наличие оператором `in`, прежде чем вызывать `index()` — тогда программа не остановится с ошибкой:

```python
fruits = ["яблоко", "банан"]
target = "груша"

if target in fruits:
    print(fruits.index(target))
else:
    print("Такого элемента нет в списке")
```

## Главная ловушка: методы списков обычно не нужно переприсваивать

Здесь стоит зафиксировать правило, прямо противоположное тому, что мы разбирали в уроке про методы строк. Тогда мы говорили: строки неизменяемы, поэтому результат метода обязательно нужно сохранять через переприсваивание, иначе изменения потеряются. Со списками — наоборот: большинство методов (`append()`, `insert()`, `remove()`, `sort()`, `reverse()`) уже меняют список на месте и при этом **возвращают `None`** — попытка их переприсвоить не сохранит результат, а полностью уничтожит список:

```python
fruits = ["яблоко", "банан"]
fruits = fruits.append("апельсин")

print(fruits)   # None — список потерян!
```

Здесь `append()` действительно добавил `"апельсин"` в список, но сам метод при этом вернул `None` — и именно это `None` было записано обратно в `fruits`, полностью стерев весь список. Правильный вариант — просто вызвать метод отдельной строкой, без присваивания:

```python
fruits = ["яблоко", "банан"]
fruits.append("апельсин")
print(fruits)   # ['яблоко', 'банан', 'апельсин']
```

Единственное исключение среди рассмотренных сегодня методов — `pop()`, который как раз специально возвращает удалённый элемент, и его результат стоит сохранять, если этот элемент нужен дальше.

## Итоги урока

`append()` добавляет элемент в конец списка, `insert()` — на указанную позицию. `remove()` удаляет первое вхождение значения (по значению, не по индексу) и вызывает ошибку, если значения нет в списке. `pop()` удаляет элемент по индексу (по умолчанию — последний) и возвращает его. `sort()` сортирует список на месте, `reverse()` разворачивает его на месте — в отличие от среза `[::-1]` и функции `sorted()`, которые создают новый список, не трогая исходный (подробнее про `sorted()` — в уроке 45). `count()` считает вхождения значения, `index()` возвращает индекс первого вхождения и вызывает ошибку, если значения нет. Большинство этих методов меняют список на месте и возвращают `None` — переприсваивать их результат не нужно и опасно.

В следующем уроке мы завершим модуль тернарным условным оператором — компактной записью того же `if`/`else`, с которым мы уже хорошо знакомы.
