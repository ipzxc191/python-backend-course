# Урок 51. Работа с текстовыми файлами (.txt)

В прошлом уроке мы научились правильно открывать и закрывать файл. Теперь разберём, как реально читать и записывать содержимое текстового файла — первого и самого простого формата из тех, что мы рассмотрим в этом модуле.

## Сначала важная деталь: кодировка

Прежде чем читать и писать текст, нужно понять одну вещь, которая регулярно ломает программы у начинающих: **компьютер хранит в файле не буквы, а байты**. Чтобы превратить буквы в байты (при записи) и байты обратно в буквы (при чтении), используется **кодировка** — таблица соответствия «символ ↔ набор байтов».

Кодировок много. Две, которые вы встретите чаще всего:

* **UTF-8** — современный стандарт. Умеет записывать символы любых языков, включая русский, эмодзи и иероглифы. Именно её используют сайты, большинство редакторов и сам Python для исходного кода.
* **cp1251** (Windows-1251) — старая кодировка Windows для кириллицы. Всё ещё встречается в файлах, созданных старыми программами.

Проблема возникает, когда файл **записан в одной кодировке, а читается в другой**. Тогда вместо текста вы получите «кракозябры» (`РџРѕР·РІРѕРЅРёС‚СЊ`) или ошибку `UnicodeDecodeError`: Python не смог превратить байты в буквы по чужой таблице.

Почему это легко пропустить? Если не указывать кодировку явно, Python берёт **кодировку по умолчанию, которая зависит от операционной системы**. На одном компьютере она может быть UTF-8, на другом — cp1251. Код, который прекрасно работает у вас, может сломаться у коллеги.

Решение простое — всегда указывать кодировку явно параметром `encoding`:

```python
with open("example.txt", "w", encoding="utf-8") as file:
    file.write("Привет, мир!\n")

with open("example.txt", "r", encoding="utf-8") as file:
    print(file.read())   # Привет, мир!
```

Параметр `encoding` работает в любом режиме (`"r"`, `"w"`, `"a"` и других) и при чтении, и при записи. **Правило курса: при работе с текстовыми файлами всегда пишем `encoding="utf-8"`.** Так запись и чтение гарантированно идут в одной кодировке, а программа ведёт себя одинаково на любом компьютере.

Если вам попадётся файл в cp1251, его можно прочитать, указав `encoding="cp1251"` — нужно лишь знать, в какой кодировке он был сохранён.

## Чтение файла целиком: read()

Метод `read()`, который мы уже мельком использовали в прошлом уроке, читает всё содержимое файла как одну строку:

```python
with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
```

Если файл содержит несколько строк, они все окажутся внутри одной строки `content`, разделённые символами `\n` — точно такими же символами перевода строки, что мы разбирали в уроке 13.

## Чтение файла построчно: readlines()

Метод `readlines()` возвращает содержимое файла не одной строкой, а списком строк — каждый элемент списка соответствует одной строке файла:

```python
with open("example.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

print(lines)
# ['Первая строка\n', 'Вторая строка\n', 'Третья строка']
```

Обратите внимание: каждая строка в списке, кроме, возможно, последней, заканчивается символом `\n` — он был частью исходного файла (перевод строки, отделявший одну строку от другой) и сохранился при чтении. Если этот символ мешает дальнейшей обработке, от него легко избавиться уже знакомым методом `strip()` из урока 12:

```python
with open("example.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

clean_lines = [line.strip() for line in lines]
print(clean_lines)
# ['Первая строка', 'Вторая строка', 'Третья строка']
```

## Самый идиоматичный способ: перебор файла циклом for

Есть и третий способ, самый распространённый на практике: файл можно перебирать циклом `for` напрямую, без предварительного вызова `read()` или `readlines()` — вспомним урок 26, где мы разбирали, что `for` работает с любым итерируемым объектом, а файл в Python как раз им и является:

```python
with open("example.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

Этот способ не просто короче — он ещё и эффективнее по памяти для больших файлов: `readlines()` сразу загружает в память весь файл целиком в виде списка, а перебор циклом `for` читает файл построчно, по одной строке за раз, ровно в духе ленивых вычислений, которые мы разбирали в уроке 38.

## Запись в файл: write()

Метод `write()`, уже использованный в прошлом уроке, записывает переданную строку в файл. Здесь важно обратить внимание на отличие от `print()`: `write()`, в отличие от `print()`, **не добавляет** перевод строки автоматически, — если нужно, чтобы следующая запись оказалась на новой строке, `\n` нужно дописать вручную:

```python
with open("example.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")
    file.write("Вторая строка\n")
```

Если `\n` не добавить, обе строки окажутся склеенными в одну без всякого разделения:

```python
with open("example.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка")
    file.write("Вторая строка")

# итоговое содержимое файла: "Первая строкаВторая строка"
```

## Запись списка строк: writelines()

Если нужно записать сразу несколько строк из списка, можно использовать `writelines()` — но здесь стоит явное предупреждение: этот метод, вопреки интуитивному ожиданию, **тоже не добавляет** переводы строк автоматически между элементами списка — за это по-прежнему отвечаете вы сами:

```python
lines = ["Первая строка\n", "Вторая строка\n", "Третья строка"]

with open("example.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)
```

Если бы элементы списка не содержали `\n` внутри себя, `writelines()` точно так же слепила бы их в одну сплошную строку без разделения — этот метод избавляет лишь от необходимости писать `write()` в цикле вручную, но не от заботы о переводах строк.

## Разбор задачи: фильтрация строк по ключевому слову

Разберём практическую задачу целиком. Дан файл с заметками, и нужно найти в нём все строки, содержащие определённое ключевое слово, и сохранить их в отдельный файл.

### Подготовка исходных данных

Для практики нам понадобится файл `notes.txt`. Создайте его рядом с программой (в той же папке) и скопируйте в него следующий текст — 12 заметок, каждая на отдельной строке:

```text
Позвонить маме
важно: сдать отчёт до пятницы
Хлеб
Записаться к врачу на вторник
важно!
Купить чай
Подготовить презентацию к лекции
Это важно не забыть про встречу
Спорт
Купить хлеб
Купить подарок, это очень важно
Прочитать главу книги
```

Важно сохранить файл в кодировке UTF-8 (в большинстве редакторов это значение по умолчанию; в Блокноте Windows — выбрать «UTF-8» в окне «Сохранить как»).

Если не хочется копировать вручную, файл можно создать кодом. Запись и последующее чтение идут в одной кодировке (`utf-8`), поэтому проблем не возникнет:

```python
notes = """Позвонить маме
важно: сдать отчёт до пятницы
Хлеб
Записаться к врачу на вторник
важно!
Купить чай
Подготовить презентацию к лекции
Это важно не забыть про встречу
Спорт
Купить хлеб
Купить подарок, это очень важно
Прочитать главу книги
"""

with open("notes.txt", "w", encoding="utf-8") as file:
    file.write(notes)
```

### Решение

Разложим задачу на понятные шаги — та самая декомпозиция из модуля 5:

```python
def read_lines(filename):
    with open(filename, "r", encoding="utf-8") as file:
        return [line.strip() for line in file]


def filter_lines(lines, keyword):
    return [line for line in lines if keyword in line]


def save_lines(filename, lines):
    with open(filename, "w", encoding="utf-8") as file:
        for line in lines:
            file.write(line + "\n")


def main():
    lines = read_lines("notes.txt")
    important_lines = filter_lines(lines, "важно")
    save_lines("important_notes.txt", important_lines)
    print(f"Найдено и сохранено строк: {len(important_lines)}")


main()
```

Разберём эту программу по функциям. `read_lines()` отвечает только за чтение — открывает файл и сразу возвращает список строк без лишних символов перевода строки. `filter_lines()` вообще не знает о существовании файлов — она принимает обычный список строк и обычную строку-ключевое слово, а возвращает отфильтрованный список, используя уже знакомый генератор списка с условием и оператор `in` для строк из урока 18. `save_lines()` снова отвечает только за файл — на этот раз за запись, добавляя `\n` вручную к каждой строке. А `main()` связывает все три части воедино, ничего не делая сама по себе, кроме вызова остальных функций по порядку.

Обратите внимание, что во всех `open()` указана кодировка `utf-8` — и при чтении, и при записи.

### Ожидаемый результат

После запуска в консоли появится:

```text
Найдено и сохранено строк: 4
```

А в папке — новый файл `important_notes.txt` со строками, в которых встретилось слово «важно»:

```text
важно: сдать отчёт до пятницы
важно!
Это важно не забыть про встречу
Купить подарок, это очень важно
```

Обратите внимание на пользу такого разделения: если завтра понадобится читать данные не из файла, а, например, из введённого пользователем текста, придётся заменить только `read_lines()`, не трогая `filter_lines()` вообще, — именно в этом и заключается практическая ценность декомпозиции, о которой мы говорили в начале модуля 5.

## Итоги урока

Текстовый файл хранит байты, а превращение их в буквы определяет кодировка: чтобы программа вела себя одинаково на любом компьютере, всегда указываем `encoding="utf-8"` при чтении и записи. `read()` читает весь файл одной строкой, `readlines()` — списком строк с сохранёнными символами `\n`, а перебор файла циклом `for` — самый эффективный по памяти и самый распространённый на практике способ построчной обработки. `write()` записывает строку без автоматического перевода строки, `writelines()` записывает список строк, тоже без автоматических переводов строк между ними, — в обоих случаях `\n` нужно добавлять вручную, если он нужен.
