# Урок 37. Генераторы словарей и множеств

В прошлом уроке среди «фишек» мы уже пользовались конструкцией вида `{ключ: значение for ... in ...}`, не называя её отдельной темой. Настало время дать ей имя и разобрать формально — а заодно познакомиться с её близким родственником, генератором множества, которого до сих пор не было в курсе.

## Генератор словаря: формализуем уже знакомое

Генератор словаря устроен по тому же принципу, что и генератор списка из урока 28, только вместо квадратных скобок используются фигурные, а вместо одного выражения — пара «ключ: значение»:

```python
numbers = [1, 2, 3, 4, 5]
squares = {n: n ** 2 for n in numbers}

print(squares)
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

Общая структура:

```
{ключ: значение for переменная in последовательность if условие}
```

Условие-фильтр работает так же, как и в генераторе списка:

```python
numbers = [1, 2, 3, 4, 5, 6]
even_squares = {n: n ** 2 for n in numbers if n % 2 == 0}

print(even_squares)
# {2: 4, 4: 16, 6: 36}
```

Ничего принципиально нового здесь нет — это тот же самый паттерн «завести пустой контейнер и заполнить его циклом», записанный компактно, просто применённый теперь не к списку, а к словарю:

```python
numbers = [1, 2, 3, 4, 5]
squares = {}

for n in numbers:
    squares[n] = n ** 2
```

## Генератор множества: то же самое, но без пар

Генератор множества выглядит почти так же, как генератор словаря, но без двоеточия — внутри фигурных скобок стоит одно выражение, как в генераторе списка, а не пара:

```python
numbers = [1, 2, 3, 2, 4, 3, 5]
unique_squares = {n ** 2 for n in numbers}

print(unique_squares)
# {1, 4, 9, 16, 25}
```

Обратите внимание: несмотря на то, что число `2` и `3` встречаются в исходном списке дважды, их квадраты (`4` и `9`) в итоговом множестве присутствуют лишь по одному разу — множество, как мы помним из урока 34, автоматически убирает дубликаты, и генератор множества ничем не отличается в этом плане от множества, созданного любым другим способом.

## Разница между {} для словаря и {} для множества

Здесь стоит явно зафиксировать то, что отличает синтаксис одного генератора от другого, раз оба используют одинаковые фигурные скобки:

```python
{ключ: значение for ...}   # генератор словаря — есть двоеточие
{значение for ...}         # генератор множества — без двоеточия
```

Наличие или отсутствие двоеточия внутри выражения — единственный синтаксический признак, определяющий, что именно вы получите: словарь или множество.

## Практическая польза генератора множества

Раньше, в уроке 34, чтобы получить множество уникальных преобразованных значений, приходилось действовать в два шага: сначала собрать список через обычный цикл или генератор списка, а затем обернуть его в `set()`:

```python
words = ["кот", "дом", "код", "мир"]
lengths_list = [len(word) for word in words]
unique_lengths = set(lengths_list)

print(unique_lengths)   # {3}
```

Генератор множества позволяет получить тот же результат за один шаг, без промежуточного списка:

```python
words = ["кот", "дом", "код", "мир"]
unique_lengths = {len(word) for word in words}

print(unique_lengths)   # {3}
```

## Условие внутри генератора множества

Условие-фильтр работает и здесь точно так же, как в остальных генераторах:

```python
words = ["кот", "программирование", "дом", "разработка", "сад"]
long_word_first_letters = {word[0] for word in words if len(word) > 4}

print(long_word_first_letters)
# {'п', 'р'}
```

## Итоги урока

Генератор словаря (`{ключ: значение for переменная in последовательность if условие}`) — прямое расширение генератора списка на новый тип контейнера, с парой «ключ: значение» вместо одного выражения. Генератор множества (`{выражение for переменная in последовательность if условие}`) устроен так же, но без двоеточия — единственный признак, отличающий синтаксис генератора множества от генератора словаря. Оба избавляют от необходимости заводить пустой контейнер и заполнять его циклом вручную, а генератор множества дополнительно избавляет от промежуточного списка там, где раньше требовалось оборачивать результат в `set()` отдельным шагом.

В следующем уроке мы разберём генераторное выражение — более глубокую тему о том, что вообще происходит внутри Python, когда данные не сразу превращаются в готовый список, а порождаются по требованию.
