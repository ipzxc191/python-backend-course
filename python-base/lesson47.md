# Урок 47. Практика: разбор многострочной строки, преобразование в удобные типы данных

Весь этот урок — одна крупная практическая задача, а вокруг неё — вариации для самостоятельной отработки. Мы возьмём данные в виде обычного текста, состоящего из нескольких строк, и превратим их в удобные для работы структуры — списки словарей. Это не абстрактное упражнение: именно так на практике чаще всего выглядит первый шаг обработки данных, полученных из файла, — а с файлами мы познакомимся уже в следующем модуле, и принцип разбора там будет практически таким же.

## Исходные данные

Представим, что у нас есть текст со списком студентов — по одному студенту на строку, поля разделены запятой:

```python
data = """Олег,25,Москва
Мария,30,Казань
Дмитрий,22,Санкт-Петербург"""

print(data)
```

Такая запись через тройные кавычки позволяет создать строку, растянутую на несколько строк прямо в коде — символы перевода строки между именами оказываются частью самой строки, без необходимости писать `\n` вручную.

## Шаг 1: разбиваем текст на отдельные строки

Первый шаг — разделить весь текст на отдельные строки-записи. Раз каждая запись отделена от следующей символом перевода строки, для этого подходит уже знакомый метод `split()`, использованный не по пробелу, а по `"\n"`:

```python
lines = data.split("\n")
print(lines)
# ['Олег,25,Москва', 'Мария,30,Казань', 'Дмитрий,22,Санкт-Петербург']
```

Теперь `lines` — это список из трёх строк, каждая из которых представляет одну запись.

## Шаг 2: разбираем одну строку в словарь

Прежде чем обрабатывать все строки сразу, разберём, как превратить в удобную структуру всего одну строку. Оформим эту логику в отдельную функцию — та самая декомпозиция, с которой начинался модуль 5:

```python
def parse_line(line):
    fields = line.split(",")
    keys = ["name", "age", "city"]
    return dict(zip(keys, fields))

print(parse_line("Олег,25,Москва"))
# {'name': 'Олег', 'age': '25', 'city': 'Москва'}
```

Здесь `fields` — список из трёх значений, полученных разбиением строки по запятой, а `dict(zip(keys, fields))` — тот самый приём из урока 46, связывающий имена полей со значениями в единый словарь.

Обратите внимание: значение `"age"` в получившемся словаре — это строка `"25"`, а не число, потому что `split()` всегда возвращает строки, независимо от того, что было в исходном тексте. Добавим преобразование типа прямо внутри функции:

```python
def parse_line(line):
    fields = line.split(",")
    keys = ["name", "age", "city"]
    record = dict(zip(keys, fields))
    record["age"] = int(record["age"])
    return record

print(parse_line("Олег,25,Москва"))
# {'name': 'Олег', 'age': 25, 'city': 'Москва'}
```

## Шаг 3: разбираем весь текст целиком

Теперь применим `parse_line()` к каждой строке текста. Здесь удобно использовать уже знакомый `map()` из урока 45 — он как раз создан для того, чтобы применить одну функцию к каждому элементу последовательности:

```python
def parse_text(text):
    lines = text.split("\n")
    return list(map(parse_line, lines))

students = parse_text(data)
print(students)
```

```
[
    {'name': 'Олег', 'age': 25, 'city': 'Москва'},
    {'name': 'Мария', 'age': 30, 'city': 'Казань'},
    {'name': 'Дмитрий', 'age': 22, 'city': 'Санкт-Петербург'}
]
```

Обратите внимание, что в `map(parse_line, lines)` функция `parse_line` передана **без круглых скобок и без аргумента** — мы не вызываем её сами, а лишь сообщаем `map()`, какую функцию применить к каждому элементу; вызовет её сама `map()`, поочерёдно передавая ей каждую строку из `lines`.

## Шаг 4: работаем с результатом как с обычными данными

Как только текст превращён в список словарей, все инструменты, разобранные в этом модуле и раньше, оказываются доступны без каких-либо специальных усилий:

```python
# отсортировать студентов по возрасту
by_age = sorted(students, key=lambda student: student["age"])

# проверить, есть ли студент старше 28 лет
has_older = any(student["age"] > 28 for student in students)

# оставить только студентов из Москвы
from_moscow = list(filter(lambda student: student["city"] == "Москва", students))

print(by_age)
print(has_older)
print(from_moscow)
```

Именно ради этого и затевался весь разбор — превратить неудобный, монолитный текст в структуру данных, с которой можно работать всеми уже знакомыми средствами, вместо того чтобы каждый раз заново копаться в исходной строке.

## Мостик к следующему модулю

Всё, что мы сделали в этом уроке, начиналось с готовой строки `data`, уже лежащей в коде. В следующем модуле мы разберём, как читать содержимое настоящего файла с диска, — и содержимое файла, прочитанное в Python, тоже оказывается обычной строкой (или списком строк), к которой применяются ровно те же самые приёмы: `split()` по разделителю, разбор каждой строки на поля, преобразование типов, сборка в список словарей. Разница будет только в том, откуда берётся исходный текст — из переменной, заданной прямо в коде, или из файла на диске.

## Итоги урока

Разбор многострочного текста в удобную структуру данных обычно проходит в несколько шагов: разбить весь текст на строки через `split("\n")`, разобрать одну строку на поля через `split()` по нужному разделителю, связать поля с именами через `dict(zip(...))`, преобразовать типы там, где это нужно, и применить получившуюся логику ко всем строкам сразу через `map()`. Вынесение шагов разбора в отдельные, небольшие функции (`parse_line()`, `parse_text()`) — прямое применение декомпозиции, с которой начинался этот модуль. Получившийся список словарей можно дальше обрабатывать любыми уже знакомыми инструментами — `sorted()`, `any()`, `filter()` и другими.
