# Урок 5. Строки: первое знакомство

До сих пор мы работали в основном с числами. Но огромная часть того, с чем имеет дело программа, — это текст: имена, сообщения, адреса, пароли. В этом уроке мы делаем первый, сознательно небольшой шаг в мир строк — достаточно, чтобы начать решать содержательные задачи, но не больше. Срезы, методы строк и многое другое из того, что строки умеют, мы подробно разберём в следующем модуле — здесь же наша цель проще: понять, что такое строка, и научиться с ней немного взаимодействовать.

## Что такое строка

Строка (`str`) — это текст, заключённый в кавычки. Python допускает как одинарные, так и двойные кавычки — разницы между ними нет, важно лишь использовать один и тот же вид кавычек в начале и в конце:

```python
city = "Москва"
country = 'Россия'
```

Строка может состоять из чего угодно: одной буквы, слова, целого предложения или вовсе быть пустой (`""`). Проверить, что перед вами действительно строка, можно уже знакомым способом:

```python
print(type(city))   # <class 'str'>
```

## Склеивание строк оператором +

К строкам, как и к числам, применим оператор `+` — но, как мы уже видели на примере с `input()` в прошлом уроке, для строк он работает иначе: не складывает, а склеивает, то есть соединяет одну строку с другой:

```python
first_name = "Анна"
last_name = "Смирнова"

full_name = first_name + " " + last_name
print(full_name)   # Анна Смирнова
```

Обратите внимание на отдельную строку `" "` посередине — без неё имя и фамилия слиплись бы в одно слово `АннаСмирнова`. Python не подставляет пробелы между склеиваемыми строками сам, в отличие, например, от `print()` с несколькими аргументами — здесь за каждый символ, включая пробелы, отвечаете вы.

Важно и обратное ограничение: оператор `+` для строк работает только со строками. Попытка склеить строку и число напрямую приведёт к ошибке — точно так же, как в прошлом уроке при попытке сложить результат `input()` с числом:

```python
age = 25
print("Мне " + age + " лет")
# TypeError: can only concatenate str (not "int") to str
```

Здесь Python не может ни сложить, ни склеить строку и число — с его точки зрения это несовместимые операнды для `+`. Мы ещё вернёмся к более удобному способу вставлять числа внутрь текста в одном из следующих уроков, а пока для подобных случаев проще использовать уже знакомый `print()` с несколькими аргументами через запятую — он сам справится с разными типами:

```python
age = 25
print("Мне", age, "лет")   # Мне 25 лет
```

## Длина строки: len()

Функция `len()` возвращает количество символов в строке, включая пробелы и знаки препинания:

```python
word = "Python"
print(len(word))   # 6

sentence = "Привет, мир!"
print(len(sentence))   # 12
```

Каждый символ считается отдельно, даже если это пробел или запятая — `len()` не отличает «содержательные» символы от прочих, она просто считает их все.

## Обращение к отдельному символу по индексу

У каждого символа в строке есть своя позиция, называемая **индексом**, и по этому индексу можно получить конкретный символ. В Python нумерация начинается не с единицы, а с нуля — это первое, что стоит запомнить и что первое время будет сбивать с толку:

```python
word = "Python"

print(word[0])   # P — первый символ
print(word[1])   # y — второй символ
print(word[5])   # n — шестой (и последний) символ
```

Индекс `0` указывает не на «нулевой», а на самый первый символ строки. Если в слове `"Python"` шесть букв, их индексы — `0, 1, 2, 3, 4, 5`, а не `1, 2, 3, 4, 5, 6`. Обращение к индексу, которого не существует (например, `word[6]` для этого же слова), приведёт к ошибке:

```python
word = "Python"
print(word[6])
# IndexError: string index out of range
```

Индекс `6` вышел бы за пределы строки, потому что последний реально существующий индекс здесь — `5`. Полезно держать в голове простое правило: последний индекс строки всегда равен `len(строка) - 1`, а не `len(строка)`.

Пока мы работаем только с положительными индексами, отсчитываемыми от начала строки. Есть и другие способы обращаться к символам строки — например, с конца, или сразу к нескольким символам подряд — но с ними мы познакомимся отдельно и подробно уже в следующем модуле.

## Итоги урока

Строка — это текст в кавычках. Оператор `+` для строк не складывает, а склеивает их, и работает только со строками — попытка склеить строку с числом напрямую приведёт к ошибке. Функция `len()` возвращает количество символов в строке. Обратиться к отдельному символу можно по индексу в квадратных скобках, при этом отсчёт индексов начинается с нуля, а не с единицы, и выход за пределы существующих индексов вызывает ошибку `IndexError`.
