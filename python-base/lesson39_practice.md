# Итоговая практика модуля 4

Новых тем снова не будет — весь модуль объединяется здесь: словари и их методы, работа со словарями в цикле, кортежи и распаковка, множества, генераторы словарей, множеств и генераторные выражения. Многие задачи специально комбинируют несколько из этих инструментов сразу, а также опираются на циклы и функции из предыдущих модулей.

### Задача 1. Частотный анализ текста

Запросите у пользователя текст. Используя `setdefault()`, постройте словарь с количеством вхождений каждого слова. Затем, перебирая словарь через `items()`, найдите слово с наибольшим количеством вхождений (используя паттерн «начальное предположение» из урока 22) и выведите его вместе с количеством.

**Пример использования**:

```
Введите текст: кот и пёс и кот играли
Самое частое слово: "и" (2 раза)
```

### Задача 2. Записная книжка

Создайте пустой словарь-записную книжку. Дважды запросите у пользователя имя, телефон и email, сохраняя каждый контакт как вложенный словарь под ключом-именем. После этого запросите у пользователя имя для поиска: если контакт найден — выведите его телефон и email, иначе — `"Контакт не найден"`.

**Пример использования**:

```
Имя: Роман
Телефон: 89998887766
Email: igor@example.com
Имя: Мария
Телефон: 89991112233
Email: maria@example.com
Кого найти: Мария
Телефон: 89991112233, Email: maria@example.com
```

### Задача 3. Расстояние между точками

Даны две точки в виде кортежей координат. Используя распаковку и `math.sqrt()` из урока 4, вычислите расстояние между ними по формуле корня из суммы квадратов разностей координат.

```python
point_a = (0, 0)
point_b = (3, 4)
```

```
5.0
```

### Задача 4. Уникальные посетители по дням

Создайте словарь, где ключ — день недели, а значение — множество имён посетителей в этот день (используйте `setdefault()` с пустым множеством по умолчанию). Трижды запросите у пользователя день и имя посетителя, добавляя имя в соответствующее множество. В конце с помощью объединения множеств выведите общее количество уникальных посетителей за все дни вместе.

**Пример использования**:

```
День: понедельник
Имя: Роман
День: вторник
Имя: Мария
День: понедельник
Имя: Роман
Уникальных посетителей всего: 2
```

### Задача 5. Сравнение покупателей двух магазинов

Даны два словаря: покупатели магазина A с суммой их покупок и покупатели магазина B с суммой их покупок. Используя множества, построенные из ключей обоих словарей, найдите покупателей, которые совершали покупки в обоих магазинах, и для каждого такого покупателя выведите общую сумму его покупок в обоих магазинах вместе.

```python
shop_a = {"Роман": 1500, "Мария": 2300, "Дмитрий": 800}
shop_b = {"Мария": 1200, "Анна": 900, "Роман": 600}
```

**Пример использования**:

```
Роман: 2100
Мария: 3500
```

### Задача 6. Обработка каталога товаров

Дан словарь с ценами товаров. Используя генератор словаря с условием, постройте новый словарь только с товарами дешевле 500. Используя генераторное выражение внутри `sum()`, посчитайте суммарную стоимость всех товаров каталога (всех, без фильтрации), не создавая промежуточный список.

```python
catalog = {"хлеб": 60, "молоко": 90, "телевизор": 25000, "сыр": 350, "ноутбук": 55000}
```

**Пример использования**:

```
{'хлеб': 60, 'молоко': 90, 'сыр': 350}
Общая стоимость каталога: 80500
```

### Задача 7. Группировка студентов по успеваемости

Дан словарь с оценками студентов (одно число на каждого). Используя `setdefault()`, сгруппируйте студентов в словарь по категориям: `"отлично"` (оценка 5), `"хорошо"` (4), `"остальное"` (3 и ниже) — значением каждой категории должен быть список имён. Затем с помощью генератора словаря постройте словарь с количеством студентов в каждой категории.

```python
grades = {"Роман": 5, "Мария": 4, "Дмитрий": 3, "Анна": 5, "Олег": 4}
```

**Пример использования**:

```
{'отлично': ['Роман', 'Анна'], 'хорошо': ['Мария', 'Олег'], 'остальное': ['Дмитрий']}
{'отлично': 2, 'хорошо': 2, 'остальное': 1}
```

### Задача 8. Объединение нескольких корзин покупок

Даны три словаря с покупками в разных сессиях одного пользователя (ключ — товар, значение — количество). Объедините их в один словарь, суммируя количество для товаров, встречающихся в нескольких корзинах.

```python
cart_1 = {"хлеб": 2, "молоко": 1}
cart_2 = {"молоко": 1, "сыр": 3}
cart_3 = {"хлеб": 1, "яйца": 12}
```

**Пример использования**:

```
{'хлеб': 3, 'молоко': 2, 'сыр': 3, 'яйца': 12}
```

records = [("Роман", 4), ("Мария", 5), ("Роман", 5), ("Мария", 4), ("Роман", 3), ("Мария", 5)]

### Задача 10. Комплексная задача: управление складом

Дан вложенный словарь-склад, где ключ — товар, а значение — вложенный словарь с полями `"price"`, `"quantity"` и `"category"`. Выполните следующее:

1. С помощью генератора множества получите множество всех уникальных категорий товаров.
2. С помощью генераторного выражения внутри `sum()` посчитайте общую стоимость всего склада (цена, умноженная на количество, просуммированная по всем товарам).
3. С помощью генератора словаря с условием постройте словарь только с товарами, количество которых меньше 5 (требуют пополнения).

```python
warehouse = {
    "хлеб": {"price": 60, "quantity": 12, "category": "еда"},
    "молоко": {"price": 90, "quantity": 3, "category": "еда"},
    "ноутбук": {"price": 55000, "quantity": 2, "category": "техника"},
    "мышь": {"price": 1200, "quantity": 15, "category": "техника"}
}
```

**Пример использования**:

```
Категории: {'еда', 'техника'}
Общая стоимость склада: 111990
Требуют пополнения: {'молоко': {...}, 'ноутбук': {...}}
```
