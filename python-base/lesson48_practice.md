# Итоговая практика модуля 5

Новых тем снова не будет — весь модуль объединяется здесь: синтаксис функций, параметры и их разновидности, `*args`/`**kwargs`, лямбда-функции, `map()`/`filter()`/`sorted()`, `any()`/`all()`/`zip()`, а также разбор текста в удобные структуры данных из прошлого урока. Задачи опираются и на материал предыдущих модулей — циклы, словари, множества.

### Задача 1. Функция проверки возраста

Напишите функцию `check_age(age, minimum_age=18)` с параметром по умолчанию, возвращающую `True`, если возраст не меньше минимального, и `False` в противном случае. Вызовите её дважды: один раз с одним аргументом, второй раз — указав своё значение минимального возраста.

### Задача 2. Гибкий калькулятор через *args и словарь операций

Напишите функцию `calculate(operation, *args)`, которая выполняет одну из операций — `"сумма"`, `"произведение"`, `"максимум"` — над произвольным количеством чисел, используя словарь, связывающий название операции с соответствующей лямбда-функцией, обёрнутой в `sum()`, `reduce()`-подобную логику или встроенные функции.

**Пример использования**:

```
calculate("сумма", 1, 2, 3) -> 6
calculate("максимум", 5, 12, 3) -> 12
```

### Задача 3. Разбор и анализ данных о сотрудниках

Дан многострочный текст с данными сотрудников в формате `"имя,отдел,зарплата"`. Разберите его в список словарей (по образцу урока 47), а затем напишите функцию `get_average_salary(employees, department)`, возвращающую среднюю зарплату по указанному отделу, используя `filter()` и генераторное выражение внутри `sum()`.

```python
data = """Егор,IT,80000
Мария,HR,65000
Дмитрий,IT,95000
Анна,HR,70000"""
```

**Пример использования**:

```
87500.0
```

### Задача 4. Сортировка и топ-N

Напишите функцию `get_top_n(employees, n, key)`, возвращающую первые `n` записей из списка словарей `employees`, отсортированных по убыванию значения, полученного функцией `key` (примените `sorted()` с `reverse=True` и срез).

**Пример использования**:

```
get_top_n(employees, 1, lambda e: e["salary"]) -> [{'name': 'Дмитрий', ...}]
```

### Задача 5. Меню через функции-обработчики

Реализуйте простое меню с помощью `while True` (модуль 3), где для каждой команды вызывается отдельная функция, а не разбросанная логика внутри `elif`: `"привет"` вызывает функцию `say_hello()`, `"пока"` вызывает функцию `say_bye()` и завершает цикл через `break`, любая другая команда вызывает функцию `unknown_command(command)`, которой передаётся сама введённая команда.

**Пример использования**:

```
Команда: привет
Здравствуйте!
Команда: тест
Неизвестная команда: тест
Команда: пока
До свидания!
```

### Задача 6. Связывание списков через zip и фильтрация

Даны два списка одинаковой длины — названия городов и их население. Используя `zip()`, `dict()` и `filter()`, постройте словарь только тех городов, население которых превышает 1000000.

```python
cities = ["Москва", "Тверь", "Санкт-Петербург", "Углич"]
populations = [12655050, 402000, 5384000, 32000]
```

**Пример использования**:

```
{'Москва': 12655050, 'Санкт-Петербург': 5384000}
```

### Задача 7. Проверка полноты данных

Дан список словарей с анкетами пользователей, где у некоторых может отсутствовать одно из ожидаемых полей. Используя `all()` и генератор словаря, напишите функцию `is_complete(profile, required_fields)`, проверяющую, что все обязательные поля присутствуют в конкретной анкете (используйте оператор `in`, уже знакомый вам для словарей).

```python
profiles = [
    {"name": "Егор", "age": 25, "email": "igor@example.com"},
    {"name": "Мария", "age": 30}
]
required = ["name", "age", "email"]
```

**Пример использования**:

```
True
False
```

### Задача 8. Функция с гибким форматированием через **kwargs

Напишите функцию `build_greeting_card(name, **details)`, возвращающую строку-открытку: первая строка — `"Дорогой(ая) <имя>!"`, а затем каждая пара из `details` в формате `"<ключ>: <значение>"`, отсортированная по ключу с помощью `sorted()`.

build_greeting_card("Егор", повод="День рождения", пожелание="Счастья")

event_1 = ["Егор", "Мария"]

### Задача 10. Комплексная задача: отчёт по заказам

Дан многострочный текст с заказами в формате `"клиент,товар,количество,цена"`. Реализуйте следующее через отдельные, декомпозированные функции:

1. `parse_orders(text)` — разбирает текст в список словарей с полями `client`, `item`, `quantity`, `price` и вычисляемым полем `total`.
2. `get_client_totals(orders)` — используя цикл и `setdefault()` из урока 36, возвращает словарь с суммой всех заказов каждого клиента.
3. `get_top_client(client_totals)` — используя `max()` с параметром `key`, возвращает имя клиента с наибольшей суммой заказов.

```python
data = """Егор,хлеб,2,60
Мария,молоко,1,90
Егор,сыр,1,350
Мария,масло,2,120"""
```

**Пример использования**:

```
{'Егор': 470, 'Мария': 330}
Егор
```
