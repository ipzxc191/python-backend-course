# Урок 53. Работа с CSV-файлами

Последний текстовый формат этого блока — CSV, формат для хранения табличных данных. Если вы когда-либо открывали таблицу в Excel, CSV — это, по сути, простейшая, полностью текстовая альтернатива такой таблице.

## CSV как альтернатива Excel

Файл Excel (`.xlsx`) на самом деле устроен как бинарный формат, требующий именно программу Excel (или совместимую с ней) для чтения, — открыть его в обычном текстовом редакторе не получится, там будет нечитаемый набор символов. CSV (Comma-Separated Values — «значения, разделённые запятыми») устроен иначе: это обычный текстовый файл, который открывается и читается где угодно, включая любой текстовый редактор, — просто с определённой договорённостью о том, как в тексте закодирована таблица.

А раз CSV — обычный текстовый файл, то на него полностью распространяется то, что мы узнали в уроке 51: у файла есть кодировка, и её нужно указывать явно. Во всех примерах этого урока мы пишем `encoding="utf-8"`.

## Структура CSV-файла

В CSV-файле каждая строка соответствует одной строке таблицы, а значения внутри строки разделены запятой (реже — другим символом, точкой с запятой или табуляцией, о чём мы поговорим отдельно). Первая строка чаще всего содержит заголовки столбцов:

```text
name,age,city
Егор,25,Москва
Мария,30,Казань
```

Здесь `name,age,city` — заголовок с названиями столбцов, а следующие строки — сами записи.

Создайте файл `students.csv` с таким содержимым (в кодировке UTF-8) — он понадобится для следующих примеров. Дальше в уроке мы научимся создавать такие файлы кодом.

## Модуль csv

Для работы с CSV в Python нужен модуль `csv`:

```python
import csv
```

## Чтение CSV: csv.reader()

`csv.reader()` читает файл построчно, где каждая строка представлена в виде списка значений:

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)
```

```text
['name', 'age', 'city']
['Егор', '25', 'Москва']
['Мария', '30', 'Казань']
```

В `open()` здесь два специальных параметра. Про `encoding="utf-8"` мы уже знаем. Параметр `newline=""` — техническая деталь, специфичная именно для CSV: модуль `csv` сам отвечает за переводы строк, и ему нужно, чтобы Python не вмешивался в них при работе с файлом. Без `newline=""` на Windows при записи между строками появляются лишние пустые строки. Правило простое: при работе с CSV всегда открывайте файл с `newline=""` (и при чтении, и при записи), и проблемы просто не возникнет.

Также обратите внимание, что первая строка результата — это тот же самый заголовок `['name', 'age', 'city']`, обработанный наравне с остальными строками; `csv.reader()` сам по себе не знает, что первая строка — заголовок, и это придётся учитывать в коде отдельно, если нужно.

## Запись в CSV: csv.writer()

```python
import csv

rows = [
    ["name", "age", "city"],
    ["Егор", 25, "Москва"],
    ["Мария", 30, "Казань"]
]

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)
    writer.writerows(rows)
```

`writerows()` записывает сразу список строк; если нужно записать одну строку — используется `writerow()` (без "s" на конце) с одним списком значений. Числа (как `25` выше) модуль `csv` при записи сам превращает в текст.

## Более удобный способ: DictReader и DictWriter

Работа со списками, где к каждому значению приходится обращаться по числовому индексу (`row[0]`, `row[1]`), быстро становится неудобной и хрупкой — легко перепутать порядок столбцов. `csv.DictReader` решает эту проблему, используя заголовок файла как ключи словаря — прямая параллель со словарями, которые мы прекрасно знаем по модулю 4:

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row)
```

```text
{'name': 'Егор', 'age': '25', 'city': 'Москва'}
{'name': 'Мария', 'age': '30', 'city': 'Казань'}
```

Теперь каждая строка — это словарь, и обратиться к значению можно по осмысленному имени столбца — `row["name"]`, `row["age"]` — вместо запоминания, на какой позиции какое значение стоит. Заголовок при этом в данные не попадает — он превращается в ключи. На практике `DictReader` используется значительно чаще «сырого» `csv.reader()` именно по этой причине.

Обратная операция — `csv.DictWriter`, которому нужно заранее указать список имён столбцов через параметр `fieldnames`:

```python
import csv

rows = [
    {"name": "Егор", "age": 25, "city": "Москва"},
    {"name": "Мария", "age": 30, "city": "Казань"}
]

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "age", "city"])
    writer.writeheader()
    writer.writerows(rows)
```

Здесь `writeheader()` отдельно записывает строку заголовка, используя переданные `fieldnames`, а `writerows()` записывает сами данные — обратите внимание, что для `DictWriter` заголовок не создаётся автоматически, его нужно вызвать явно.

## Важно: все значения из CSV — строки

Здесь стоит вспомнить прошлый урок про JSON и провести контраст. В отличие от JSON, где типы данных сохраняются автоматически, CSV — обычный текст, и все прочитанные значения, включая числа, приходят в виде строк:

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(type(row["age"]))
        # <class 'str'>
```

Если значение нужно использовать как число, преобразование типа, как и при разборе обычного текста в уроке 47, придётся выполнять вручную.

## Свой разделитель: параметр delimiter

Иногда в CSV-файлах вместо запятой используется другой разделитель — например, точка с запятой. Это особенно часто встречается в файлах, экспортированных из русскоязычного Excel: в российских региональных настройках запятая служит десятичным разделителем (`3,14`), поэтому для разделения столбцов Excel берёт точку с запятой. Задать нужный разделитель можно параметром `delimiter`:

```python
import csv

with open("data.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file, delimiter=";")

    for row in reader:
        print(row)
```

Параметр `delimiter` принимают и `DictReader`, и `writer`, и `DictWriter`.

## CSV, Excel и кодировка

Когда CSV-файлы создаются или открываются в Excel, кодировка снова даёт о себе знать. Два типичных случая:

* **Файл из русскоязычного Excel** (обычный «CSV (разделитель — точка с запятой)») чаще всего сохранён в кодировке cp1251. Если прочитать его с `encoding="utf-8"`, получите `UnicodeDecodeError` или «кракозябры» — в таком случае указывайте `encoding="cp1251"`.
* **Файл «CSV UTF-8», сохранённый в Excel**, начинается с невидимого служебного символа (BOM). Прочитанный через `encoding="utf-8"`, он испортит имя первого столбца: вместо `name` ключ окажется `'﻿name'`, и `row["name"]` вызовет `KeyError`. Для таких файлов используется кодировка `utf-8-sig` — она убирает этот символ при чтении.

Обратная ситуация: если вы создаёте CSV из Python, чтобы его открыли двойным щелчком в Excel, русский текст в UTF-8 без BOM Excel может показать «кракозябрами». Запись с `encoding="utf-8-sig"` решает и эту проблему. Для файлов, которые читают программы, достаточно обычного `utf-8`.

## Разбор задачи: анализ успеваемости

Разберём задачу: дан CSV-файл с оценками студентов, нужно посчитать средний балл каждого и сохранить результат в новый CSV-файл.

### Подготовка исходных данных

Для практики нам понадобится файл `grades.csv`. Создайте его рядом с программой и скопируйте в него следующий текст — заголовок и шесть студентов, по три оценки у каждого:

```text
name,grade_1,grade_2,grade_3
Егор,4,5,4
Мария,5,5,4
Дмитрий,3,4,3
Анна,5,5,5
Иван,2,3,3
Ольга,4,4,5
```

Сохраните файл в кодировке UTF-8. Если не хочется копировать вручную, файл можно создать кодом — запись и чтение пойдут в одной кодировке:

```python
data = """name,grade_1,grade_2,grade_3
Егор,4,5,4
Мария,5,5,4
Дмитрий,3,4,3
Анна,5,5,5
Иван,2,3,3
Ольга,4,4,5
"""

with open("grades.csv", "w", newline="", encoding="utf-8") as file:
    file.write(data)
```

### Решение

```python
import csv


def load_students(filename):
    with open(filename, "r", newline="", encoding="utf-8") as file:
        reader = csv.DictReader(file)
        return list(reader)


def calculate_average(student):
    grades = [int(student["grade_1"]), int(student["grade_2"]), int(student["grade_3"])]
    return round(sum(grades) / len(grades), 2)


def save_report(filename, report):
    with open(filename, "w", newline="", encoding="utf-8") as file:
        writer = csv.DictWriter(file, fieldnames=["name", "average"])
        writer.writeheader()
        writer.writerows(report)


def main():
    students = load_students("grades.csv")

    report = []
    for student in students:
        report.append({"name": student["name"], "average": calculate_average(student)})

    save_report("report.csv", report)
    print("Отчёт сохранён")


main()
```

Как и в прошлых уроках, задача разбита на понятные, самостоятельные функции: `load_students()` отвечает только за чтение, `calculate_average()` вообще не подозревает о существовании файлов — она просто получает словарь и возвращает число (и именно здесь оценки, пришедшие из CSV строками, превращаются в числа через `int()`), а `save_report()` отвечает только за запись. Такое разделение уже должно быть для вас привычным по прошлым двум урокам.

## Итоги урока

CSV — простой текстовый формат для табличных данных, каждая строка которого соответствует строке таблицы, а значения разделены запятой (или другим символом через параметр `delimiter`). Как у любого текстового файла, у CSV есть кодировка: в `open()` указываем `encoding="utf-8"`, а для файлов из Excel помним про `cp1251` и `utf-8-sig`. При открытии CSV-файла нужно указывать `newline=""`, чтобы не появлялись лишние пустые строки. `csv.reader()`/`csv.writer()` работают со списками, а `csv.DictReader()`/`csv.DictWriter()` — со словарями, используя заголовок как ключи, и на практике применяются чаще. В отличие от JSON, все значения, прочитанные из CSV, — строки, и преобразование типов, если оно нужно, выполняется вручную.

Этим уроком завершается разбор трёх текстовых форматов данного блока — в следующем уроке мы соберём файлы, JSON и CSV в одной цельной практической программе.
