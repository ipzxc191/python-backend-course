# Урок 23. Универсальный цикл for i in range(len(list)). Функция enumerate()

В прошлом уроке `for` показал себя во всей красе — перебор списка без единого индекса, коротко и понятно. Но у этого удобства есть скрытая цена, и в этом уроке мы её обнаружим: окажется, что просто перебирать значения недостаточно, если нужно эти значения менять.

## Проблема: for по значениям не позволяет изменить список

Допустим, нужно удвоить каждое число в списке. Интуитивно кажется, что можно сделать так же, как мы перебирали список в прошлом уроке:

```python
numbers = [1, 2, 3, 4, 5]

for number in numbers:
    number = number * 2

print(numbers)   # [1, 2, 3, 4, 5] — список не изменился!
```

Список остался прежним, хотя внутри цикла мы честно умножали `number` на 2 на каждом шаге. Разгадка в том, как на самом деле работает `for`: на каждой итерации переменная `number` получает **копию** значения из списка — это самостоятельная переменная, которая никак не связана с самим списком после того, как значение в неё скопировано. Присваивание `number = number * 2` меняет только эту отдельную переменную, а исходный список, из которого значение было скопировано, эта операция не затрагивает вообще.

## Решение: перебор по индексу

Чтобы действительно изменить список, нужно обращаться не к копии значения, а к самому списку по индексу — точно так же, как мы это делали в уроках про `while`, только теперь получая индексы через `range(len(...))`:

```python
numbers = [1, 2, 3, 4, 5]

for i in range(len(numbers)):
    numbers[i] = numbers[i] * 2

print(numbers)   # [2, 4, 6, 8, 10] — теперь изменился по-настоящему
```

Здесь `i` пробегает все допустимые индексы списка — от `0` до `len(numbers) - 1` — и на каждом шаге мы напрямую обращаемся к элементу списка по этому индексу и заменяем его новым значением. `numbers[i] = ...` — это уже не работа с отдельной копией, а изменение самого списка на месте, точно так же, как мы делали методами `append()`/`insert()` в уроке 16.

Эта конструкция — `for i in range(len(список)):` — настолько часто встречается в реальном коде, что заслуживает отдельного названия: **универсальный цикл по индексу**. Он открывает доступ сразу к двум вещам одновременно: к позиции элемента (через `i`) и, через `список[i]`, к самому значению — а значит, позволяет не только читать, но и изменять список во время перебора.

## enumerate(): индекс и значение вместе, без len()

Часто внутри цикла нужен и индекс, и значение сразу — например, чтобы вывести список с порядковыми номерами. Писать `numbers[i]` каждый раз, когда и так есть под рукой сам список, немного избыточно. Для таких случаев существует функция `enumerate()`, которая на каждом шаге сразу отдаёт пару значений — индекс и элемент — не заставляя обращаться к списку по индексу отдельно:

```python
fruits = ["яблоко", "банан", "апельсин"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

```
0 яблоко
1 банан
2 апельсин
```

Обратите внимание на запись `for index, fruit in enumerate(fruits):` — сразу две переменные через запятую. `enumerate()` на каждом шаге возвращает пару значений (технически это называется кортеж — с этим типом данных мы познакомимся отдельно и подробнее в одном из следующих модулей), и Python сразу же раскладывает эту пару по двум переменным: первая переменная получает индекс, вторая — само значение.

Сравните ту же задачу без `enumerate()`, через `range(len(...))`:

```python
fruits = ["яблоко", "банан", "апельсин"]

for i in range(len(fruits)):
    print(i, fruits[i])
```

Результат абсолютно тот же, но с `enumerate()` не пришлось ни разу писать `fruits[i]` — значение уже готово во второй переменной цикла. Если внутри цикла нужен только индекс для изменения списка (как в примере с удвоением чисел), `range(len(...))` остаётся уместным. Но если нужны сразу оба — и позиция, и значение, — `enumerate()` избавляет от лишнего обращения по индексу.

## enumerate() с произвольным началом отсчёта

По умолчанию `enumerate()` начинает счёт индексов с нуля — точно так же, как индексируются сами списки. Но если результат предназначен для показа человеку (например, пронумерованный список в меню), привычнее начинать с единицы. Для этого у `enumerate()` есть необязательный второй аргумент `start`:

```python
fruits = ["яблоко", "банан", "апельсин"]

for number, fruit in enumerate(fruits, start=1):
    print(f"{number}. {fruit}")
```

```
1. яблоко
2. банан
3. апельсин
```

Обратите внимание: `start=1` меняет только то, с какого числа начинается счёт при выводе, — на реальные индексы списка (которые по-прежнему начинаются с нуля внутри самого Python) это никак не влияет.

## Итоги урока

`for` по значениям списка удобен для чтения, но не позволяет изменить сам список — переменная цикла получает лишь копию значения, и её изменение никак не затрагивает исходный список. Чтобы изменить список во время перебора, используется `for i in range(len(список)):` — цикл по индексу, дающий прямой доступ к элементам через `список[i]`. Функция `enumerate()` даёт индекс и значение одновременно, избавляя от необходимости обращаться к списку по индексу отдельно там, где изменение списка не требуется, а нужны сразу оба — позиция и значение. Необязательный параметр `start` у `enumerate()` позволяет начать нумерацию не с нуля, а с любого удобного числа.
