# Урок 31. Методы словарей: keys(), values(), items(), get()

В прошлом уроке мы работали со словарём напрямую по ключам — либо зная их заранее, либо рискуя нарваться на `KeyError`. Сегодня разберём набор методов, которые дают более удобный и безопасный доступ к содержимому словаря целиком.

## keys(): все ключи словаря

Метод `keys()` возвращает все ключи словаря:

```python
person = {"name": "Олег", "age": 25, "city": "Москва"}
print(person.keys())
# dict_keys(['name', 'age', 'city'])
```

Результат — не совсем обычный список, а специальный объект `dict_keys`, но для большинства задач с ним можно работать так же, как со списком, — в частности, перебирать циклом `for` (с циклами по словарям мы подробно разберёмся в следующем уроке) или, при необходимости, превратить в настоящий список функцией `list()`:

```python
person = {"name": "Олег", "age": 25, "city": "Москва"}
keys_list = list(person.keys())
print(keys_list)   # ['name', 'age', 'city']
```

## values(): все значения словаря

Метод `values()` возвращает все значения, без ключей:

```python
person = {"name": "Олег", "age": 25, "city": "Москва"}
print(person.values())
# dict_values(['Олег', 25, 'Москва'])
```

## items(): пары «ключ, значение» одновременно

Метод `items()` возвращает сразу и ключи, и значения — в виде пар, очень похожих на те, что возвращал `enumerate()` в уроке 23 (там были пары «индекс, значение», здесь — «ключ, значение»):

```python
person = {"name": "Олег", "age": 25, "city": "Москва"}
print(person.items())
# dict_items([('name', 'Олег'), ('age', 25), ('city', 'Москва')])
```

С `items()` мы ещё не раз встретимся в следующем уроке, когда будем перебирать словарь циклом — именно этот метод даёт возможность получить ключ и значение одновременно, на каждом шаге перебора, без необходимости дополнительно обращаться к словарю по ключу.

## get(): безопасное обращение к ключу

Вот, пожалуй, самый практически полезный метод этого урока. Мы уже знаем, что обращение к несуществующему ключу через квадратные скобки вызывает ошибку:

```python
person = {"name": "Олег", "age": 25}
print(person["city"])
# KeyError: 'city'
```

Метод `get()` решает эту проблему: если ключ существует, он возвращает соответствующее значение, а если нет — возвращает `None` вместо того, чтобы останавливать программу с ошибкой:

```python
person = {"name": "Олег", "age": 25}

print(person.get("name"))   # Олег
print(person.get("city"))   # None
```

Более того, `get()` принимает необязательный второй аргумент — значение по умолчанию, которое будет возвращено вместо `None`, если ключа нет:

```python
person = {"name": "Олег", "age": 25}
print(person.get("city", "Не указан"))   # Не указан
```

## Как get() упрощает уже знакомый паттерн

Вспомним задачу из прошлого урока, где мы проверяли наличие ключа перед обращением к нему:

```python
stock = {"хлеб": 12, "молоко": 5, "сыр": 8}
item = "яйца"

if item in stock:
    print("На складе:", stock[item])
else:
    print("Такого товара нет на складе")
```

С помощью `get()` эту же логику можно записать компактнее, без явной проверки `in` и без развёрнутого `if`/`else` (если, конечно, устраивает единое сообщение для случая отсутствия, без отдельной ветки логики):

```python
stock = {"хлеб": 12, "молоко": 5, "сыр": 8}
item = "яйца"

quantity = stock.get(item, "нет в наличии")
print("На складе:", quantity)
```

Это не значит, что `get()` всегда полностью заменяет `if`/`in` — если после проверки наличия ключа нужно выполнить какую-то более сложную, отдельную логику (не просто вернуть значение по умолчанию), явная проверка `in` по-прежнему остаётся уместной. Но там, где нужно просто безопасно получить значение, не рискуя упасть с `KeyError`, — `get()` короче и readable.

## Итоги урока

`keys()` возвращает все ключи словаря, `values()` — все значения, `items()` — пары «ключ, значение» одновременно, по аналогии с парами, которые давал `enumerate()`. `get(ключ)` безопасно обращается к значению по ключу, возвращая `None` вместо ошибки `KeyError`, если ключа нет; `get(ключ, значение_по_умолчанию)` позволяет задать собственное значение на случай отсутствия ключа, вместо `None`.

В следующем уроке мы разберём самое важное с практической точки зрения — перебор словаря циклом, включая случай, когда значением словаря является список.
