# Урок 13. Экранирование символов. Спецсимволы

Это короткий, технический урок, но пропустить его нельзя: без него часть кода, который вы уже видели или ещё увидите — в частности, в следующем уроке про форматирование строк — будет выглядеть как необъяснимая магия из символов обратного слэша. Разберёмся, что это такое.

## Проблема: как записать кавычку внутри строки

Строка в Python заключается в кавычки — но что делать, если сама кавычка должна быть частью текста? Например, если нужно вывести фразу с кавычками внутри:

```python
text = "Он сказал "привет""
# SyntaxError: invalid syntax
```

Python не может понять, где заканчивается строка, потому что вторая кавычка, стоящая перед словом «привет», выглядит для интерпретатора точно так же, как и та, что должна закрывать всю строку целиком. Получается путаница, и код просто не запускается.

## Решение 1: использовать разные виды кавычек

Мы уже знаем, что Python допускает и одинарные, и двойные кавычки. Самый простой способ решить проблему выше — обернуть строку в кавычки одного вида, а кавычки внутри текста написать другим видом:

```python
text = 'Он сказал "привет"'
print(text)   # Он сказал "привет"
```

Здесь внешние кавычки — одинарные, а кавычки внутри текста — двойные, и никакого конфликта не возникает: Python видит только одинарные кавычки как границы строки, а двойные внутри просто становятся обычными символами текста.

## Решение 2: экранирование символом `\`

Второй способ работает даже тогда, когда нужны именно те же кавычки, что и снаружи, — с помощью **экранирования**. Перед символом, который нужно «спрятать» от обычной роли, ставится обратный слэш `\`:

```python
text = "Он сказал \"привет\""
print(text)   # Он сказал "привет"
```

Обратный слэш перед кавычкой говорит Python: «эта кавычка — не граница строки, а обычный символ текста». Это и называется экранированием — символ теряет свою обычную специальную роль и становится просто частью содержимого строки.

## Специальные символы: \n и \t

Экранирование используется не только для кавычек — с его же помощью записываются символы, которые вообще нельзя ввести напрямую как обычный текст: перевод на новую строку и табуляция.

`\n` — переход на новую строку:

```python
text = "Первая строка\nВторая строка"
print(text)
# Первая строка
# Вторая строка
```

Хотя в коде `\n` записан как два символа подряд — обратный слэш и буква `n`, — Python воспринимает их как единый специальный символ перевода строки, а не как два отдельных символа. Убедиться в этом можно через `len()`:

```python
text = "a\nb"
print(len(text))   # 3, а не 4
```

В строке `"a\nb"` всего три символа: `a`, символ перевода строки и `b` — несмотря на то что в исходном коде `\n` занимает два места на экране.

`\t` — символ табуляции, горизонтальный отступ:

```python
text = "Имя:\tИгорь"
print(text)
# Имя:    Игорь
```

## Забегая вперёд: \r

Есть ещё один похожий по духу спецсимвол — `\r` (возврат каретки), который возвращает "курсор" вывода в начало текущей строки, не переходя на новую. Сам по себе, без циклов, он не особенно полезен, но когда мы дойдём до циклов в одном из следующих модулей, именно `\r` станет ключевым инструментом для создания простых анимаций прямо в терминале — например, для индикатора загрузки, обновляющегося на месте, а не печатающего десятки строк подряд. Пока просто запомните, что такой символ существует, — подробно вернёмся к нему позже.

## Экранирование самого обратного слэша: \\

Раз обратный слэш имеет особое значение — он «включает» экранирование, — то как записать в строке сам символ обратного слэша, если он нужен буквально? Точно так же — экранировать его самого себя, поставив перед ним ещё один обратный слэш:

```python
path = "C:\\Users\\Documents"
print(path)   # C:\Users\Documents
```

Это особенно актуально при работе с путями к файлам в Windows, где разделителем директорий как раз служит обратный слэш. Каждый одиночный `\` в желаемом результате нужно записать в коде как `\\`. В следующем уроке мы разберём ещё один, более удобный способ работать с подобными строками — так называемые сырые строки, — но пока важно понимать именно этот, базовый механизм.

### Частая ловушка: \U в пути Windows

Здесь стоит разобрать конкретную, реальную и очень частую ошибку. Путь к папке пользователя в Windows часто выглядит так: `C:\Users\...`. Если написать его в Python без экранирования, кажется, что должно получиться то же самое, что мы уже видели с безобидными сочетаниями вроде `\d` или `\p`, — но здесь ситуация другая:

```python
path = "C:\Users\Documents"
# SyntaxError: (unicode error) 'unicodeescape' codec can't decode bytes
# in position 2-3: truncated \UXXXXXXXX escape
```

Дело в том, что `\U` (с заглавной буквы) — это не случайный, ничего не значащий символ, а **зарезервированная** escape-последовательность: Python ожидает, что сразу после `\U` пойдут ровно 8 шестнадцатеричных цифр, обозначающих определённый символ Unicode (например, эмодзи или редкую букву). Поскольку после `\U` в слове `Users` идут буквы `sers`, а не 8 hex-цифр, Python не может завершить разбор этой последовательности и останавливается с ошибкой ещё до запуска программы — а не просто "непонимающе" пропускает её, как это было бы с `\p` или `\d`.

Решение то же самое, что мы уже разобрали: экранировать каждый обратный слэш, включая тот, что перед `Users`:

```python
path = "C:\\Users\\Documents"
print(path)   # C:\Users\Documents
```

Эта ошибка — одна из самых частых при первом знакомстве с путями Windows в Python, поэтому полезно один раз чётко понять её причину, а не просто запомнить "всегда экранируй пути".

## Другие escape-последовательности: для общего кругозора

Существует ещё несколько специальных последовательностей, которые вы вряд ли будете использовать часто, но полезно знать об их существовании:

| Последовательность | Значение |
|---|---|
| `\r` | возврат каретки (курсор в начало строки — пригодится с циклами) |
| `\xHH` | символ по его коду в шестнадцатеричной системе (2 цифры) |
| `\uXXXX` | символ Unicode по 4-значному коду |
| `\UXXXXXXXX` | символ Unicode по 8-значному коду (та самая последовательность из примера выше) |
| `\N{ИМЯ}` | символ Unicode по его названию, например `\N{HEART SUIT}` |
| `\a` | звуковой сигнал (в современных терминалах обычно ничего не делает) |

## Итоги урока

кранирование с помощью обратного слэша `\` позволяет включить в строку символ, который иначе имел бы особое значение — например, ту же кавычку, которой обёрнута сама строка. `\n` — специальный символ перевода строки, `\t` — символ табуляции, `\r` — возврат каретки (пригодится позже, с циклами), `\\` — способ записать буквальный обратный слэш. Особенно важно помнить про `\U`, `\u`, `\x` и `\N` — это зарезервированные, а не случайные последовательности, и неверное их использование (например, в неэкранированном пути Windows вида `C:\Users\...`) вызывает `SyntaxError` ещё до запуска программы, а не просто печатается как есть. Несмотря на то что такие последовательности записываются в коде двумя и более символами, Python воспринимает каждую корректную из них как единый символ, что можно проверить через `len()`.

В следующем уроке мы применим эти знания на практике — разберём форматирование строк, f-строки и сырые строки, где экранирование либо становится не нужным, либо, наоборот, играет ключевую роль.
