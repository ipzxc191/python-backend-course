# Урок 46. Функции any(), all(), zip(), zip_longest()

Завершаем блок встроенных функций высшего порядка тремя инструментами. Первые два — `any()` и `all()` — вы будете использовать постоянно, они заменяют собой паттерн с флагом, который мы разбирали в уроке 25. Третий — `zip()` — встречается реже, но необходим, чтобы понимать чужой код, и заодно элегантно решает задачу, которая доставляла нам неудобство ещё в модуле 3.

## any(): истинно ли хотя бы одно значение

`any(последовательность)` возвращает `True`, если хотя бы один элемент последовательности является истинным (обычно — результатом сравнения), и `False`, если ни один:

```python
numbers = [3, 8, -2, 15, 7]
has_negative = any(n < 0 for n in numbers)

print(has_negative)   # True
```

Обратите внимание на то, что передано в `any()` — генераторное выражение из урока 38, без отдельных скобок вокруг него (это допустимо, когда генератор — единственный аргумент функции). Генератор здесь вычисляет `n < 0` для каждого числа по очереди, а `any()` останавливается, как только встречает первое истинное значение, — ей незачем проверять остальные, ответ уже получен.

Вспомним, как эта же задача решалась в уроке 25 — через флаг:

```python
numbers = [3, 8, -2, 15, 7]

found = False
for n in numbers:
    if n < 0:
        found = True
        break

print(found)
```

`any()` делает то же самое в одну строку, без явного цикла, флага и `break`, — ровно тот случай, когда встроенная функция берёт на себя целый паттерн, который раньше приходилось писать вручную.

## all(): истинны ли все значения

`all(последовательность)` возвращает `True`, только если **все** элементы истинны, — если хотя бы один ложен, результат `False`:

```python
ages = [18, 22, 45, 19]
all_adults = all(age >= 18 for age in ages)

print(all_adults)   # True
```

```python
prices = [100, 250, -50, 300]
all_positive = all(price > 0 for price in prices)

print(all_positive)   # False
```

`all()` тоже прекращает проверку досрочно — как только встречает первое ложное значение, дальнейшую проверку она уже не продолжает, результат и так известен.

## any() и all() с обычными списками значений

Не обязательно передавать именно генератор со сравнением — `any()` и `all()` можно применить и напрямую к списку логических значений, или даже к списку чисел (где любое число, кроме `0`, считается истинным, а `0` — ложным, но эту тонкость мы разбирать подробно не будем, ограничившись явными сравнениями):

```python
checks = [True, True, False]
print(any(checks))   # True
print(all(checks))   # False
```

## zip(): объединяем несколько последовательностей поэлементно

Вспомним задачу из урока 23 — два параллельных списка, имена и возрасты, которые приходилось связывать через общий индекс:

```python
names = ["Егор", "Мария", "Дмитрий"]
ages = [25, 30, 22]

for i in range(len(names)):
    print(names[i], ages[i])
```

`zip()` решает эту задачу куда изящнее, связывая элементы нескольких последовательностей по позиции без единого индекса:

```python
names = ["Егор", "Мария", "Дмитрий"]
ages = [25, 30, 22]

for name, age in zip(names, ages):
    print(name, age)
```

```
Егор 25
Мария 30
Дмитрий 22
```

`zip()`, как `map()` и `filter()` из прошлого урока, возвращает ленивый объект — если нужен список пар (кортежей) целиком, его тоже нужно обернуть в `list()`:

```python
names = ["Егор", "Мария"]
ages = [25, 30]

pairs = list(zip(names, ages))
print(pairs)   # [('Егор', 25), ('Мария', 30)]
```

## zip() и словари: удобная связка

Раз `zip()` производит пары, а конструктор `dict()` умеет строить словарь из пар «ключ, значение», их можно скомбинировать в одну строку:

```python
names = ["Егор", "Мария", "Дмитрий"]
ages = [25, 30, 22]

people = dict(zip(names, ages))
print(people)
# {'Егор': 25, 'Мария': 30, 'Дмитрий': 22}
```

## Осторожно: zip() останавливается по самой короткой последовательности

Если переданные последовательности разной длины, `zip()` молча останавливается там, где заканчивается самая короткая из них, — оставшиеся элементы более длинной последовательности просто теряются, без единой ошибки или предупреждения:

```python
names = ["Егор", "Мария", "Дмитрий"]
ages = [25, 30]

for name, age in zip(names, ages):
    print(name, age)
```

```
Егор 25
Мария 30
```

`"Дмитрий"` в вывод не попал вообще — для него просто не нашлось пары в списке возрастов, и `zip()` предпочла тихо остановиться, а не сообщить об этом расхождении явно.

## zip_longest(): что делать, если длины разные

Если нужно сохранить все элементы, даже когда последовательности разной длины, поможет `zip_longest()` из модуля `itertools`. Забегая немного вперёд — модули и импорт мы подробно разберём в одном из следующих модулей курса, а пока просто используем готовую строку импорта:

```python
from itertools import zip_longest

names = ["Егор", "Мария", "Дмитрий"]
ages = [25, 30]

for name, age in zip_longest(names, ages):
    print(name, age)
```

```
Егор 25
Мария 30
Дмитрий None
```

Там, где не хватило значения из более короткой последовательности, `zip_longest()` подставляет `None`. Если вместо `None` нужно какое-то своё значение-заполнитель, его можно указать явно через параметр `fillvalue`:

```python
from itertools import zip_longest

for name, age in zip_longest(names, ages, fillvalue="неизвестно"):
    print(name, age)
```

```
Егор 25
Мария 30
Дмитрий неизвестно
```

## Итоги урока

`any()` возвращает `True`, если хотя бы один элемент последовательности истинен, `all()` — если истинны все; обе функции часто применяются к генераторному выражению и заменяют собой паттерн с флагом из урока 25. `zip()` связывает элементы нескольких последовательностей поэлементно по позиции, устраняя необходимость в общем индексе; результат ленивый, как у `map()`/`filter()`, и его удобно комбинировать с `dict()`. `zip()` останавливается по самой короткой последовательности, молча теряя лишние элементы более длинной; `zip_longest()` из модуля `itertools` решает эту проблему, дополняя недостающие места значением `None` или указанным через `fillvalue`.
