# Урок 19. Цикл while: основы. Счётчики, while True

Начинается третий модуль курса — и, забегая вперёд, самый сложный по восприятию. Если строки, списки и условия давались вам более-менее интуитивно, циклы — это первая тема, где придётся по-настоящему перестроить мышление. Но начнём с самого начала: с того, зачем циклы вообще нужны.

## Зачем нужны циклы

Вспомните задачу из прошлого модуля, где нужно было трижды подряд запросить у пользователя название товара — пришлось буквально скопировать одни и те же три строки кода три раза подряд. А что, если бы товаров было не три, а сто? Копировать одну и ту же строку сто раз — не просто неудобно, а практически нереально.

**Цикл** — это конструкция, которая позволяет выполнить один и тот же блок кода много раз подряд, не дублируя его вручную. В Python есть два основных вида циклов: `while` («пока») и `for` («для каждого»). Мы подробно разберём оба — начнём с `while`, потому что его логика напрямую опирается на то, что вы уже знаете об условиях из модуля 2, а к `for` перейдём чуть позже.

## Синтаксис while

```python
count = 1

while count <= 5:
    print(count)
    count = count + 1
```

```
1
2
3
4
5
```

Разберём это по частям. После `while` идёт условие — точно такое же, как в `if`, возвращающее `True` или `False`. Пока это условие истинно, код внутри цикла (с отступом, ровно как у `if`) выполняется снова и снова. Как только условие становится ложным, цикл останавливается, и выполнение программы продолжается со следующей строки после цикла.

В примере выше происходит следующее: сначала `count` равен 1, условие `count <= 5` истинно, поэтому тело цикла выполняется — печатается `1`, а затем `count` увеличивается до 2. Python снова проверяет условие: `2 <= 5` всё ещё истинно, цикл продолжается. Так происходит, пока `count` не станет равным 6 — тогда `6 <= 5` окажется ложным, и цикл завершится.

## Счётчик — переменная, которая меняется на каждом шаге

Переменную `count` из примера выше называют **счётчиком** — это переменная, которая отслеживает, сколько раз цикл уже выполнился (или до какого значения дошёл), и меняется на каждой итерации. Строка `count = count + 1` — сердце любого счётчика: без неё значение `count` никогда бы не изменилось, и условие `count <= 5` оставалось бы истинным вечно.

## Самая частая ошибка: бесконечный цикл

Вот к чему приводит забытая строка обновления счётчика:

```python
count = 1

while count <= 5:
    print(count)
    # забыли строку count = count + 1
```

Условие `count <= 5` в этом коде никогда не станет ложным, потому что `count` навсегда останется равным 1. Программа будет печатать `1` бесконечно, до тех пор пока её не остановят вручную (или пока не закончится терпение, память компьютера, или и то, и другое). Такая ситуация называется **бесконечным циклом**, и это одна из самых частых и досадных ошибок начинающих: перед тем как запустить любой `while`, стоит явно проверить, что где-то внутри тела цикла условие действительно рано или поздно станет ложным.

## Счётчик может не только увеличиваться

Ничто не заставляет счётчик обязательно расти — он может и уменьшаться, если условие цикла подстроено под это:

```python
count = 5

while count >= 1:
    print(count)
    count = count - 1
```

```
5
4
3
2
1
```

Точно так же счётчик может использоваться не только для подсчёта количества повторений, но и для накопления результата — например, суммы чисел от 1 до 5:

```python
count = 1
total = 0

while count <= 5:
    total = total + count
    count = count + 1

print(total)   # 15
```

Здесь используются сразу две переменные: `count` — счётчик, отслеживающий, на каком числе от 1 до 5 мы сейчас находимся, и `total` — накопитель, который на каждом шаге увеличивается на текущее значение `count`. К моменту, когда цикл завершится, `total` будет содержать сумму всех чисел от 1 до 5.

## Забегая вперёд: while True

Раз уж речь зашла об условии цикла, стоит упомянуть особый, очень распространённый в реальном коде случай — `while True`:

```python
while True:
    print("Это будет повторяться вечно")
```

Условие `True` — это значение, которое всегда истинно, вне зависимости ни от чего, поэтому такой цикл никогда не остановится сам по себе. На первый взгляд это звучит бесполезно — зачем нужен цикл, который в принципе не может закончиться? На деле именно такая конструкция чаще всего используется в реальных программах: для постоянно работающего меню, для программы, которая ждёт команд от пользователя, пока он сам не решит выйти. Но чтобы `while True` был не просто бесконечным циклом, а управляемым инструментом, нужен способ выйти из него изнутри — и этому целиком посвящён следующий урок.

## Итоги урока

Цикл `while` выполняет блок кода снова и снова, пока указанное условие остаётся истинным — синтаксически он устроен так же, как `if`, но проверяет условие заново после каждого выполнения тела. Счётчик — переменная, которая меняется на каждой итерации цикла и в конце концов делает условие ложным, останавливая цикл; забытое обновление счётчика приводит к бесконечному циклу. `while True` — цикл, который никогда не завершится сам по себе, и с ним чаще всего работают через специальный инструмент, о котором пойдёт речь в следующем уроке.

В следующем уроке мы разберём операторы `break` и `continue` — именно они дают возможность управлять циклом изнутри, включая тот самый `while True`, который сегодня остался незавершённым примером.
