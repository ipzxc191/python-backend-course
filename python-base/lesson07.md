# Урок 7. Логический тип Bool. Операторы сравнения

В прошлом уроке мы уже видели `True` и `False` — оператор `in` возвращал одно из этих двух значений, но мы отложили разговор о том, что это такое на самом деле. Пора разобраться. Заодно этот урок — прямой мостик к следующему: без операторов сравнения и без понимания `True`/`False` невозможно объяснить, как программа вообще принимает решения, а именно этим мы займёмся уже в следующем уроке.

## Логический тип: bool

`True` и `False` — это не просто слова, а значения отдельного типа данных, который называется `bool` (сокращение от boolean, «логический»). У этого типа всего два возможных значения — «истина» (`True`) и «ложь» (`False`), больше никаких вариантов не существует.

```python
is_raining = True
is_sunny = False

print(type(is_raining))   # <class 'bool'>
```

Обратите внимание на написание: `True` и `False` пишутся с заглавной буквы — это ключевые слова языка, а не обычные строки. `true` (со строчной буквы) Python не распознает как логическое значение и выдаст ошибку, если попытаться его использовать без кавычек.

## Операторы сравнения

Чтобы получить значение типа `bool`, обычно не пишут `True`/`False` вручную, а сравнивают что-то между собой. Для этого существуют операторы сравнения:

```python
print(5 > 3)     # True
print(5 < 3)     # False
print(5 == 5)    # True
print(5 != 3)    # True
print(5 >= 5)    # True
print(5 <= 4)    # False
```

Каждый из этих операторов возвращает `True` или `False` в зависимости от того, выполняется условие или нет: `>` — больше, `<` — меньше, `>=` — больше или равно, `<=` — меньше или равно, `==` — равно, `!=` — не равно.

## Важно: == это не то же самое, что =

Здесь легко допустить ошибку, особенно на первых порах: `=` (один символ) — это оператор присваивания, с которым мы работаем с самого второго урока, а `==` (два символа подряд) — это оператор сравнения на равенство. Это два совершенно разных оператора с разными задачами, и путать их — одна из самых частых ошибок у новичков:

```python
x = 5     # присваивание: положить 5 в переменную x
x == 5    # сравнение: проверить, равно ли значение x пятёрке
```

Первая строка ничего не проверяет и не возвращает — она изменяет значение переменной. Вторая строка, наоборот, ничего не меняет — она лишь возвращает `True` или `False`, в зависимости от того, что в этот момент хранится в `x`.

## Сравнение строк

Оператор `==` прекрасно работает и со строками — проверяет, совпадают ли они полностью, символ в символ:

```python
name = "Игорь"

print(name == "Игорь")   # True
print(name == "игорь")   # False
```

Обратите внимание на второй пример: `"Игорь"` и `"игорь"` для Python — разные строки, потому что заглавная и строчная буквы — это разные символы. С тем же самым принципом мы уже сталкивались в уроке про переменные, когда говорили, что `total` и `Total` — разные имена.

Операторы `>` и `<` тоже применимы к строкам, хотя используются реже: они сравнивают строки по алфавиту (если точнее — по числовым кодам символов, но для практических целей достаточно думать об этом как об алфавитном порядке):

```python
print("апельсин" > "банан")   # False, потому что "а" идёт раньше "б"
print("яблоко" > "банан")     # True, потому что "я" идёт позже "б"
```

## Логические операторы: and, or, not

Иногда одного сравнения недостаточно — нужно объединить сразу несколько условий. Для этого существуют логические операторы `and`, `or` и `not`.

`and` («и») возвращает `True`, только если оба условия вокруг него истинны одновременно:

```python
age = 20
has_ticket = True

print(age >= 18 and has_ticket)   # True
```

`or` («или») возвращает `True`, если истинно хотя бы одно из двух условий:

```python
is_weekend = False
is_holiday = True

print(is_weekend or is_holiday)   # True
```

`not` («не») переворачивает значение на противоположное — `True` становится `False`, и наоборот:

```python
is_raining = False
print(not is_raining)   # True
```

Эти три оператора можно комбинировать между собой, и мы ещё не раз вернёмся к ним — в частности, при разборе более сложных условий в следующих модулях, где логика проверки бывает многоступенчатой. Пока для нас важно освоить сам принцип: сравнения дают `True`/`False`, а логические операторы позволяют объединять несколько таких сравнений в одно общее условие.

## Итоги урока

`bool` — тип данных ровно с двумя возможными значениями: `True` и `False`. Операторы сравнения (`==`, `!=`, `>`, `<`, `>=`, `<=`) возвращают значение типа `bool` в зависимости от того, выполняется ли условие; они работают как с числами, так и со строками. Важно не путать `=` (присваивание) и `==` (сравнение) — это два разных оператора с разными задачами. Логические операторы `and`, `or` и `not` позволяют объединять несколько условий в одно.
