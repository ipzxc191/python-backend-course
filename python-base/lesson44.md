# Урок 44. Обработка произвольного количества аргументов (*args и **kwargs)

Все функции, которые мы писали до сих пор, принимали строго определённое количество параметров. А что, если заранее не известно, сколько аргументов понадобится передать, — например, функция должна складывать числа, но иногда их два, иногда пять, а иногда пятнадцать? Фиксированный список параметров здесь не подходит. На этот случай в Python есть `*args` и `**kwargs`.

## Проблема: фиксированное количество параметров не гибко

```python
def add_two(a, b):
    return a + b

def add_three(a, b, c):
    return a + b + c
```

Заводить отдельную функцию под каждое возможное количество слагаемых — очевидно плохое решение. Нужен способ принять **любое** количество позиционных аргументов одной функцией.

## *args: произвольное количество позиционных аргументов

Если параметру предшествует одна звёздочка, он собирает **все** переданные позиционные аргументы, сколько бы их ни было, в один кортеж — тот самый тип данных, с которым мы познакомились в модуле 4:

```python
def add_all(*args):
    print(args)
    print(type(args))

add_all(1, 2, 3)
```

```
(1, 2, 3)
<class 'tuple'>
```

Раз `args` — это обычный кортеж, с ним можно делать всё, что мы уже умеем делать с кортежами и вообще с любой перебираемой последовательностью, — например, пройтись по нему циклом и просуммировать:

```python
def add_all(*args):
    total = 0
    for number in args:
        total = total + number
    return total

print(add_all(1, 2, 3))          # 6
print(add_all(10, 20))           # 30
print(add_all(5, 5, 5, 5, 5))    # 25
```

Теперь одна функция одинаково хорошо работает с любым количеством аргументов. Имя `args` — не зарезервированное слово, а лишь общепринятое соглашение (сокращение от arguments); технически можно назвать параметр как угодно, лишь бы перед ним стояла одна звёздочка, — но `*args` настолько распространено, что стоит придерживаться этого имени, чтобы код был понятен другим разработчикам с первого взгляда.

## **kwargs: произвольное количество именованных аргументов

Если параметру предшествуют две звёздочки, он собирает все переданные **именованные** аргументы в словарь, где ключами становятся имена аргументов, а значениями — переданные значения:

```python
def print_profile(**kwargs):
    print(kwargs)
    print(type(kwargs))

print_profile(name="Егор", age=25, city="Москва")
```

```
{'name': 'Егор', 'age': 25, 'city': 'Москва'}
<class 'dict'>
```

Раз `kwargs` — обычный словарь, с ним работает всё, что мы знаем о словарях из модуля 4, включая перебор через `items()`:

```python
def print_profile(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_profile(name="Егор", age=25, city="Москва")
```

```
name: Егор
age: 25
city: Москва
```

Как и с `args`, имя `kwargs` (сокращение от keyword arguments) — общепринятое соглашение, а не обязательное требование языка.

## Комбинирование: обычные параметры, *args и **kwargs вместе

Всё это можно сочетать в одной функции, но с определённым порядком: сначала обычные позиционные параметры, затем `*args`, затем `**kwargs`:

```python
def create_order(customer, *items, **details):
    print("Заказчик:", customer)
    print("Товары:", items)
    print("Детали:", details)

create_order("Егор", "хлеб", "молоко", срочно=True, адрес="ул. Ленина")
```

```
Заказчик: Егор
Товары: ('хлеб', 'молоко')
Детали: {'срочно': True, 'адрес': 'ул. Ленина'}
```

Здесь `customer` получает первый позиционный аргумент как обычно, все следующие позиционные аргументы (`"хлеб"`, `"молоко"`) собираются в `items` в виде кортежа, а именованные аргументы (`срочно=True`, `адрес=...`) собираются в `details` в виде словаря.

## Обратная сторона: распаковка при вызове

Если `*args`/`**kwargs` при объявлении функции **собирают** аргументы, то те же самые звёздочки при вызове функции работают в обратную сторону — **распаковывают** уже готовую последовательность или словарь на отдельные аргументы:

```python
def add_three(a, b, c):
    return a + b + c

numbers = (1, 2, 3)
print(add_three(*numbers))   # 6
```

Здесь `*numbers` разворачивает кортеж на три отдельных позиционных аргумента, как если бы вы написали `add_three(1, 2, 3)` напрямую. Точно так же `**` разворачивает словарь на именованные аргументы:

```python
def greet(name, greeting):
    return f"{greeting}, {name}!"

data = {"name": "Мария", "greeting": "Добрый день"}
print(greet(**data))   # Добрый день, Мария!
```

Здесь важно, чтобы ключи словаря (`"name"`, `"greeting"`) в точности совпадали с именами параметров функции — именно по этому совпадению Python сопоставляет значения словаря с нужными параметрами.

## Затравка на будущее

Здесь стоит честно сказать: настоящая, полная сила `*args` и `**kwargs` раскроется значительно позже в курсе, в теме декораторов, — там эта конструкция окажется практически незаменимой, потому что позволит писать код, который одинаково хорошо работает с абсолютно любой функцией, независимо от того, сколько и каких аргументов та принимает. Сейчас достаточно уверенно понимать сам механизм — он пригодится совсем скоро.

## Итоги урока

`*args` при объявлении функции собирает все переданные позиционные аргументы в кортеж. `**kwargs` собирает все переданные именованные аргументы в словарь. Оба можно сочетать с обычными параметрами в строгом порядке: сначала обычные параметры, затем `*args`, затем `**kwargs`. Те же звёздочки при вызове функции работают в обратную сторону — распаковывают готовый кортеж или список на отдельные позиционные аргументы (`*`), либо словарь на именованные аргументы (`**`).

В следующем уроке мы разберём лямбда-функции и несколько встроенных функций высшего порядка — `map()`, `filter()`, `sorted()`.

## Вопросы для проверки

**1. В какой тип данных собираются аргументы, переданные через `*args`?**

<details>
<summary>Ответ</summary>

В кортеж — тот же самый неизменяемый тип данных, с которым мы познакомились в модуле 4.

</details>

---

**2. В какой тип данных собираются аргументы, переданные через `**kwargs`?**

<details>
<summary>Ответ</summary>

В словарь, где ключами становятся имена именованных аргументов, а значениями — переданные значения.

</details>

---

**3. В каком порядке должны следовать обычные параметры, `*args` и `**kwargs` при объявлении функции?**

<details>
<summary>Ответ</summary>

Сначала обычные позиционные параметры, затем `*args`, затем `**kwargs` — в этом строгом порядке, не наоборот.

</details>

---

**4. Что делает одна звёздочка перед готовым кортежем или списком в момент вызова функции, в отличие от той же звёздочки при объявлении?**

<details>
<summary>Ответ</summary>

При вызове функции звёздочка распаковывает уже готовую последовательность на отдельные позиционные аргументы, тогда как при объявлении функции звёздочка, наоборот, собирает переданные по отдельности аргументы в один кортеж.

</details>
