# Урок 35. Обзор дополнительных типов: frozenset, Counter, OrderedDict

Это короткий, чисто ознакомительный урок — без практики. Цель не в том, чтобы вы начали уверенно использовать эти три типа данных, а в том, чтобы, встретив их однажды в чужом коде или документации, вы не растерялись и примерно понимали, о чём речь. Каждому типу — буквально пара предложений и один демонстрационный пример.

## frozenset: неизменяемое множество

Мы разобрали, что список неизменяем в виде кортежа, а у множества такого «неизменяемого брата» тоже есть аналог — `frozenset`. Это точно такое же множество по своим свойствам (уникальные значения, отсутствие порядка), но, как и кортеж, его нельзя изменить после создания:

```python
numbers = frozenset([1, 2, 2, 3])
print(numbers)   # frozenset({1, 2, 3})

numbers.add(4)
# AttributeError: 'frozenset' object has no attribute 'add'
```

Зачем это может понадобиться: в одном из будущих модулей вы узнаете, что ключами словаря могут быть только неизменяемые типы данных — обычное множество для этого не подходит именно из-за своей изменяемости, а `frozenset`, будучи неизменяемым, подходит. На базовом уровне вам вряд ли придётся использовать этот тип самостоятельно, но полезно знать, что он существует и для чего был придуман.

## Counter: подсчёт количества элементов

`Counter` — не встроенный тип данных, а инструмент из отдельного модуля `collections`, который нужно импортировать. Это специальная разновидность словаря, которая сама, автоматически подсчитывает, сколько раз встречается каждое значение в переданной последовательности — то, что мы до сих пор делали вручную через цикл и словарь-счётчик:

```python
from collections import Counter

letters = Counter("абракадабра")
print(letters)
# Counter({'а': 5, 'б': 2, 'р': 2, 'к': 1, 'д': 1})
```

Без `Counter` эту же задачу пришлось бы решать примерно так, как мы это делали в задаче 8 урока 32, — проверять, есть ли значение в словаре, и либо увеличивать счётчик, либо создавать новую запись. `Counter` берёт всю эту рутину на себя одной строкой.

## OrderedDict: словарь с гарантированным порядком

`OrderedDict` — тоже инструмент из модуля `collections`, представляющий собой словарь, который явно гарантирует, что порядок ключей в нём совпадает с порядком их добавления:

```python
from collections import OrderedDict

data = OrderedDict()
data["первый"] = 1
data["второй"] = 2

print(data)
# OrderedDict([('первый', 1), ('второй', 2)])
```

Здесь стоит сделать важную историческую оговорку: раньше, в старых версиях Python, обычный словарь (`dict`) вообще не гарантировал, что порядок ключей останется таким же, каким они добавлялись, — именно поэтому и появился `OrderedDict` как специальное решение для тех случаев, где порядок был принципиально важен. Начиная с Python 3.7 обычный `dict`, с которым мы работали весь этот модуль, сам по себе уже гарантированно сохраняет порядок добавления ключей — поэтому в современном коде `OrderedDict` используется значительно реже, чем раньше, и в основном встречается либо в старом коде, либо в редких случаях, где нужны его специфические дополнительные методы.

## Итоги урока

`frozenset` — неизменяемая версия множества, применяется там, где нужно множество, которое нельзя случайно изменить (например, если оно должно стать ключом словаря). `Counter` из модуля `collections` автоматически подсчитывает количество вхождений каждого значения в последовательности, избавляя от ручного цикла со словарём-счётчиком. `OrderedDict` — словарь с явно гарантированным порядком ключей; исторически важный инструмент, но в современном Python обычный `dict` уже сам сохраняет порядок добавления, поэтому потребность в `OrderedDict` заметно снизилась. Все три типа стоит уметь узнать в чужом коде — не более того на данном этапе.
