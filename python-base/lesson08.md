# Урок 8. Условный оператор if. Конструкция if-else

Все семь предыдущих уроков программа делала ровно то, что было написано, строка за строкой, без единого выбора. Сегодня это меняется: мы научим программу принимать решения — выполнять один код, если условие истинно, и, возможно, другой код, если оно ложно. Это первый по-настоящему важный момент курса: именно с условий начинается то, что отличает программу от простого списка команд.

## Синтаксис if

```python
age = 20

if age >= 18:
    print("Доступ разрешён")
```

Разберём эту конструкцию по частям. После слова `if` идёт условие — то самое выражение, которое возвращает `True` или `False`, с которым мы работали в прошлом уроке (`age >= 18`). После условия обязательно ставится двоеточие. А дальше, на следующей строке, идёт код, который выполнится **только если условие истинно** — этот код обязательно должен быть сдвинут вправо, то есть иметь отступ.

Если запустить пример выше, программа выведет `"Доступ разрешён"`, потому что `age` равно `20`, а `20 >= 18` — истина. Если бы `age` было равно, скажем, `15`, строка внутри `if` вообще не выполнилась бы, и программа просто ничего бы не вывела.

## Отступы — не украшение, а часть синтаксиса

Здесь стоит остановиться отдельно, потому что это принципиальное отличие Python от многих других языков программирования: отступы (обычно четыре пробела) — это не вопрос стиля или красоты кода, а часть самого синтаксиса языка. Именно отступ определяет, какой код относится к `if`, а какой уже находится вне его:

```python
age = 15

if age >= 18:
    print("Доступ разрешён")
    print("Добро пожаловать")

print("Программа завершена")
```

Первые две строки с `print()` имеют отступ и относятся к `if` — они выполнятся, только если условие истинно. Третья строка `print("Программа завершена")` отступа не имеет, а значит, находится уже вне `if` и выполнится в любом случае — независимо от того, было ли условие истинным.

Если отступ забыть или поставить неправильно, Python не будет ничего домысливать — он остановит программу с ошибкой:

```python
age = 20

if age >= 18:
print("Доступ разрешён")
# IndentationError: expected an indented block
```

Здесь строка после `if` не имеет отступа, хотя обязана его иметь, — и программа не запустится вовсе, даже не начав выполняться.

## Конструкция if-else

Часто нужно не просто выполнить код при истинном условии, а сделать одно при истинном условии и совсем другое — при ложном. Для этого существует `else` («иначе»):

```python
age = 15

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

`else` не принимает собственного условия — он всегда идёт сразу за блоком `if` и выполняется ровно тогда, когда условие в `if` оказалось ложным. У `else`, как и у `if`, обязательно двоеточие, и код внутри него точно так же должен иметь отступ.

Важно понимать, что из пары `if`/`else` выполнится ровно один блок — либо один, либо другой, никогда не оба сразу и никогда ни одного. Пока в этом уроке мы рассматриваем только самый простой вариант — выбор из двух вариантов. Более сложные ситуации, где вариантов больше двух, а условия могут быть вложены друг в друга, мы разберём уже в следующем модуле — конструкцию `elif` и вложенные условия специально оставили за пределами этого урока, чтобы сначала как следует закрепить самый базовый механизм.

## Условие может быть любым выражением, возвращающим bool

Условие внутри `if` не обязано быть простым сравнением — это может быть любое выражение, которое в итоге даёт `True` или `False`, включая всё, что мы разбирали в предыдущих уроках:

```python
fruits = ["яблоко", "банан", "апельсин"]

if "банан" in fruits:
    print("Банан есть в списке")
else:
    print("Банана нет в списке")
```

```python
username = "admin"

if username == "admin":
    print("Здравствуйте, администратор")
else:
    print("Здравствуйте, пользователь")
```

```python
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("Проход разрешён")
else:
    print("Проход запрещён")
```

Все три примера используют то же самое устройство `if`/`else`, просто с разными видами условий — оператор `in` из урока про списки, сравнение строк из прошлого урока, комбинацию условий через `and`. Условный оператор сам по себе прост — сила заключается именно в том, насколько разнообразным может быть условие внутри него.

## Частая ошибка: = вместо ==

Ловушка, о которой уже шла речь в прошлом уроке, особенно легко подстерегает именно внутри `if` — по невнимательности легко написать оператор присваивания вместо оператора сравнения:

```python
age = 18

if age = 18:
    print("Вам ровно 18")
# SyntaxError: invalid syntax
```

Python не позволит запустить такой код вовсе — использование `=` там, где ожидается условие, считается синтаксической ошибкой. Правильный вариант — конечно, `if age == 18:`, с двойным знаком равенства.

## Итоги урока

`if` выполняет блок кода, только если указанное условие истинно; `else`, если он есть, выполняется в противоположном случае. Отступы в Python — не оформление, а часть синтаксиса: именно они определяют, какой код относится к условию, а какой — нет. Условием может быть любое выражение, возвращающее `True` или `False`, включая сравнения, оператор `in`, и комбинации через `and`/`or`/`not`. Из пары `if`/`else` выполняется ровно один блок.

Этим уроком завершается первый модуль курса — в следующем материале вас ждёт итоговая практика, объединяющая всё пройденное: числа, строки, списки, логические значения и условия. А в модуле 2 мы вернёмся к `if` вплотную и разберём его куда более мощные формы — множественный выбор через `elif`, вложенные условия и компактную запись через тернарный оператор.
