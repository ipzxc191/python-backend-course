# Урок 4. Математические функции. Модуль math. Функции print() и input()

До сих пор мы использовали `print()` как само собой разумеющийся инструмент — просто чтобы увидеть, что происходит внутри переменной. Пора разобраться с ним по-настоящему, расширить арсенал математических возможностей и, что важнее всего, научить программу не просто выводить готовые числа, а получать их от человека, который её запускает.

## print() чуть подробнее

Функция `print()` умеет выводить сразу несколько значений за один вызов, если перечислить их через запятую:

```python
name = "Игорь"
age = 25

print("Имя:", name, "Возраст:", age)
# Имя: Игорь Возраст: 25
```

Обратите внимание: между значениями `print()` автоматически подставила пробелы — так происходит по умолчанию. Это поведение можно изменить с помощью необязательного параметра `sep` (от separator — разделитель):

```python
print("2026", "01", "15", sep="-")
# 2026-01-15
```

Есть и ещё один похожий параметр — `end`. Он определяет, что будет напечатано после всех значений вместо привычного перехода на новую строку (по умолчанию `end` равен `"\n"` — символу перевода строки, поэтому каждый следующий `print()` обычно начинает вывод с новой строки):

```python
print("Загрузка", end="...")
print("Готово")
# Загрузка...Готово
```

Пока этого достаточно — оба параметра пригодятся вам не раз, особенно когда вывод нужно оформить аккуратно, без лишних переносов строк.

## Округление: round()

Функция `round()` — ещё один инструмент, доступный сразу, без каких-либо дополнительных действий. Она округляет число до ближайшего целого:

```python
print(round(4.3))    # 4
print(round(4.7))    # 5
```

Если передать вторым аргументом количество знаков после точки, `round()` округлит не до целого, а до заданной точности:

```python
print(round(3.14159, 2))   # 3.14
```

## Модуль math: расширяем возможности

Не всё, что может понадобиться при работе с числами, встроено в Python по умолчанию — иначе язык был бы перегружен сотнями редко используемых функций. Вместо этого дополнительные возможности собраны в отдельные **модули**, которые подключаются только тогда, когда действительно нужны. Модуль — это, по сути, готовый набор инструментов, написанный заранее и просто ожидающий, когда его подключат к вашей программе. Подробно с модулями и с тем, как создавать их самостоятельно, мы познакомимся значительно позже в курсе, а пока нам достаточно знать одно простое правило: чтобы воспользоваться модулем, его нужно импортировать в самом начале файла.

Один из самых полезных модулей для работы с числами называется `math`, и подключается он одной строкой:

```python
import math
```

После этого становятся доступны все функции и константы модуля — обращаться к ним нужно через точку, указывая сначала имя модуля, а затем то, что вам из него нужно:

```python
import math

print(math.sqrt(16))   # 4.0
print(math.pi)          # 3.141592653589793
```

`math.sqrt()` — функция для извлечения квадратного корня, а `math.pi` — не функция, а готовая константа: значение числа π с высокой точностью, которое незачем вычислять или запоминать самому.

```python
import math

radius = 5
area = math.pi * radius ** 2
print(round(area, 2))   # 78.54
```

Обратите внимание на порядок вычисления: `radius ** 2` вычисляется раньше умножения на `math.pi`, потому что возведение в степень имеет более высокий приоритет — этот принцип мы уже разбирали в прошлом уроке, и он точно так же работает, когда в выражении участвуют функции и константы из модулей.

## input(): получаем данные от пользователя

Все примеры до этого момента работали с числами и текстом, которые мы сами прописывали прямо в коде. Но по-настоящему полезная программа обычно должна уметь получать данные от того, кто её запускает, — и для этого существует функция `input()`.

```python
name = input("Как вас зовут? ")
print("Привет,", name)
```

При выполнении этой строки программа останавливается, показывает пользователю текст в скобках (в данном случае — `"Как вас зовут? "`) и ждёт, пока пользователь введёт что-то с клавиатуры и нажмёт Enter. Введённое значение возвращается функцией `input()` и, как в примере выше, может быть сразу сохранено в переменную.

## Главная особенность input(), о которой легко забыть

Вот ключевой момент этого урока: **`input()` всегда возвращает строку**, вне зависимости от того, что именно ввёл пользователь — хоть слово, хоть число.

```python
value = input("Введите число: ")
print(type(value))   # <class 'str'>
```

Даже если пользователь честно ввёл `25`, в переменной `value` окажется не число `25`, а строка `"25"`. На первый взгляд разница может показаться незначительной, но она приводит к вполне реальным ошибкам:

```python
value = input("Введите число: ")   # пользователь вводит 25
result = value + 5
# TypeError: can only concatenate str (not "int") to str
```

Python отказывается складывать строку и число — с его точки зрения это совершенно разные, несовместимые типы данных, и он не станет молча угадывать, что вы имели в виду. Более того, если бы вы попытались «сложить» две строки-числа между собой, ошибки бы не возникло, но результат оказался бы совсем не тем, что вы, скорее всего, ожидали:

```python
a = input("Первое число: ")    # пользователь вводит 2
b = input("Второе число: ")    # пользователь вводит 3
print(a + b)   # 23, а не 5
```

Оператор `+`, применённый к строкам, не складывает числа, а склеивает текст — эту операцию мы подробно разберём в одном из следующих уроков про строки. Здесь же важно другое: `"2" + "3"` даёт `"23"`, и это не ошибка Python, а совершенно предсказуемое поведение — просто не то, которое чаще всего нужно новичку в подобной ситуации.

## Решение: приведение типов

Чтобы превратить строку, полученную от `input()`, в настоящее число, с которым можно производить арифметику, используются уже знакомые вам по своей сути функции `int()` и `float()`:

```python
value = input("Введите число: ")   # пользователь вводит 25
number = int(value)
print(number + 5)   # 30
```

Чаще всего оба шага объединяют в одну строку, оборачивая `input()` сразу в `int()` или `float()`:

```python
age = int(input("Сколько вам лет? "))
print("Через 5 лет вам будет", age + 5)
```

Выбор между `int()` и `float()` зависит от того, какое число вы ожидаете получить: если это может быть дробное значение (например, цена или вес), используйте `float()`, если заведомо целое (например, возраст или количество штук) — `int()`.

Здесь стоит явно предупредить о ещё одной распространённой ошибке: если пользователь введёт что-то, что вообще не является числом, `int()` или `float()` не смогут выполнить преобразование и остановят программу с ошибкой:

```python
number = int(input("Введите число: "))   # пользователь вводит "привет"
# ValueError: invalid literal for int() with base 10: 'привет'
```

Позже в курсе мы разберём, как перехватывать подобные ошибки, чтобы программа не завершалась аварийно из-за некорректного ввода, — а пока просто держите в голове, что `int()` и `float()` доверяют вам ровно настолько, насколько введённая строка действительно похожа на число.

## Итоги урока

`print()` умеет выводить сразу несколько значений и настраивать разделитель между ними (`sep`) и то, что печатается в конце (`end`). Встроенная функция `round()` округляет число до целого или до заданного количества знаков после точки. Модуль `math` расширяет возможности работы с числами — его нужно подключить командой `import math`, после чего его содержимое становится доступно через точку: `math.sqrt()`, `math.pi` и другие. Функция `input()` получает данные от пользователя, но всегда возвращает их в виде строки — чтобы превратить введённое значение в число, его нужно явно обернуть в `int()` или `float()`.
