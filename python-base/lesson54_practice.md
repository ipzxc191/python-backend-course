## Часть 1. Разбор: мини-приложение учёта склада

### Что мы строим

Консольное приложение, в котором:

* **JSON** хранит учётные записи пользователей — список, где у каждого пользователя есть `login` и `password`. Пользователь может войти в программу или зарегистрироваться как новый;
* **CSV** хранит остатки товаров на складе — по одному из пунктов меню программа находит товары, которые заканчиваются;
* **TXT** используется как журнал — в него построчно записывается каждое значимое действие.

Как будет выглядеть работа с программой:

```text
Команда (вход/регистрация/выход): регистрация
Новый логин: anna
Новый пароль: 777
Пользователь зарегистрирован. Теперь выполните вход
Команда (вход/регистрация/выход): вход
Логин: anna
Пароль: 777
Вход выполнен успешно
Команда (анализ/выход): анализ
Требуют пополнения:
  молоко: 3
  масло: 1
Команда (анализ/выход): выход
```

Пока пользователь не вошёл, ему доступны только три команды: `вход`, `регистрация` и `выход`. После входа открывается рабочее меню: `анализ` и `выход`.

### Шаг 0. Подготовка исходных данных

Создайте рядом с будущей программой два файла.

**`users.json`** — два пользователя. Обратите внимание на структуру: это список (JSON-массив), а каждый пользователь в нём — словарь (JSON-объект) с ключами `login` и `password`:

```json

    {"login": "admin", "password": "1234"},
    {"login": "igor", "password": "qwerty"}
```

**`inventory.csv`** — остатки на складе:

Оба файла должны быть сохранены в кодировке UTF-8. Если не хочется создавать их вручную, это можно сделать кодом (запускается один раз, отдельно от программы):

Теперь пишем саму программу. Начнём с подключения модулей:

```python
import json
import csv
```

И дальше будем добавлять функции одну за другой. Каждая отвечает ровно за одну задачу и ничего не знает о меню.

### Шаг 1. Загрузка пользователей

Первая задача — прочитать `users.json` и получить список пользователей. Файл JSON, значит, используем `json.load()`:

```python
def load_users(filename):
    with open(filename, "r", encoding="utf-8") as file:
        return json.load(file)
```

Функция принимает имя файла и возвращает готовый список словарей, например:

```python
[{'login': 'admin', 'password': '1234'}, {'login': 'igor', 'password': 'qwerty'}]
```

Никаких преобразований типов не нужно — JSON сохранил структуру сам (урок 52).

### Шаг 2. Сохранение пользователей

Когда появится регистрация, список пользователей придётся записывать обратно в файл. Это обратная задача — `json.dump()`:

```python
def save_users(filename, users):
    with open(filename, "w", encoding="utf-8") as file:
        json.dump(users, file, indent=4, ensure_ascii=False)
```

`indent=4` сделает файл читаемым, `ensure_ascii=False` — сохранит русские буквы как есть (а значит, `encoding="utf-8"` здесь обязателен).

### Шаг 3. Проверка: существует ли пользователь

Перед регистрацией нужно убедиться, что такого логина ещё нет. Нам нужен ответ «да или нет» на вопрос «есть ли в списке хотя бы один пользователь с этим логином» — отличная задача для `any()` из урока 46:

```python
def user_exists(users, login):
    return any(user["login"] == login for user in users)
```

Внутри `any()` стоит генераторное выражение: для каждого пользователя из списка оно проверяет, совпадает ли его логин с искомым. Как только находится хотя бы один совпавший, `any()` возвращает `True`; если совпадений нет — `False`.

### Шаг 4. Аутентификация

Аутентификация — это проверка, что введённые логин и пароль принадлежат одному и тому же пользователю. Условие чуть сложнее предыдущего: у **одного и того же** пользователя должны совпасть **оба** значения. Поэтому оба сравнения записываем внутри одного `any()`, соединяя их через `and`:

```python
def authenticate(users, login, password):
    return any(user["login"] == login and user["password"] == password for user in users)
```

Почему нельзя проверить логин и пароль двумя отдельными вызовами `user_exists`? Потому что тогда пароль одного пользователя подошёл бы к логину другого. Здесь же проверка идёт по каждому пользователю целиком.

### Шаг 5. Добавление нового пользователя

Функция принимает текущий список, логин и пароль, а возвращает **новый список** с добавленным пользователем:

```python
def add_user(users, login, password):
    return users + [{"login": login, "password": password}]
```

`users + [...]` склеивает исходный список с новым списком из одного элемента — словаря нового пользователя (сложение списков мы разбирали в модуле 1). Сама функция не обращается к файлу и не проверяет, свободен ли логин — это задачи других функций. Запись в файл выполнит `save_users()`, а проверку — `user_exists()`.

> Заметка о безопасности: хранить пароли в открытом виде, как в нашем учебном примере, нельзя в настоящих программах — там их хранят в зашифрованном (хешированном) виде. Для учебной практики такое упрощение допустимо.

### Шаг 6. Загрузка склада

Склад хранится в CSV. Читаем его через `DictReader` — тогда каждая строка станет словарём с ключами `name` и `quantity`:

```python
def load_inventory(filename):
    with open(filename, "r", newline="", encoding="utf-8") as file:
        reader = csv.DictReader(file)
        return list(reader)
```

Не забываем про `newline=""` и про то, что все значения из CSV — строки: `quantity` пока имеет вид `'12'`, а не `12`.

### Шаг 7. Поиск товаров, которые заканчиваются

Задача: из списка товаров оставить те, у которых остаток меньше заданного порога. Именно здесь строка из CSV превращается в число:

```python
def get_low_stock_items(inventory, threshold):
    return [item for item in inventory if int(item["quantity"]) < threshold]
```

Функция работает с обычным списком словарей и не знает ни о каких файлах.

### Шаг 8. Запись в журнал

Журнал — обычный текстовый файл, в который мы дописываем по одной строке. Режим `"a"` добавляет в конец, не стирая прежнее содержимое, а `\n` в конце сообщения (урок 51) переводит строку:

```python
def log_action(message):
    with open("app.log", "a", encoding="utf-8") as file:
        file.write(message + "\n")
```

Все функции готовы. Теперь соберём из них программу.

### Шаг 9. Главная функция: загрузка и состояние

Начало `main()`:

```python
def main():
    users = load_users("users.json")
    current_login = ""

    while True:
        ...
```

Переменная `current_login` хранит логин вошедшего пользователя. Пока никто не вошёл, в ней пустая строка — так мы отличаем состояния «ещё не вошёл» и «уже вошёл». Цикл `while True` (урок 19) будет работать, пока мы не выйдем из него командой `break`.

### Шаг 10. Меню до входа: команда «вход»

Если `current_login` пустая, показываем меню входа. Начнём с команды `вход`:

```python
        if current_login == "":
            command = input("Команда (вход/регистрация/выход): ")

            if command == "вход":
                login = input("Логин: ")
                password = input("Пароль: ")

                if authenticate(users, login, password):
                    current_login = login
                    log_action(f"Вход выполнен: {login}")

                    log_action(f"Неудачная попытка входа: {login}")

```

Если проверка прошла, запоминаем логин в `current_login` — с этого момента программа считает пользователя вошедшим. Успех и неудача записываются в журнал по-разному.

### Шаг 11. Меню до входа: команда «регистрация»

Добавляем следующую ветку к тому же `if command == ...`:

```python
            elif command == "регистрация":
                login = input("Новый логин: ")
                password = input("Новый пароль: ")

                if login == "" or password == "":
                    print("Логин и пароль не могут быть пустыми")
                elif user_exists(users, login):
                    print("Пользователь с таким логином уже существует")
                else:
                    users = add_user(users, login, password)
                    save_users("users.json", users)
                    log_action(f"Зарегистрирован новый пользователь: {login}")
                    print("Пользователь зарегистрирован. Теперь выполните вход")
```

Здесь три случая, проверяемые по порядку: пустые данные, занятый логин и, наконец, успешная регистрация. В успешном случае мы делаем три действия: обновляем список в памяти (`add_user`), сохраняем его в файл (`save_users`) и пишем в журнал.

### Шаг 12. Меню до входа: «выход» и неизвестная команда

Две оставшиеся ветки, а затем `continue`:

```python
            elif command == "выход":
                log_action("Программа завершена")
                break

            else:
                print("Неизвестная команда")

            continue
```

`continue` (урок 20) возвращает выполнение в начало цикла, пропуская всё, что идёт ниже. Это важно: пока пользователь не вошёл, рабочее меню показывать нельзя.

### Шаг 13. Рабочее меню после входа

Сюда выполнение доходит только если `current_login` не пустая:

```python
        command = input("Команда (анализ/выход): ")

        if command == "анализ":
            inventory = load_inventory("inventory.csv")
            low_stock = get_low_stock_items(inventory, 5)

            print("Требуют пополнения:")
            for item in low_stock:
                print(f"  {item['name']}: {item['quantity']}")

            log_action(f"Анализ склада выполнен пользователем: {current_login}")

        elif command == "выход":
            log_action("Программа завершена")
            break

        else:
            print("Неизвестная команда")
```

Для анализа мы последовательно вызываем уже написанные функции: загрузили склад, отобрали товары с остатком меньше 5, вывели их и записали действие в журнал — теперь уже с логином того, кто его выполнил.

### Шаг 14. Полный код программы

Остаётся запустить `main()`. Вот программа целиком:

```python
import json
import csv


def load_users(filename):
    with open(filename, "r", encoding="utf-8") as file:
        return json.load(file)


def save_users(filename, users):
    with open(filename, "w", encoding="utf-8") as file:
        json.dump(users, file, indent=4, ensure_ascii=False)


def user_exists(users, login):
    return any(user["login"] == login for user in users)


def authenticate(users, login, password):
    return any(user["login"] == login and user["password"] == password for user in users)


def add_user(users, login, password):
    return users + [{"login": login, "password": password}]


def load_inventory(filename):
    with open(filename, "r", newline="", encoding="utf-8") as file:
        reader = csv.DictReader(file)
        return list(reader)


def get_low_stock_items(inventory, threshold):
    return [item for item in inventory if int(item["quantity"]) < threshold]


def log_action(message):
    with open("app.log", "a", encoding="utf-8") as file:
        file.write(message + "\n")


def main():
    users = load_users("users.json")
    current_login = ""

    while True:
        if current_login == "":
            command = input("Команда (вход/регистрация/выход): ")

            if command == "вход":
                login = input("Логин: ")
                password = input("Пароль: ")

                if authenticate(users, login, password):
                    current_login = login
                    log_action(f"Вход выполнен: {login}")
                    print("Вход выполнен успешно")
                else:
                    log_action(f"Неудачная попытка входа: {login}")
                    print("Неверный логин или пароль")

            elif command == "регистрация":
                login = input("Новый логин: ")
                password = input("Новый пароль: ")

                if login == "" or password == "":
                    print("Логин и пароль не могут быть пустыми")
                elif user_exists(users, login):
                    print("Пользователь с таким логином уже существует")
                else:
                    users = add_user(users, login, password)
                    save_users("users.json", users)
                    log_action(f"Зарегистрирован новый пользователь: {login}")
                    print("Пользователь зарегистрирован. Теперь выполните вход")

            elif command == "выход":
                log_action("Программа завершена")
                break

            else:
                print("Неизвестная команда")

            continue

        command = input("Команда (анализ/выход): ")

        if command == "анализ":
            inventory = load_inventory("inventory.csv")
            low_stock = get_low_stock_items(inventory, 5)

            print("Требуют пополнения:")
            for item in low_stock:
                print(f"  {item['name']}: {item['quantity']}")

            log_action(f"Анализ склада выполнен пользователем: {current_login}")

        elif command == "выход":
            log_action("Программа завершена")
            break

        else:
            print("Неизвестная команда")


main()
```

## Часть 2. Самостоятельная работа: приложение личных заметок

Теперь ваша очередь собрать приложение аналогичной структуры, но на другом материале.

### Что нужно создать

Консольное приложение для учёта личных заметок. В нём:

* **JSON**-файл `accounts.json` хранит пользователей — список словарей, у каждого пользователя есть `login` и `password`;
* **CSV**-файл `notes.csv` хранит заметки — у каждой есть заголовок (`title`) и категория (`category`);
* **TXT**-файл `notes_app.log` — журнал действий.

### Исходные данные

Создайте два файла в кодировке UTF-8 в папке с программой (вручную или кодом).

`accounts.json`:

```json
[
    {"login": "user1", "password": "secret"}
]
```

`notes.csv`:

```text
title,category
Купить продукты,личное
Отправить отчёт,работа
Записаться к врачу,личное
Подготовить презентацию,работа
Позвонить клиенту,работа
Выбрать подарок,личное
```

Файл журнала создавать не нужно — он появится при первой записи.

### Как должна работать программа

**До входа** программа показывает приглашение `Команда (вход/регистрация/выход): ` и понимает три команды:

* `вход` — запрашивает `Логин: ` и `Пароль: `. Если в `accounts.json` есть пользователь с таким логином и таким паролем, программа печатает `Вход выполнен успешно` и переходит к рабочему меню. Иначе печатает `Неверный логин или пароль` и снова показывает меню входа.
* `регистрация` — запрашивает `Новый логин: ` и `Новый пароль: `. Правила:
  * если логин или пароль — пустая строка, печатается `Логин и пароль не могут быть пустыми`;
  * если пользователь с таким логином уже есть, печатается `Пользователь с таким логином уже существует`;
  * иначе пользователь добавляется в список, **список целиком сохраняется в `accounts.json`**, и печатается `Пользователь зарегистрирован. Теперь выполните вход`. После регистрации пользователь автоматически не входит — ему нужно выполнить команду `вход`.
* `выход` — завершает программу.

Любая другая команда: `Неизвестная команда`.

**После входа** программа показывает приглашение `Команда (показать <категория> / выход): ` и понимает:

* `показать <категория>` (например, `показать работа`) — выводит заголовки всех заметок этой категории, каждый с новой строки и с отступом в два пробела. Если заметок нет, печатает `Заметок в этой категории нет`. Команда считается командой показа, если она начинается с `показать ` (слово и пробел). Название категории — всё, что идёт после этого префикса (подсказка: срез строки).
* `выход` — завершает программу.

Любая другая команда: `Неизвестная команда`.

### Что записывать в журнал

В `notes_app.log` при каждом значимом действии добавляется отдельная строка:

| Событие | Строка журнала |
|---|---|
| успешный вход | `Вход выполнен: user1` |
| неверный логин или пароль | `Неудачная попытка входа: user1` |
| успешная регистрация | `Зарегистрирован новый пользователь: anna` |
| команда `показать` | `Просмотр категории: работа` |
| выход из программы (в любом меню) | `Программа завершена` |

Вместо `user1`, `anna` и `работа` подставляются реальные введённые значения.

### Требования к структуре

Не пишите всё в одном месте. Разбейте программу на функции, каждая из которых решает одну задачу. Рекомендуемый набор:

| Функция | Что делает |
|---|---|
| `load_users(filename)` | читает JSON и возвращает список пользователей |
| `save_users(filename, users)` | записывает список пользователей в JSON с отступами и русскими буквами |
| `user_exists(users, login)` | возвращает `True`, если пользователь с таким логином уже есть |
| `authenticate(users, login, password)` | возвращает `True`, если есть пользователь с таким логином **и** таким паролем |
| `add_user(users, login, password)` | возвращает новый список пользователей, в конце которого добавлен новый |
| `load_notes(filename)` | читает CSV и возвращает список словарей |
| `get_titles_by_category(notes, category)` | возвращает список заголовков заметок указанной категории |
| `log_action(message)` | дописывает строку в журнал |
| `main()` | меню и связывание всех функций |

Все файлы открывайте с `encoding="utf-8"`, CSV — ещё и с `newline=""`.

### Рекомендуемый порядок работы

1. Создайте файлы с исходными данными.
2. Напишите и по отдельности проверьте функции работы с пользователями: загрузите список, проверьте существование и аутентификацию на нескольких логинах.
3. Напишите функции для заметок и проверьте, что `get_titles_by_category(notes, "работа")` возвращает три заголовка.
4. Напишите `log_action()` и убедитесь, что файл журнала создаётся и дополняется.
5. Соберите `main()`: сначала меню до входа (вход, регистрация, выход), затем рабочее меню.
6. Проведите сеанс, как в примере ниже, и сверьте журнал.
