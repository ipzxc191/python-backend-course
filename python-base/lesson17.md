# Урок 17. Тернарный условный оператор

Этим уроком завершается модуль про условия — и завершается он приятно: ничего принципиально нового учить не придётся. Тернарный оператор — это просто более компактная запись того же самого `if`/`else`, с которым вы уже отлично знакомы. Считайте это вишенкой на торте, а не новой сложной темой.

## От развёрнутого if-else к одной строке

Вспомним самый обычный `if`/`else`:

```python
age = 20

if age >= 18:
    status = "совершеннолетний"
else:
    status = "несовершеннолетний"

print(status)
```

Четыре строки кода ради того, чтобы просто выбрать одно из двух значений и положить его в переменную. Тернарный оператор позволяет записать ровно то же самое в одну строку:

```python
age = 20
status = "совершеннолетний" if age >= 18 else "несовершеннолетний"

print(status)
```

Порядок чтения непривычный по сравнению с обычным `if`, но интуитивно понятный, если прочитать его почти как обычную фразу: «`status` равен "совершеннолетний", если `age >= 18`, иначе — "несовершеннолетний"». Общий синтаксис такой:

```
значение_если_истина if условие else значение_если_ложь
```

## Тернарный оператор — это выражение, а не отдельная команда

Важное отличие от обычного `if`/`else`: тернарный оператор — это не самостоятельная конструкция, а выражение, которое можно использовать везде, где ожидается значение, — например, прямо внутри `print()`:

```python
number = 7
print("Чётное" if number % 2 == 0 else "Нечётное")
```

Здесь не пришлось заводить отдельную переменную для промежуточного результата — значение сразу вычисляется и сразу выводится, ровно так же, как если бы вы написали `print("любая строка")` напрямую.

Точно так же тернарный оператор можно использовать внутри f-строки, с которой мы познакомились несколько уроков назад:

```python
age = 15
print(f"Статус: {'совершеннолетний' if age >= 18 else 'несовершеннолетний'}")
```

## Когда стоит использовать, а когда — нет

Тернарный оператор хорош именно там, где выбор простой — одно из двух значений, без дополнительной логики внутри. Как только начинают напрашиваться несколько условий подряд (то, что раньше решалось через `elif`), пытаться втиснуть всё это в тернарный оператор — плохая идея:

```python
score = 82
result = "Отлично" if score >= 90 else "Хорошо" if score >= 75 else "Удовлетворительно" if score >= 60 else "Не сдал"
```

Технически этот код рабочий — тернарные операторы можно вкладывать один в другой, — но читать его сходу практически невозможно, особенно если вернуться к нему через месяц. Здесь развёрнутая цепочка `if`/`elif`/`else` из урока 10 будет однозначно понятнее, даже несмотря на то что займёт больше строк. Правило простое: тернарный оператор — для действительно простого выбора из двух вариантов, а не для замены целой цепочки условий ради формальной краткости.

## Итоги урока

Тернарный оператор (`значение_если_истина if условие else значение_если_ложь`) — это компактная запись обычного `if`/`else` для случаев, когда нужно выбрать одно из двух значений. В отличие от обычного `if`, это выражение, а не отдельная команда — его можно использовать прямо внутри `print()`, f-строк и присваивания переменной. Стоит применять его только для простого выбора из двух вариантов — вложенные друг в друга тернарные операторы быстро становятся нечитаемыми, и в таких случаях лучше использовать полноценную цепочку `if`/`elif`/`else`.
