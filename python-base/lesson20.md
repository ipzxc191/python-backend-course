# Урок 20. Операторы break, continue

В прошлом уроке `while True` остался незакрытым обещанием — циклом, который выглядел полезным, но не имел способа завершиться. Сегодня мы его получаем: операторы `break` и `continue` дают возможность управлять циклом изнутри, а не только через условие в его шапке.

## break: немедленный выход из цикла

`break` останавливает цикл сразу же, полностью, независимо от того, что написано в его условии:

```python
count = 1

while count <= 10:
    if count == 5:
        break
    print(count)
    count = count + 1
```

```
1
2
3
4
```

Хотя условие цикла — `count <= 10` — оставалось бы истинным вплоть до 10, `break` сработал раньше, как только `count` стал равен 5, и цикл завершился досрочно, даже не дойдя до `print(5)`.

## while True + break: главный рабочий паттерн

Теперь мы можем вернуться к `while True` из прошлого урока и наконец сделать его полезным. Идея простая: цикл работает бесконечно, пока внутри него не сработает `break` при определённом условии:

```python
while True:
    command = input("Введите команду (введите 'стоп' для выхода): ")

    if command == "стоп":
        break

    print("Выполняется команда:", command)
```

Такой паттерн — `while True` в связке с `break` внутри — вы будете видеть в реальном коде постоянно, гораздо чаще, чем `while` со сложным условием в шапке. Причина в удобстве: вместо того чтобы заранее придумывать одно составное условие, которое должно предугадать все причины остановки, можно просто написать `while True` и явно, по шагам, указать внутри, при каком именно событии нужно выйти. Это особенно удобно для постоянно работающих программ — меню, ожидания команд пользователя, — где заранее не всегда понятно, каким должно быть условие в шапке цикла.

Обратите внимание и на обратную сторону этого паттерна: если забыть `break` внутри `while True`, цикл действительно останется бесконечным — в точности та же ошибка, о которой шла речь в прошлом уроке применительно к забытому обновлению счётчика.

## continue: пропустить текущий шаг, но не выходить из цикла

`continue` — оператор помягче: он не завершает цикл целиком, а лишь пропускает оставшуюся часть текущей итерации и сразу переходит к следующей проверке условия:

```python
count = 0

while count < 10:
    count = count + 1

    if count % 2 == 0:
        continue

    print(count)
```

```
1
3
5
7
9
```

Здесь при каждом чётном значении `count` строка `print(count)` пропускается — `continue` сразу возвращает выполнение к проверке условия `count < 10`, минуя всё, что написано в теле цикла ниже. В результате печатаются только нечётные числа.

## Ловушка: continue и забытое обновление счётчика

Здесь стоит обратить особое внимание на порядок строк в примере выше — счётчик `count = count + 1` намеренно стоит **до** проверки с `continue`, а не после. Если поменять их местами, получится бесконечный цикл:

```python
count = 0

while count < 10:
    if count % 2 == 0:
        continue
    print(count)
    count = count + 1   # эта строка никогда не выполнится для чётных count!
```

Проследим, что здесь происходит: `count` равен 0, условие `count % 2 == 0` истинно, срабатывает `continue` — и выполнение сразу прыгает обратно к проверке `count < 10`, полностью минуя строку `count = count + 1`, которая находится ниже. А значит, `count` так и остаётся равным 0 навсегда, условие `count % 2 == 0` каждый раз истинно, `continue` срабатывает снова и снова — бесконечный цикл.

Правило, которое стоит вынести из этого примера: если внутри цикла используется `continue`, нужно особенно внимательно следить, чтобы всё, что обязано выполниться на каждой итерации — прежде всего обновление счётчика, — стояло **до** `continue`, а не после него. Так же, как забытое обновление счётчика само по себе может привести к бесконечному циклу, `continue`, расположенный не в том месте, приводит к той же проблеме — просто менее очевидным путём.

## Итоги урока

`break` немедленно и полностью завершает цикл, независимо от его условия. `continue` пропускает только оставшуюся часть текущей итерации и переходит к следующей проверке условия, не завершая цикл целиком. Связка `while True` вместе с `break` — самый распространённый способ организовать цикл, условие остановки которого удобнее описать явно внутри тела цикла, а не в его шапке. При использовании `continue` важно располагать обновление счётчика до него, а не после — иначе легко получить бесконечный цикл, в котором `continue` каждый раз обрывает выполнение раньше, чем счётчик успевает измениться.
