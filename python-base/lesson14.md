# Урок 14. Форматирование строк. F-строки. Сырые строки

Ещё в модуле 1 мы столкнулись с тем, что строку и число нельзя склеить оператором `+` напрямую — приходилось выкручиваться через `print()` с несколькими аргументами через запятую. Это работало, но неудобно, особенно если строка длинная и в неё нужно вставить сразу несколько значений в разных местах. В этом уроке мы разберём куда более удобный способ — f-строки — а заодно вернёмся к экранированию из прошлого урока и увидим, как его можно избежать вовсе.

## Проблема, которую решают f-строки

Вспомним ловушку из модуля 1:

```python
name = "Игорь"
age = 25

print("Меня зовут " + name + ", мне " + age + " лет")
# TypeError: can only concatenate str (not "int") to str
```

Здесь `age` — число, и его нельзя склеить со строкой оператором `+` без явного преобразования в строку. Можно было бы обернуть `age` в `str()`, но при длинной фразе с несколькими вставками такой код быстро становится нечитаемым, с множеством `+` и кавычек вперемешку.

## F-строки: вставляем значения прямо внутрь текста

F-строка — это обычная строка с буквой `f` непосредственно перед открывающей кавычкой, внутри которой в фигурных скобках `{}` можно писать переменные — и они автоматически подставятся в нужное место, независимо от типа:

```python
name = "Игорь"
age = 25

print(f"Меня зовут {name}, мне {age} лет")
# Меня зовут Игорь, мне 25 лет
```

Никакого `+`, никаких `str()` — `age` подставляется как есть, хотя это число, а не строка, и никакой ошибки не возникает. Именно поэтому f-строки — основной, самый распространённый способ вставлять значения в текст в современном Python, и дальше в курсе вы будете видеть их постоянно.

## Внутри фигурных скобок можно писать не только переменные

Фигурные скобки f-строки принимают любое выражение, а не только имя переменной напрямую — включая арифметику, вызовы методов и функций:

```python
price = 199
quantity = 3

print(f"Итого: {price * quantity}")
# Итого: 597
```

```python
word = "python"
print(f"В верхнем регистре: {word.upper()}")
# В верхнем регистре: PYTHON
```

```python
value = 3.14159
print(f"Округлённо: {round(value, 2)}")
# Округлённо: 3.14
```

Всё, что находится внутри `{}`, вычисляется точно так же, как если бы вы написали это выражение в обычном коде, а результат просто подставляется в текст на этом месте.

## Кратко: другие способы форматирования

F-строки — не единственный способ подставлять значения в текст, и в старом коде (а иногда и в новом, для совместимости) вам могут встретиться два других подхода. Разбирать их подробно мы не будем — достаточно уметь их узнать.

Метод `.format()`:

```python
name = "Игорь"
print("Меня зовут {}".format(name))
# Меня зовут Игорь
```

Форматирование через `%`:

```python
name = "Игорь"
print("Меня зовут %s" % name)
# Меня зовут Игорь
```

Оба способа решают в целом ту же задачу, что и f-строки, но менее наглядно и более многословно — f-строки появились в Python позже как раз для того, чтобы сделать эту задачу удобнее, и на сегодня считаются предпочтительным вариантом.

## Сырые строки: r"..."

В прошлом уроке мы разбирали, что путь к файлу в Windows приходится экранировать через двойной обратный слэш: `"C:\\Users\\Documents"`. Если такой путь длинный, обилие `\\` подряд начинает мешать читать код. Python предлагает более удобный способ — сырую строку (raw string), в которой обратный слэш перестаёт быть специальным символом и воспринимается буквально, символ в символ.

Сырая строка создаётся так же, как f-строка, но с буквой `r` перед кавычкой вместо `f`:

```python
path = r"C:\Users\Documents"
print(path)   # C:\Users\Documents
```

Внутри сырой строки `\U`, `\D` и подобные сочетания не воспринимаются Python как что-то особое — экранирования просто не происходит, и каждый символ, включая обратный слэш, остаётся именно тем, чем был написан. Это удобно не только для путей к файлам, но и, забегая немного вперёд, для одной из тем в конце курса — регулярных выражений, где обратный слэш встречается очень часто и постоянно экранировать его вручную было бы утомительно.

Важная деталь: `r` не отменяет действие `\n` или `\t` в буквальном смысле «сделать их снова переводом строки и табуляцией» — наоборот, внутри сырой строки `\n` — это именно два обычных символа, обратный слэш и буква `n`, а вовсе не единый символ перевода строки, как было бы в обычной строке. Сравните:

```python
print("строка1\nстрока2")    # строка1 и строка2 на разных строках
print(r"строка1\nстрока2")   # строка1\nстрока2 — всё на одной строке
```

## Итоги урока

F-строки (`f"..."`) позволяют подставлять значения любого типа прямо внутрь текста через фигурные скобки `{}`, включая произвольные выражения — арифметику, вызовы методов и функций — без необходимости в `+` и явном преобразовании типов. Методы `.format()` и `%`-форматирование решают похожую задачу, но менее удобно, и встречаются в основном в старом коде. Сырая строка (`r"..."`) отключает экранирование — обратный слэш внутри неё воспринимается буквально, что особенно удобно для путей к файлам.

В следующем уроке мы вернёмся к спискам и разберём то же самое, что уже проходили со строками, — срезы и сравнение, только теперь применительно к спискам.
