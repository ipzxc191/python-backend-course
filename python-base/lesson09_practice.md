### Задача 1. Скидка в магазине

Запросите у пользователя сумму покупки. Если сумма превышает 2000, предоставьте скидку 15% и выведите итоговую сумму к оплате, округлённую до двух знаков после запятой. Если сумма 2000 или меньше — скидка не предоставляется, к оплате идёт полная сумма.

**Пример использования**:

```
Введите сумму покупки: 3000
К оплате: 2550.0
```

### Задача 2. Проход на мероприятие

Запросите у пользователя возраст и наличие абонемента (ответ `"да"` или `"нет"`). Проход разрешён, если пользователю есть 18 лет и при этом у него есть абонемент, либо если ему уже есть 21 год (в этом случае абонемент не требуется). Во всех остальных случаях проход запрещён.

**Пример использования**:

```
Введите возраст: 19
Есть абонемент? (да/нет): да
Проход разрешён
```

### Задача 3. Проверка имени

Запросите у пользователя имя. Если длина имени не меньше 2 символов и при этом первый символ имени равен `"А"`, выведите `"Полноценное имя на букву А"`. В противном случае выведите `"Условие не выполнено"`.

**Пример использования**:

```
Введите имя: Анна
Полноценное имя на букву А
```

### Задача 4. Хватит ли бюджета

Дан список цен на три товара. Запросите у пользователя доступный бюджет и посчитайте общую сумму всех трёх товаров (складывая элементы списка по индексам). Если бюджета хватает на все товары — выведите `"Хватает"` и итоговую сумму, иначе — `"Не хватает"` и то, сколько денег не хватает.

```python
prices = [450, 1200, 899]
```

**Пример использования**:

```
Введите бюджет: 2000
Не хватает: 549
```

### Задача 6. Статус участника

Дан список участников закрытого клуба. Запросите у пользователя имя. Выведите `"Статус: VIP"`, если имя есть в списке участников и при этом в клубе состоит меньше 4 человек. В любом другом случае (имени нет в списке, либо клуб уже достаточно большой) выведите `"VIP-статус недоступен"`.

```python
members = ["Олег", "Мария", "Дмитрий"]
```

**Пример использования**:

```
Введите имя: Мария
Статус: VIP
```

### Задача 7. Средний балл

Запросите у пользователя три оценки за экзамены (целые числа). Посчитайте их среднее значение. Если среднее значение больше или равно 4, выведите `"Экзамен сдан хорошо"`, иначе — `"Нужно подтянуть знания"`. Выведите также само среднее значение, округлённое до двух знаков после запятой.

**Пример использования**:

```
Первая оценка: 5
Вторая оценка: 4
Третья оценка: 3
Среднее: 4.0
Экзамен сдан хорошо
```

### Задача 9. Список покупок и бюджет одновременно

Дан список товаров в наличии и их фиксированная цена за штуку — 250. Запросите у пользователя название нужного товара и доступный бюджет. Если товара нет в списке — выведите `"Такого товара нет"`. Если товар есть, но бюджета не хватает даже на одну штуку — выведите `"Не хватает денег"`. Если товар есть и бюджета хватает — выведите `"Можно купить"`. Решить задачу нужно с помощью независимых `if` (без использования `elif` или вложенных конструкций).

```python
available_items = ["хлеб", "молоко", "сыр"]
item_price = 250
```

**Пример использования**:

```
Какой товар нужен: сыр
Ваш бюджет: 300
Можно купить
Товар есть в наличии
```

```
Какой товар нужен: яблоки
Ваш бюджет: 350
Такого товара нет
```

### Задача 10. Регистрация пользователя

Запросите у пользователя имя, возраст и город. Регистрация считается успешной, если возраст не меньше 18 и город находится в списке разрешённых городов. Сначала отдельно проверьте и сообщите о каждой из возможных причин отказа (недостаточный возраст; город вне списка разрешённых, если с возрастом всё в порядке), а в конце — если обе проверки пройдены — выведите приветственное сообщение с именем пользователя.

```python
allowed_cities = ["Москва", "Санкт-Петербург", "Казань"]
```

**Пример использования**:

```
Введите имя: Артём
Введите возраст: 17
Введите город: Москва
Причина отказа: недостаточный возраст
```
