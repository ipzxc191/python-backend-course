# Урок 15. Срезы списков. Сравнение списков

Хорошая новость: почти всё, что мы разобрали про срезы строк несколько уроков назад, работает у списков точно так же, символ в символ — точнее, элемент в элемент. В этом уроке мы быстро перенесём эти знания на списки, а заодно увидим, что сравнение списков подчиняется ровно тому же принципу, что мы уже видели на строках в уроке 7, — просто на этот раз в его самом общем, явном виде.

## Срезы списков работают так же, как срезы строк

В модуле 1 мы ограничились обращением к списку только по одному положительному индексу. Теперь, по аналогии со строками, добавляем: отрицательные индексы, срезы, шаг.

```python
fruits = ["яблоко", "банан", "апельсин", "груша", "манго"]

print(fruits[-1])    # манго — последний элемент
print(fruits[1:3])   # ['банан', 'апельсин']
print(fruits[:2])    # ['яблоко', 'банан']
print(fruits[-2:])   # ['груша', 'манго']
print(fruits[::-1])  # ['манго', 'груша', 'апельсин', 'банан', 'яблоко']
```

Все правила, разобранные для строк, действуют без изменений: конечный индекс среза не включается в результат, срез с выходом за границы списка не вызывает ошибку (в отличие от обычного индекса), а срез с шагом `-1` разворачивает список в обратном порядке. Единственное отличие — результатом среза списка становится не строка, а новый список:

```python
numbers = [10, 20, 30, 40, 50]
print(type(numbers[1:3]))   # <class 'list'>
```

Раз правила те же самые, стоит для практики один раз явно вспомнить, чем обычный индекс отличается от среза по поведению при выходе за границы:

```python
numbers = [10, 20, 30]

print(numbers[10])
# IndexError: list index out of range

print(numbers[10:20])
# [] — пустой список, а не ошибка
```

## Списки изменяемы — в отличие от строк

Здесь стоит сказать пару слов о том, что нам ещё предстоит подробно разобрать в следующем уроке. В отличие от строк, которые в Python неизменяемы, списки можно менять после создания — добавлять, удалять и заменять элементы прямо в исходном списке, без необходимости создавать новый и переприсваивать переменную. Пока просто держите это в голове — с конкретными инструментами для изменения списков мы познакомимся уже в следующем уроке.

## Сравнение списков

Списки можно сравнивать между собой, и работает это не как что-то новое, а как прямое продолжение того, что мы уже видели на строках в уроке 7. Оператор `==` проверяет, полностью ли совпадают списки — одинаковое количество элементов, одинаковые значения и одинаковый порядок — точно так же, как `==` для строк проверял посимвольное совпадение:

```python
list_a = [1, 2, 3]
list_b = [1, 2, 3]
list_c = [3, 2, 1]

print(list_a == list_b)   # True — совпадают полностью
print(list_a == list_c)   # False — те же числа, но другой порядок
```

Обратите внимание на второй пример: `list_a` и `list_c` содержат одни и те же числа, но `==` вернул `False`, потому что порядок элементов другой. Для списков порядок имеет значение при сравнении, а не только сам набор значений.

Здесь стоит явно сформулировать общий принцип, который мы до сих пор видели только на частных примерах: **сравнение составных типов данных в Python всегда зависит от элементов внутри них и от их порядка** — будь то строка (сравниваются символы по порядку) или список (сравниваются элементы по порядку). Это не два разных правила для двух разных типов, а одно и то же правило, применённое к разным видам последовательностей.

Списки можно сравнивать и через `>`/`<` — и это снова ровно тот же принцип, что и алфавитное сравнение строк из урока 7: поэлементно, слева направо, до первого различия:

```python
print([1, 2, 3] < [1, 2, 4])   # True — до третьего элемента списки совпадают, а 3 < 4
print([1, 5, 0] < [1, 2, 100]) # False — уже на втором элементе 5 не меньше 2
```

Python сравнивает списки элемент за элементом: как только находится первая пара элементов, которая отличается, именно она и определяет результат всего сравнения — точно так же, как при сравнении слов по алфавиту сравнение останавливается на первой несовпадающей букве.

## Итоги урока

Срезы списков используют абсолютно тот же синтаксис и те же правила, что и срезы строк: отрицательные индексы, диапазон `[начало:конец:шаг]`, отсутствие ошибки при выходе за границы, разворот через `[::-1]` — с единственной разницей в том, что результатом среза списка становится новый список, а не строка. Списки, в отличие от строк, изменяемы — подробнее об этом в следующем уроке. Сравнение списков через `==`, `>` и `<` работает по тому же общему принципу, что мы уже видели на строках в уроке 7: поэлементно, с учётом порядка, до первого различия, — это не новое правило, а универсальный для составных типов данных в Python подход к сравнению.

В следующем уроке мы наконец разберём методы списков — инструменты для добавления, удаления и изменения элементов, ради которых списки и оказываются настолько полезнее строк в задачах, где данные должны меняться по ходу работы программы.
