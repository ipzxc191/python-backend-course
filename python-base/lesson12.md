# Урок 12. Основные методы строк

До сих пор всё, что мы делали со строками, приходилось собирать вручную — через срезы, конкатенацию, отдельные индексы. Но у строк в Python есть большой набор готовых, уже написанных инструментов для самых частых операций: привести текст к одному регистру, убрать лишние пробелы, найти подстроку, разбить строку на части. Эти инструменты называются методами, и сегодняшний урок — про них.

## Что такое метод и чем он отличается от функции

До этого момента мы работали с функциями вроде `len()` или `print()` — им передаётся значение внутри круглых скобок, и функция что-то с ним делает. Метод устроен немного иначе: он «принадлежит» самому значению и вызывается через точку, сразу после этого значения:

```python
word = "Python"
print(word.upper())   # PYTHON
```

Здесь `upper()` — это метод, который вызывается прямо на строке `word` через точку, а не берёт эту строку в скобках как аргумент, подобно тому, как это делает `len(word)`. Разница в записи может показаться незначительной, но синтаксис `значение.метод()` вы будете видеть постоянно на протяжении всего курса — не только со строками, но и почти с любым типом данных в Python.

## Строки неизменяемы: важное правило перед тем, как мы начнём

Прежде чем разбирать конкретные методы, нужно проговорить одно фундаментальное свойство строк: строки в Python **неизменяемы**. Это значит, что ни один метод не меняет исходную строку — вместо этого каждый метод, что-то преобразующий, возвращает **новую** строку, а старая остаётся нетронутой:

```python
word = "python"
word.upper()
print(word)   # python — ничего не изменилось!
```

Это одна из самых частых ошибок новичков: вызвать метод и ожидать, что переменная сама изменится. Так не работает — результат нужно обязательно сохранить, например переприсвоив той же переменной:

```python
word = "python"
word = word.upper()
print(word)   # PYTHON — теперь изменилось, потому что мы переприсвоили переменную
```

Держите это правило в голове на протяжении всего урока: если вы вызвали метод, но не использовали его результат — то есть не вывели его, не сохранили в переменную и не передали куда-то ещё, — этот вызов был бесполезен.

## Изменение регистра: upper(), lower()

```python
word = "Python"

print(word.upper())   # PYTHON
print(word.lower())   # python
```

`upper()` переводит все буквы в верхний регистр, `lower()` — в нижний. Один из самых частых сценариев использования — сравнение строк без учёта регистра, с которым мы уже сталкивались в модуле 1:

```python
answer = input("Ваш ответ: ")

if answer.lower() == "да":
    print("Принято")
```

Здесь `answer.lower()` приводит введённый пользователем текст к нижнему регистру перед сравнением — и тогда `"Да"`, `"ДА"` и `"да"` все одинаково будут распознаны как согласие, вместо того чтобы требовать от пользователя ввести ответ строго определённым образом.

## Удаление лишних пробелов: strip()

Метод `strip()` убирает пробелы (а заодно и переводы строк) в начале и в конце строки, не трогая пробелы внутри неё:

```python
text = "   привет   "
print(text.strip())   # "привет"
```

Этот метод особенно полезен при работе с данными, введёнными пользователем, — люди часто случайно добавляют лишний пробел в начале или в конце, и без `strip()` такая строка не совпадёт при сравнении с ожидаемым значением, даже если по смыслу это то же самое слово.

## Замена части строки: replace()

```python
text = "Привет, мир!"
print(text.replace("мир", "Python"))   # Привет, Python!
```

`replace(что_искать, на_что_заменить)` заменяет все вхождения первой подстроки на вторую по всей строке — не первое найденное, а сразу все:

```python
text = "кот кот кот"
print(text.replace("кот", "пёс"))   # пёс пёс пёс
```

## Разбиение строки на список: split()

Метод `split()` разбивает строку на части по указанному разделителю и возвращает результат в виде списка — того самого типа данных, с которым мы уже знакомы по модулю 1:

```python
text = "яблоко,банан,апельсин"
fruits = text.split(",")
print(fruits)   # ['яблоко', 'банан', 'апельсин']
```

Если вызвать `split()` вовсе без аргумента, строка разбивается по любому количеству пробелов подряд — это самый частый способ использования этого метода:

```python
sentence = "Python это просто"
words = sentence.split()
print(words)   # ['Python', 'это', 'просто']
```

Раз результатом `split()` становится список, к нему сразу применимо всё, что мы знаем про списки из первого модуля — `len()`, обращение по индексу, оператор `in`:

```python
sentence = "мама мыла раму"
words = sentence.split()

print(len(words))    # 3
print(words[0])       # мама
print("раму" in words)   # True
```

## Обратная операция: join()

Если `split()` разбивает строку на список, то `join()` делает противоположное — собирает список строк обратно в одну строку, вставляя между элементами заданный разделитель. У этого метода необычный порядок записи, который стоит запомнить отдельно: `join()` вызывается не на списке, а на строке-разделителе, а список передаётся ей как аргумент:

```python
words = ["Python", "это", "просто"]
sentence = " ".join(words)
print(sentence)   # Python это просто
```

Здесь `" "` (строка из одного пробела) — это тот разделитель, который будет вставлен между элементами списка, а сам список `words` передаётся в скобках. Многие интуитивно ожидают, что писать нужно `words.join(" ")` — то есть вызывать метод на списке, — но это не так, и подобная ошибка выдаст `AttributeError`, потому что у списков попросту нет метода `join()`. Запомнить правильный порядок проще всего так: `join()` — это метод той строки, которая станет «клеем» между элементами, а не метод самого списка.

```python
fruits = ["яблоко", "банан", "апельсин"]
print(", ".join(fruits))   # яблоко, банан, апельсин
```

## Поиск подстроки: find()

Метод `find()` ищет подстроку внутри строки и возвращает индекс её первого вхождения — или `-1`, если подстрока не найдена:

```python
text = "Python это просто"

print(text.find("это"))    # 7
print(text.find("Java"))   # -1
```

Отдельно возвращаемое значение `-1` при отсутствии совпадения стоит запомнить — это не ошибка и не `None`, а именно число `-1`, и его нужно явно проверять, если нужно узнать, найдена ли подстрока вообще:

```python
text = "Python это просто"

if text.find("Java") == -1:
    print("Слово не найдено")
```

## Проверка начала и конца строки: startswith(), endswith()

Эти два метода возвращают `True` или `False` в зависимости от того, начинается или заканчивается ли строка на указанную подстроку:

```python
filename = "report.pdf"

print(filename.startswith("report"))   # True
print(filename.endswith(".pdf"))       # True
print(filename.endswith(".docx"))      # False
```

Такие проверки особенно удобны в связке с `if`, потому что и сами возвращают готовое логическое значение — не нужно дополнительно оборачивать их в сравнение с `-1`, как в случае с `find()`:

```python
filename = "photo.jpg"

if filename.endswith(".jpg") or filename.endswith(".png"):
    print("Это изображение")
else:
    print("Неизвестный формат файла")
```

## Проверка содержимого строки: isdigit(), isalpha(), isspace()

Иногда нужно не найти что-то внутри строки, а проверить, из чего вообще состоит сама строка, — например, состоит ли она только из цифр. Для этого есть отдельная группа методов, возвращающих `True` или `False`.

```python
print("12345".isdigit())   # True
print("12a45".isdigit())   # False
```

Обратите внимание: `isdigit()` проверяет **всю** строку целиком — результат будет `True`, только если **все** символы строки являются цифрами, а не только часть из них.

Похожим образом работает `isalpha()` — проверяет, что строка состоит только из букв:

```python
print("Python".isalpha())    # True
print("Python3".isalpha())   # False — есть цифра
```

И `isspace()` — проверяет, что строка состоит только из пробельных символов:

```python
print("   ".isspace())    # True
print("  a ".isspace())   # False
```

Эти же методы прекрасно работают и с одним отдельным символом строки, полученным по индексу, — самый частый сценарий использования на практике:

```python
word = "5apples"
print(word[0].isdigit())   # True — первый символ цифра
print(word[1].isdigit())   # False — второй символ буква
```

### Зачем это нужно уже сейчас

У нас пока нет инструмента для перехвата ошибок (с `try`/`except` мы познакомимся значительно позже, в отдельном модуле курса), поэтому если нужно заранее убедиться, что введённая пользователем строка вообще является числом, прежде чем передавать её в `int()`, `isdigit()` — ровно то, что нужно:

```python
age_text = input("Введите возраст: ")

if age_text.isdigit():
    age = int(age_text)
    print("Вам", age, "лет")
else:
    print("Это не похоже на число")
```

Без такой проверки `int(age_text)` привёл бы к ошибке `ValueError`, если бы пользователь ввёл что-то нечисловое, — а `isdigit()` позволяет предусмотреть эту ситуацию заранее и отреагировать на неё самостоятельно, а не ждать аварийного завершения программы.

Небольшая оговорка на будущее: `isdigit()` возвращает `False` для отрицательных чисел (строка `"-5"` содержит символ `-`, который цифрой не является) и для дробных чисел (символ `.` тоже не цифра) — для большинства простых задач начального уровня этого достаточно, а более надёжные способы проверки мы рассмотрим позже в курсе.

### Другие похожие методы: для общего кругозора

Методов такого рода в Python довольно много, и разбирать каждый подробно смысла нет — но полезно хотя бы знать об их существовании, чтобы не растеряться, встретив один из них в чужом коде:

| Метод | Проверяет / делает |
|---|---|
| `isupper()` | все буквы строки — заглавные |
| `islower()` | все буквы строки — строчные |
| `isalnum()` | строка состоит только из букв и цифр |
| `istitle()` | каждое слово строки начинается с заглавной буквы |
| `title()` | (преобразование) делает первую букву каждого слова заглавной |
| `capitalize()` | (преобразование) делает заглавной только первую букву всей строки |
| `zfill(ширина)` | (преобразование) дополняет строку нулями слева до нужной длины |

## Итоги урока

Методы вызываются через точку сразу после значения (`строка.метод()`), в отличие от функций, куда значение передаётся в скобках. Строки в Python неизменяемы — ни один метод не меняет исходную строку, а возвращает новую, которую нужно сохранить или использовать явно. `upper()`/`lower()` меняют регистр, `strip()` убирает пробелы по краям, `replace()` заменяет все вхождения подстроки, `split()` разбивает строку на список, `join()` — обратная операция, собирающая список обратно в строку, `find()` ищет подстроку и возвращает индекс или `-1`, а `startswith()`/`endswith()` сразу возвращают `True`/`False` для проверки начала и конца строки. `isdigit()`, `isalpha()` и `isspace()` проверяют, из каких символов состоит строка (или один её символ, полученный по индексу) — целиком из цифр, букв или пробелов соответственно, что особенно полезно для предварительной проверки данных до появления в курсе `try`/`except`. Существует и ряд других похожих методов (`isupper()`, `title()` и другие) — с ними полезно быть знакомым хотя бы поверхностно.
