# Урок 24. Примеры задач, решаемых с помощью цикла for

Новой теории в этом уроке не будет — только практика. Сначала разберём несколько задач вместе, обращая внимание не столько на код, сколько на ход мысли: что именно мы перебираем и что делаем на каждом шаге перебора. А дальше — большой самостоятельный банк задач на все варианты `for`, которые мы прошли: простой перебор значений, перебор по индексу для изменения списка, `enumerate()`.

## Разбор примера 1: сумма чётных чисел в списке

**Что перебираем**: каждое число в списке по очереди.
**Что делаем на каждом шаге**: проверяем, чётное ли число; если да — прибавляем его к накопителю суммы.

```python
numbers = [3, 8, 12, 5, 20, 7, 14]
total = 0

for number in numbers:
    if number % 2 == 0:
        total = total + number

print(total)   # 54
```

Обратите внимание на структуру: переменная-накопитель (`total`) заводится **до** цикла, с нулевого («пустого») значения, а внутри цикла только пополняется — этот паттерн вы уже видели в уроке про `while`, и он абсолютно так же работает и в `for`.

## Разбор примера 2: самое длинное слово в предложении

**Что перебираем**: каждое слово из предложения, полученное через `split()`.
**Что делаем на каждом шаге**: сравниваем длину текущего слова с длиной уже найденного «рекордсмена»; если текущее слово длиннее — оно становится новым рекордсменом.

```python
sentence = "Python это простой и одновременно очень мощный язык"
words = sentence.split()

longest = words[0]

for word in words:
    if len(word) > len(longest):
        longest = word

print(longest)   # одновременно
```

Этот паттерн — «завести переменную с начальным предположением, а затем сравнивать с ней каждый следующий элемент» — мы уже применяли в уроке 22 для поиска наибольшего числа. Здесь та же самая логика, просто сравниваются не сами значения, а их длины.

## Разбор примера 3: собираем новый список по условию

**Что перебираем**: каждое число в исходном списке.
**Что делаем на каждом шаге**: если число положительное — добавляем его в новый, отдельный список; если нет — просто пропускаем.

```python
numbers = [5, -3, 8, -12, 0, 17, -1]
positive_numbers = []

for number in numbers:
    if number > 0:
        positive_numbers.append(number)

print(positive_numbers)   # [5, 8, 17]
```

Это ещё один очень частый паттерн: не менять исходный список, а собрать из него новый, отфильтрованный по условию. Пустой список-накопитель заводится до цикла (так же, как `total` в первом примере), а `append()` внутри цикла постепенно его наполняет.
