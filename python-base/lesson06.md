# Урок 6. Списки: первое знакомство

Строка хранит текст — но что, если нужно сохранить не один элемент, а сразу много: список покупок, имена участников встречи, оценки за неделю? Держать для этого отдельную переменную под каждое значение было бы неудобно и совершенно не масштабируется. Для таких случаев в Python существует список — и именно с ним мы сегодня познакомимся, тоже пока в ограниченном объёме, оставив срезы и методы списков на следующий модуль.

## Что такое список

Список (`list`) — это упорядоченный набор значений, объединённых под одним именем. Создаётся список с помощью квадратных скобок, а элементы внутри перечисляются через запятую:

```python
fruits = ["яблоко", "банан", "апельсин"]
```

В список можно положить не только строки, но и числа, и даже значения разных типов одновременно — список не заставляет все свои элементы быть одного типа:

```python
mixed = ["Игорь", 25, "Москва"]
```

Вывести список целиком можно уже привычным способом:

```python
print(fruits)
# ['яблоко', 'банан', 'апельсин']
```

## Длина списка: len()

Функция `len()`, уже знакомая нам по строкам, точно так же работает и со списками — только теперь она считает не символы, а количество элементов:

```python
fruits = ["яблоко", "банан", "апельсин"]
print(len(fruits))   # 3
```

## Обращение к элементу по индексу

Списки, как и строки, поддерживают обращение к отдельному элементу по индексу, и работает это по тому же самому принципу, который мы разобрали в прошлом уроке: отсчёт начинается с нуля, а не с единицы.

```python
fruits = ["яблоко", "банан", "апельсин"]

print(fruits[0])   # яблоко
print(fruits[2])   # апельсин
```

`fruits[0]` — это первый элемент списка, а не «нулевой»; `fruits[2]` — третий и последний элемент в списке из трёх штук. Обращение к индексу, которого не существует, приводит к точно такой же ошибке, что и со строками:

```python
fruits = ["яблоко", "банан", "апельсин"]
print(fruits[3])
# IndexError: list index out of range
```

Индекса `3` в списке из трёх элементов не существует — последний доступный индекс здесь равен `2`, то есть `len(fruits) - 1`, ровно как и в случае со строками.

## Проверка на вхождение: оператор in

Часто нужно узнать не сам элемент по индексу, а просто выяснить, есть ли в списке определённое значение вообще. Для этого существует оператор `in`:

```python
fruits = ["яблоко", "банан", "апельсин"]

print("банан" in fruits)     # True
print("груша" in fruits)     # False
```

Результатом оператора `in` всегда становится одно из двух значений — `True` («истина», значение найдено) или `False` («ложь», значение не найдено). Что именно представляют собой `True` и `False` как тип данных, мы подробно разберём уже в следующем уроке — а пока достаточно того, что `in` — это удобный способ проверить список на присутствие нужного значения, не перебирая все элементы вручную и не разбираясь с индексами.

Обратите внимание: `in` ищет полное совпадение значения, а не часть его. Если бы список содержал строку `"бананы"` (во множественном числе), проверка `"банан" in fruits` вернула бы `False` — потому что `"банан"` и `"бананы"` для Python — это два совершенно разных значения, а не одно значение, «похожее» на другое.

## Итоги урока

Список — это упорядоченный набор значений под одним именем, создаваемый с помощью квадратных скобок. `len()` для списка возвращает количество элементов, а обращение по индексу в квадратных скобках работает так же, как у строк — с отсчётом от нуля и с ошибкой `IndexError` при выходе за границы. Оператор `in` проверяет, присутствует ли значение в списке, и возвращает `True` или `False`.

В следующем уроке мы разберём логический тип данных — то, чем на самом деле являются `True` и `False` — и операторы сравнения, которые тоже возвращают такие значения.
