# Урок 45. Лямбда-функции. Функции map(), filter(), sorted(). Доп: параметр key, функция reduce()

До сих пор каждая функция, которую мы писали, получала имя через `def` и жила в коде отдельной, самостоятельной строкой. Сегодня мы познакомимся с функциями без имени — лямбда-функциями, — а заодно с несколькими встроенными функциями, которые принимают другие функции в качестве аргумента.

## Лямбда-функции: функция без имени, в одну строку

Лямбда-функция — это короткая, безымянная функция, объявляемая в одну строку с помощью ключевого слова `lambda`:

```python
square = lambda number: number ** 2

print(square(5))   # 25
```

Сравните это с полноценным объявлением через `def`:

```python
def square(number):
    return number ** 2
```

Обе записи делают одно и то же, но у `lambda` другой синтаксис: после `lambda` перечисляются параметры (без скобок), затем двоеточие, а затем — одно-единственное выражение, результат которого автоматически становится возвращаемым значением, без явного `return`. Лямбда-функция не может содержать несколько строк кода, циклы или условные операторы в развёрнутом виде — только одно выражение (хотя внутри этого выражения вполне можно использовать уже знакомый тернарный оператор, если нужно ветвление).

Присваивать лямбда-функцию переменной, как в примере выше, — не самое частое её применение на практике. Куда чаще лямбда-функции создаются прямо на месте, как аргумент для другой функции, — именно с этим мы сейчас и познакомимся.

## map(): применить функцию к каждому элементу

`map(функция, последовательность)` применяет переданную функцию к каждому элементу последовательности и возвращает результат применения ко всем элементам:

```python
numbers = [1, 2, 3, 4, 5]
squared = map(lambda n: n ** 2, numbers)

print(squared)          # <map object at 0x...>
print(list(squared))    # [1, 4, 9, 16, 25]
```

Обратите внимание на то, что вывелось при первом `print()` — не готовый список, а объект `map`. Это не случайность: `map`, как и генераторное выражение из урока 38, вычисляет значения лениво, по требованию, а не сразу все целиком. Чтобы получить готовый список, результат нужно явно обернуть в `list()` — точно так же, как мы делали с `range()` в уроке 26.

`map()` полностью заменяет собой генератор списка без условия, разобранный в уроке 28, — оба подхода делают одно и то же:

```python
numbers = [1, 2, 3, 4, 5]

squared_map = list(map(lambda n: n ** 2, numbers))
squared_comprehension = [n ** 2 for n in numbers]

print(squared_map)            # [1, 4, 9, 16, 25]
print(squared_comprehension)  # [1, 4, 9, 16, 25]
```

Какой из двух вариантов использовать — вопрос личного вкуса и читаемости в конкретной ситуации; многие Python-разработчики предпочитают генератор списка как более наглядный, но `map()` вы будете регулярно встречать в чужом коде.

## filter(): оставить только подходящие элементы

`filter(функция, последовательность)` оставляет только те элементы, для которых переданная функция вернула `True`:

```python
numbers = [3, 8, 12, 5, 20, 7, 14]
even_numbers = filter(lambda n: n % 2 == 0, numbers)

print(list(even_numbers))   # [8, 12, 20, 14]
```

Точно так же, как и `map()`, `filter()` возвращает не готовый список, а специальный ленивый объект, который нужно обернуть в `list()`, чтобы получить его содержимое целиком. И точно так же `filter()` дублирует возможности генератора списка с условием из урока 28:

```python
numbers = [3, 8, 12, 5, 20, 7, 14]

even_filter = list(filter(lambda n: n % 2 == 0, numbers))
even_comprehension = [n for n in numbers if n % 2 == 0]
```

## sorted(): сортировка без изменения исходных данных

В уроке 16 мы разбирали метод `.sort()`, который сортирует список **на месте**, изменяя сам исходный список. `sorted()` — отдельная, самостоятельная функция, которая работает иначе: она **не меняет** переданную последовательность, а возвращает совершенно новый, отсортированный список:

```python
numbers = [5, 2, 8, 1, 9]
sorted_numbers = sorted(numbers)

print(sorted_numbers)   # [1, 2, 5, 8, 9]
print(numbers)          # [5, 2, 8, 1, 9] — исходный список не изменился
```

Это важное отличие стоит запомнить: `.sort()` — метод, доступный только у списков, меняющий их на месте и ничего не возвращающий (мы разбирали это как ловушку ещё в уроке 16). `sorted()` — функция, работающая с любой перебираемой последовательностью, включая строки и кортежи, и всегда возвращающая новый список, оставляя оригинал нетронутым:

```python
word = "питон"
print(sorted(word))   # ['и', 'н', 'о', 'п', 'т'] — список отсортированных букв
```

## Параметр key: сортировка по собственному правилу

Самая частая причина использовать `sorted()` вместо простого `.sort()` — параметр `key`, позволяющий задать, **по какому критерию** сортировать элементы, если сортировка по ним самим не подходит:

```python
words = ["кот", "программирование", "дом", "сад"]
sorted_by_length = sorted(words, key=len)

print(sorted_by_length)
# ['кот', 'дом', 'сад', 'программирование']
```

Здесь `key=len` говорит: «при сравнении элементов ориентируйся не на сами строки, а на результат применения `len()` к ним» — то есть сортируй по длине слова, а не по алфавиту. `key` может принимать и лямбда-функцию, если нужен более сложный критерий:

```python
people = [("Олег", 25), ("Мария", 19), ("Дмитрий", 32)]
sorted_by_age = sorted(people, key=lambda person: person[1])

print(sorted_by_age)
# [('Мария', 19), ('Олег', 25), ('Дмитрий', 32)]
```

Здесь `key=lambda person: person[1]` говорит Python сравнивать не сами кортежи целиком, а только вторые элементы каждого из них — возраст.

Добавить сортировку по убыванию можно уже знакомым параметром `reverse=True`, точно так же, как и у метода `.sort()` из урока 16:

```python
sorted_by_age_desc = sorted(people, key=lambda person: person[1], reverse=True)
```

## Дополнение: key встречается не только в sorted()

Параметр `key` — не уникальная особенность `sorted()`, та же идея встречается и в других встроенных функциях, например в `max()` и `min()`:

```python
words = ["кот", "программирование", "дом"]
longest = max(words, key=len)

print(longest)   # программирование
```

Здесь `max()` с параметром `key=len` находит не наибольшую по алфавиту строку, а строку с наибольшей длиной — тот же самый принцип «сравнивай не сами элементы, а результат применения функции к ним», просто применённый к поиску максимума, а не к сортировке.

## Дополнение: функция reduce()

Последнее, что стоит здесь упомянуть, — функция `reduce()` из модуля `functools`. В отличие от `map()` и `filter()`, она не встроена напрямую в язык, а требует импорта, и решает несколько иную задачу: последовательно «сворачивает» всю последовательность в одно итоговое значение, применяя функцию к накопленному результату и очередному элементу поочерёдно:

```python
from functools import reduce

numbers = [1, 2, 3, 4]
product = reduce(lambda acc, n: acc * n, numbers)

print(product)   # 24
```

Мы не будем разбирать `reduce()` подробно — в подавляющем большинстве случаев такую же задачу удобнее и понятнее решить обычным циклом с переменной-накопителем, как мы делали множество раз на протяжении курса. Достаточно знать, что такой инструмент существует и что его можно встретить в чужом коде.

## Итоги урока

Лямбда-функция — короткая, безымянная функция из одного выражения, чаще всего создаваемая прямо на месте как аргумент для другой функции. `map()` применяет функцию к каждому элементу последовательности, `filter()` оставляет только подходящие элементы — обе возвращают ленивый объект, требующий `list()` для материализации, и обе дублируют возможности генераторов списков из урока 28. `sorted()`, в отличие от метода `.sort()`, не меняет исходную последовательность, а возвращает новый отсортированный список и работает с любой перебираемой последовательностью, а не только со списком. Параметр `key` задаёт критерий сортировки (или поиска максимума/минимума через `max()`/`min()`) и часто передаётся в виде лямбда-функции. `reduce()` из модуля `functools` сворачивает последовательность в одно значение, но на практике для этой задачи чаще используют обычный цикл с накопителем.
