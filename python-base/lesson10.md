# Урок 10. Вложенные условия и множественный выбор (if-elif-else)

В итоговой практике первого модуля несколько задач специально решались обходными путями — через объединённые условия с `and`/`or` или через череду независимых `if` подряд, — потому что настоящего инструмента для этого у нас ещё не было. Сегодня этот инструмент появляется: `elif` и вложенные условия. С этого момента ни один из тех обходных путей больше не понадобится — а заодно вы увидите, насколько естественнее становится решение той же самой задачи.

## Множественный выбор: elif

`if`/`else` даёт только два исхода — либо одно, либо другое. Но реальные ситуации часто предполагают куда больше двух вариантов: не «сдал / не сдал», а «отлично / хорошо / удовлетворительно / не сдал». Для этого существует `elif` (сокращение от «else if» — «иначе если»):

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Не сдал")
```

`elif` идёт между `if` и `else`, может повторяться сколько угодно раз, и у каждого `elif`, в отличие от `else`, есть собственное условие. Работает эта цепочка так: Python проверяет условия по порядку сверху вниз и выполняет код только у **первого** условия, которое оказалось истинным — все остальные `elif` и `else` после этого просто пропускаются, даже если их условия тоже были бы истинны.

Это последнее замечание стоит проверить на практике, потому что оно объясняет частую ошибку новичков:

```python
score = 95

if score >= 60:
    print("Удовлетворительно")
elif score >= 75:
    print("Хорошо")
elif score >= 90:
    print("Отлично")
```

При `score = 95` эта программа выведет `"Удовлетворительно"` — хотя формально верны сразу все три условия (95 действительно больше и 60, и 75, и 90). Но Python останавливается на первом же истинном условии сверху, а первое условие здесь — `score >= 60`, оно и срабатывает. Правильный порядок — от самого строгого условия к самому нестрогому, как и было в первом примере урока: сначала проверяем `>= 90`, и только если это не подошло, спускаемся ниже. **Порядок условий в цепочке `elif` имеет значение**, и об этом легко забыть.

## Вложенные условия

Иногда одно условие имеет смысл проверять только внутри другого — то есть второй `if` физически находится внутри блока первого:

```python
age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Проход разрешён")
    else:
        print("Нужен документ, удостоверяющий личность")
else:
    print("Вход только с 18 лет")
```

Здесь проверка `has_id` вообще не имеет смысла, если возраст меньше 18 — зачем спрашивать про документ у человека, которому и так нельзя войти? Именно для таких ситуаций, где одно условие логически подчинено другому, а не просто идёт с ним «в паре» через `and`, вложенность оказывается уместнее и понятнее, чем попытка втиснуть всё в одно длинное составное условие.

Сравните с тем, как эту же задачу пришлось бы решать одним условием через `and`, теряя возможность дать пользователю точное, разное сообщение в зависимости от причины отказа:

```python
age = 20
has_id = True

if age >= 18 and has_id:
    print("Проход разрешён")
else:
    print("Проход запрещён")   # но по какой причине — непонятно
```

Оба варианта рабочие, но у них разная цель: объединённое условие подходит, когда важен только конечный результат («пропустить или нет»), а вложенность — когда важно различить, по какой именно причине что-то пошло не так, и сообщить об этом отдельно.

## Возвращаемся к задаче из прошлого модуля

В итоговой практике модуля 1 была задача про регистрацию пользователя, где для двух разных причин отказа (недостаточный возраст, неподходящий город) пришлось писать три независимых `if` подряд, чтобы обойтись без вложенности. Теперь, с `elif` и вложенными условиями в арсенале, эта же задача решается прямее:

```python
allowed_cities = ["Москва", "Санкт-Петербург", "Казань"]

age = 17
city = "Москва"

if age < 18:
    print("Регистрация невозможна: недостаточный возраст")
elif city not in allowed_cities:
    print("Регистрация невозможна: город вне зоны обслуживания")
else:
    print("Регистрация прошла успешно")
```

`elif` здесь заменяет вложенный `if` внутри `else`, делая код более плоским и читаемым: Python проверит `age < 18`, и если это ложно, перейдёт к следующему условию `city not in allowed_cities`, а если и оно ложно — выполнит `else`. По смыслу это ровно то же самое, что вложенность (`if ...: ... else: if ...: ... else: ...`), но записанное без лишнего сдвига вправо на каждом уровне.

Здесь стоит явно проговорить, когда лучше `elif`, а когда — настоящая вложенность: `elif` подходит, когда варианты взаимоисключающие и находятся как бы «на одном уровне» (либо один возраст не подошёл, либо, если с возрастом всё в порядке, не подошёл город). Вложенность лучше подходит, когда второе условие имеет смысл только как уточнение внутри первого, а не как альтернатива ему — как в примере с проверкой документа, где вопрос о документе вообще не встаёт, если возраст не подошёл.

## Итоги урока

`elif` позволяет проверить несколько условий по очереди в рамках одной цепочки `if`/`elif`/`else` — выполнится код только у первого истинного условия, а порядок условий имеет значение, особенно при проверке диапазонов. Вложенные условия — это `if` внутри другого `if`, уместные тогда, когда одно условие логически подчинено другому, а не просто идёт с ним в паре. И `elif`, и вложенность решают задачи, которые в модуле 1 приходилось обходить через составные условия или череду независимых `if` — теперь для этого есть куда более прямые и читаемые инструменты.

В следующем уроке мы вернёмся к строкам и наконец разберём то, что было сознательно отложено в первом модуле — срезы и отрицательные индексы.
