# Практикум. Словари, строки и функции: собираем всё вместе

Каждую тему по отдельности вы уже проходили: словари, строки, циклы, функции. Но на практике они почти никогда не встречаются по одной. Настоящие задачи требуют **соединить** несколько знаний сразу — и именно на этом месте большинство людей застревает. Этот материал — не новая тема, а «карта», которая показывает, как всё, что вы знаете, собирается в одно целое.

## Куда мы идём и зачем

Программисту постоянно приходится работать с данными, которые приходят в виде **обычного текста**: строка из `input()`, содержимое текстового файла, ответ сайта. Вот пример такого «сырого» текста:

```python
products_text = """
молоко, 3, 89.9
хлеб, 10, 45
сыр, 2, 420.5
масло, 5, 180
"""
```

Для компьютера это просто одна длинная строка. Посчитать по ней общую стоимость, найти самый дорогой товар или отфильтровать то, что заканчивается, очень неудобно. А вот так те же данные выглядят после преобразования:

```python
[
    {"name": "молоко", "quantity": 3, "price": 89.9},
    {"name": "хлеб", "quantity": 10, "price": 45.0},
    {"name": "сыр", "quantity": 2, "price": 420.5},
    {"name": "масло", "quantity": 5, "price": 180.0}
]
```

Это список словарей. С такой структурой всё просто: к любому значению можно обратиться по имени (`product["price"]`), числа — настоящие числа, а все инструменты циклов и условий работают сразу.

**Главная цель этого материала — научиться превращать сырой текст в удобные структуры данных**, а затем оформлять это превращение в функции. Путь, который мы пройдём, можно записать цепочкой типов:

```text
str  →  list[str]  →  list[list[str]]  →  list[dict]
```

Что здесь происходит:

1. Сначала у нас одна большая строка (`str`).
2. Мы делим её на строки по одной (`list[str]`).
3. Каждую из этих строк делим на отдельные значения — получается список списков (`list[list[str]]`).
4. Наконец, превращаем каждый маленький список в словарь, и получается список словарей (`list[dict]`).

Заодно по ходу дела мы превратим текст в числа: всё, что приходит из текста, — это строки, а нам нужны `int` и `float`. Эту цепочку полезно держать в голове всё время: решая задачу, всегда спрашивайте себя — **что у меня есть сейчас и что мне нужно получить на следующем шаге**.

Чтобы пройти этот путь, нам понадобятся три группы знаний: словари (в них мы складываем результат), строковые методы (ими мы разбираем текст) и функции (в них мы оформляем решение). Повторим их по порядку.

## Часть 1. Словарь

### Что это такое

Словарь (`dict`) — это набор пар «ключ → значение». Представьте карточку студента: на ней есть подписанные поля («имя», «возраст», «оценка»), и в каждое поле вписано значение. Подписи — это **ключи**, вписанные данные — **значения**, а вместе подпись с данными — **пара**.

```python
student = {"name": "Егор", "age": 25, "score": 4.5}
```

Из чего состоит словарь:

* фигурные скобки `{}`, внутри которых пары через запятую;
* **ключ** — название поля, после него двоеточие;
* **значение** — данные, которые лежат под этим ключом.

Несколько правил, которые важно помнить:

* **ключи уникальны** — второй раз тот же ключ не появится (при повторной записи значение просто заменится);
* **ключом** может быть только неизменяемый тип: строка, число, кортеж (чаще всего — строка);
* **значением** может быть что угодно: число, строка, список и даже другой словарь;
* к значению мы обращаемся не по номеру, а по **ключу**.

### Создание словаря

Пустой словарь — когда мы собираемся наполнять его позже:

```python
empty = {}
also_empty = dict()
```

Заполненный словарь — когда данные известны сразу:

```python
student = {"name": "Егор", "age": 25, "score": 4.5}
```

### Добавление и изменение пар

Основной способ — присваивание по ключу. Если такого ключа ещё нет — пара **добавится**, если уже есть — значение **заменится**:

```python
student = {"name": "Егор", "age": 25}

student["city"] = "Москва"   # новый ключ — пара добавлена
student["age"] = 26          # ключ уже есть — значение заменено

print(student)   # {'name': 'Егор', 'age': 26, 'city': 'Москва'}
```

Добавить сразу несколько пар можно методом `update()`:

```python
student.update({"score": 5.0, "group": "A1"})
print(student)
# {'name': 'Егор', 'age': 26, 'city': 'Москва', 'score': 5.0, 'group': 'A1'}
```

### Получение значений

Первый способ — квадратные скобки с ключом:

```python
print(student["name"])   # Егор
```

Если такого ключа нет, программа остановится с ошибкой `KeyError`:

```python
print(student["phone"])   # KeyError: 'phone'
```

Второй способ — метод `get()`. Он **не вызывает ошибку**: при отсутствии ключа вернёт `None` или значение, которое вы укажете вторым аргументом:

```python
print(student.get("phone"))                # None
print(student.get("phone", "не указан"))   # не указан
```

Проверить, есть ли ключ в словаре, можно оператором `in`:

```python
print("name" in student)    # True
print("phone" in student)   # False
```

### Основные методы и операции

| Что нужно | Как записывается |
|---|---|
| Узнать количество пар | `len(student)` |
| Получить значение без ошибки | `student.get("phone", "нет")` |
| Добавить или заменить одну пару | `student["city"] = "Москва"` |
| Добавить или заменить несколько пар | `student.update({"score": 5.0})` |
| Удалить пару и получить её значение | `student.pop("city")` |
| Удалить пару | `del student["group"]` |
| Проверить наличие ключа | `"name" in student` |

### Словарь и цикл

Цикл `for` по словарю по умолчанию перебирает **ключи**. Но есть три метода, которые позволяют выбрать, что именно перебирать:

```python
student = {"name": "Егор", "age": 26, "score": 5.0}

for key in student.keys():       # только ключи
    print(key)

for value in student.values():   # только значения
    print(value)

for key, value in student.items():   # пары «ключ, значение»
    print(key, value)
```

Метод `items()` на каждом шаге отдаёт пару (кортеж из двух элементов), которую мы сразу «распаковываем» в две переменные `key` и `value`. Именно он нужен чаще всего.

### Разминка: что выведет программа?

Попробуйте ответить, не запуская код.

```python
# 1
d = {"a": 1, "b": 2}
d["c"] = 3
print(d)

# 2
d = {"x": 10}
d["x"] = d["x"] + 5
print(d["x"])

# 3
d = {"a": 1}
print(d.get("b", 0))

# 4
for key, value in {"a": 1, "b": 2}.items():
    print(key, value * 2)
```

## Часть 2. Строки как инструмент разбора текста

Когда данные приходят текстом, нам нужно уметь их «разбирать на части». Для этого у строк есть методы. Главное, что нужно помнить про любой строковый метод: **строки неизменяемы**, поэтому метод не меняет исходную строку, а **возвращает новую**. Результат нужно сохранить в переменную или сразу использовать.

### strip() — убрать лишнее по краям

`strip()` убирает пробелы и переводы строки в начале и в конце:

```python
print("  Привет  ".strip())   # Привет
```

### lower() — привести к нижнему регистру

```python
print("ПрИвЕт".lower())   # привет
```

Полезно, когда нужно сравнивать слова независимо от того, как они написаны.

### split() — разделить строку на список

`split(разделитель)` разрезает строку на части по указанному разделителю и возвращает **список строк**:

```python
print("Егор,25,4.5".split(","))   # ['Егор', '25', '4.5']
```

Без аргумента `split()` делит по пробелам (и сразу игнорирует лишние):

```python
print("один два  три".split())   # ['один', 'два', 'три']
```

Обратите внимание: даже число `25` после `split()` остаётся **строкой** `'25'`.

### join() — собрать список обратно в строку

`join()` — обратная операция. Вызывается у разделителя, а в скобках передаётся список строк:

```python
print(", ".join(["a", "b", "c"]))   # a, b, c
```

Важно: `join()` работает только со списком **строк**. Если в нём числа, их придётся предварительно превратить в строки через `str()`.

### Цепочки методов

Методы можно применять один за другим, передавая результат дальше:

```python
print("  Hello ".strip().lower())   # hello
print(" ".join("a-b-c".split("-")))   # a b c
```

### Приведение типов: int() и float()

Всё, что мы получили из текста, — строки. Чтобы с данными можно было считать, их нужно превратить в числа:

```python
print(int("25") + 1)       # 26
print(float("4.5") * 2)    # 9.0
print("25" + "1")          # 251 — просто склеились две строки!
```

Запомните: `int()` подходит для целых чисел (`"25"`), `float()` — для дробных (`"4.5"`). Попытка превратить `"4.5"` в `int` вызовет ошибку. Приятная деталь: обе функции спокойно относятся к пробелам вокруг числа — `int(" 25 ")` вернёт `25`, поэтому `strip()` нужен только для строк.

### Ловушка: многострочная строка

Многострочные строки в тройных кавычках часто начинаются и заканчиваются переводом строки:

```python
text = """
первая
вторая
"""
print(text.split("\n"))
# ['', 'первая', 'вторая', '']
```

В списке появились два лишних пустых элемента — по краям. Поэтому **сначала** убираем лишнее с краёв через `strip()`, и **потом** делим на строки:

```python
print(text.strip().split("\n"))
# ['первая', 'вторая']
```

Здесь `"\n"` — символ перевода строки (урок про экранирование): мы режем текст в тех местах, где он переходит на новую строку.

### Ловушка: пробелы после запятых

Если в данных запятые стоят с пробелами, каждая часть получит «хвост» из пробела:

```python
print("Егор, 25".split(","))   # ['Егор', ' 25']
```

Для чисел это не страшно (`int` и `float` пробелы игнорируют), а вот строки нужно чистить через `strip()` у каждой части.

### Разминка: что выведет программа?

```python
# 1
print("  Hello ".strip().lower())

# 2
print(" ".join("a-b-c".split("-")))

# 3
print(int("12") + int("1"))
print("12" + "1")
```

## Часть 3. Собираем вместе: три задачи

Теперь у нас есть всё нужное. Мы решим три задачи, и каждая следующая использует предыдущую.

* **Задача 1** — научиться превращать **одну строку** в словарь.
* **Задача 2** — научиться превращать **список из многих маленьких списков** в список словарей (то есть применять идею задачи 1 ко многим элементам).
* **Задача 3** — соединить обе идеи и добавить ещё один шаг: разделить **большую многострочную строку** на части.

Главное правило, которое будет проходить через все задачи: **сначала решаем для одного элемента, потом повторяем в цикле для всех**.

### Задача 1. Строка → словарь

Пользователь вводит строку с информацией о студенте в формате `имя,возраст,оценка`. Нужно превратить её в словарь вида:

```python
{"name": "Егор", "age": 25, "score": 4.5}
```

Цепочка типов здесь такая: `str → list[str] → dict` (с числами внутри).

**Шаг 1. Исходные данные.** Пока пишем решение, строку удобнее записать прямо в код — так мы можем запускать программу снова и снова, не вводя её руками. `input()` подключим в конце:

```python
line = "  Егор , 25 , 4.5 "
```

**Шаг 2. Делим строку на части.** Метод `split(",")` вернёт список из трёх строк:

```python
parts = line.split(",")
print(parts)   # ['  Егор ', ' 25 ', ' 4.5 ']
```

**Шаг 3. Достаём значения по индексам** и приводим их к нужным типам. Имя — это строка, которую нужно очистить через `strip()`; возраст — целое число; оценка — дробное:

```python
name = parts[0].strip()
age = int(parts[1])
score = float(parts[2])
```

**Шаг 4. Собираем словарь:**

```python
student = {"name": name, "age": age, "score": score}
print(student)   # {'name': 'Егор', 'age': 25, 'score': 4.5}
```

**Шаг 5. Подключаем `input()`.** Вместо фиксированной строки — ввод пользователя. Полный код:

```python
line = input("Введите данные студента (имя,возраст,оценка): ")

parts = line.split(",")

student = {
    "name": parts[0].strip(),
    "age": int(parts[1]),
    "score": float(parts[2])
}

print(student)
```

### Задача 2. Список списков → список словарей

Есть список, в котором лежат списки — по одному на каждую машину. В каждом из них три **строки**: марка, год выпуска, стоимость:

```python
cars = [
    ["Toyota", "2018", "1500000"],
    ["BMW", "2020", "3200000"],
    ["Lada", "2015", "450000"]
]
```

Нужно получить список словарей, где год и стоимость — числа:

```python
[
    {"brand": "Toyota", "year": 2018, "price": 1500000},
    {"brand": "BMW", "year": 2020, "price": 3200000},
    {"brand": "Lada", "year": 2015, "price": 450000}
]
```

Цепочка типов: `list[list[str]] → list[dict]`.

**Шаг 1. Сначала одна машина.** Берём один внутренний список и превращаем его в словарь — точно так же, как в задаче 1:

```python
car = cars[0]   # ["Toyota", "2018", "1500000"]

car_dict = {
    "brand": car[0],
    "year": int(car[1]),
    "price": int(car[2])
}
print(car_dict)   # {'brand': 'Toyota', 'year': 2018, 'price': 1500000}
```

**Шаг 2. Теперь все машины.** Нам нужен пустой список для результата и цикл, в котором мы повторяем то же самое для каждой машины, добавляя результат через `append()`. Этот приём — **пустой список-накопитель перед циклом** — мы будем использовать постоянно:

```python
cars_dicts = []

for car in cars:
    car_dict = {
        "brand": car[0],
        "year": int(car[1]),
        "price": int(car[2])
    }
    cars_dicts.append(car_dict)

print(cars_dicts)
```

Результат полностью совпадает с ожидаемым. Заметьте: тело цикла — это буквально код из шага 1.

### Задача 3. Многострочная строка → список словарей

Есть многострочная строка, где в каждой строке записан один продукт: название, количество, цена.

```python
products_text = """
молоко, 3, 89.9
хлеб, 10, 45
сыр, 2, 420.5
масло, 5, 180
"""
```

Нужно получить список словарей:

```python
[
    {"name": "молоко", "quantity": 3, "price": 89.9},
    {"name": "хлеб", "quantity": 10, "price": 45.0},
    {"name": "сыр", "quantity": 2, "price": 420.5},
    {"name": "масло", "quantity": 5, "price": 180.0}
]
```

Здесь уже есть всё, что мы делали раньше. Разложим задачу на шаги — это самое важное умение.

**План:**

1. Разделить большую строку на список строк (по одной на продукт).
2. Научиться превращать одну такую строку в словарь (это задача 1).
3. Пройтись по всем строкам в цикле и собрать результат в список (это задача 2).

**Шаг 1. Делим текст на строки.** Помним про ловушку: сначала `strip()`, потом `split("\n")`:

```python
lines = products_text.strip().split("\n")
print(lines)
# ['молоко, 3, 89.9', 'хлеб, 10, 45', 'сыр, 2, 420.5', 'масло, 5, 180']
```

Теперь у нас `list[str]` — по одной строке на продукт.

**Шаг 2. Берём одну строку и превращаем её в словарь** — точно как в задаче 1:

```python
line = lines[0]   # "молоко, 3, 89.9"
parts = line.split(",")

product = {
    "name": parts[0].strip(),
    "quantity": int(parts[1]),
    "price": float(parts[2])
}
print(product)   # {'name': 'молоко', 'quantity': 3, 'price': 89.9}
```

**Шаг 3. Повторяем для всех строк**, как в задаче 2 — пустой список-накопитель и цикл:

```python
products = []

for line in lines:
    parts = line.split(",")
    product = {
        "name": parts[0].strip(),
        "quantity": int(parts[1]),
        "price": float(parts[2])
    }
    products.append(product)

print(products)
```

**Итоговый код:**

```python
products_text = """
молоко, 3, 89.9
хлеб, 10, 45
сыр, 2, 420.5
масло, 5, 180
"""

lines = products_text.strip().split("\n")

products = []
for line in lines:
    parts = line.split(",")
    product = {
        "name": parts[0].strip(),
        "quantity": int(parts[1]),
        "price": float(parts[2])
    }
    products.append(product)

print(products)
```

**Зачем нам всё это?** Теперь с данными легко работать. Например, общая стоимость всех товаров:

```python
total = 0
for product in products:
    total = total + product["quantity"] * product["price"]

print(round(total, 2))   # 2460.7
```

Попробуйте сделать то же самое с исходным текстом — и вы поймёте, зачем мы его преобразовывали.

## Часть 4. Вспоминаем функции

Код из задачи 3 работает. Но представьте: завтра у вас появится ещё один такой текст — с машинами, сотрудниками или студентами. Придётся копировать огромный кусок кода и менять в нём пару слов. А если в коде найдётся ошибка, исправлять её придётся в каждой копии. Именно эту проблему решают функции.

### Зачем нужны функции

Функции дают две вещи:

* **переиспользование** — один раз написали, дальше вызываем сколько угодно и для каких угодно данных;
* **декомпозиция** — большая задача разбивается на небольшие понятные части, у каждой из которых есть имя и своя работа.

Вы уже пользуетесь готовыми функциями: `len()`, `print()`, `int()`. Теперь мы пишем свои.

### Синтаксис

```python
def get_double(number):
    result = number * 2
    return result


print(get_double(5))   # 10
```

Разберём по частям:

* `def` — ключевое слово, объявляющее функцию;
* `get_double` — имя функции (оно должно говорить, что она делает);
* `(number)` — **параметр**;
* тело функции — с отступом;
* `return` — что функция **возвращает** наружу.

### Параметры и аргументы

Эти два слова часто путают:

* **параметр** — это переменная, которую функция создаёт для себя; она записана в скобках при объявлении (`number` в примере выше);
* **аргумент** — это конкретное значение, которое мы передаём при вызове (`5` в `get_double(5)`).

Когда функция вызывается, значение аргумента попадает в параметр. Функцию можно вызывать с разными аргументами: `get_double(5)`, `get_double(100)`.

### return и print — не одно и то же

Это самая частая ошибка начинающих:

* `print()` — **показывает** значение на экране, но не отдаёт его программе;
* `return` — **отдаёт** значение тому месту, откуда функцию вызвали, и там его можно сохранить в переменную или передать дальше.

```python
def double_print(number):
    print(number * 2)

def double_return(number):
    return number * 2

a = double_print(5)    # на экране появится 10
b = double_return(5)

print(a)   # None — print ничего не отдал
print(b)   # 10
```

Если в функции нет `return`, она возвращает `None`. Чтобы результат можно было использовать дальше, функция должна его **вернуть**.

### Вход → функция → выход

Хорошая функция — это маленькая «машина»: на вход получает данные, внутри что-то с ними делает, на выходе отдаёт результат. Задавайте себе два вопроса: **что функция получает** и **что должна вернуть**. Это те же вопросы, что мы задавали в цепочке типов.

## Часть 5. Задача 3, разложенная на функции

Вернёмся к задаче 3 и посмотрим, как её решение превращается в набор функций. Мы будем идти шаг за шагом так, как это происходит в реальной работе: сначала решаем первую проблему, потом сталкиваемся со второй, потом с третьей.

> Здесь мы не обсуждаем, где лучше «объединить два действия в одной функции», а где «разделить». Сейчас важнее другое: почувствовать, **зачем нужны функции** и как удобно читать и переиспользовать код, который из них собран.

### Проблема 1. Многострочная строка → список строк

Первое, что мы делали, — делили большой текст на строки. Это законченное действие со своей задачей: на входе строка с текстом, на выходе список строк. Оформим его в функцию:

```python
def text_to_lines(text):
    return text.strip().split("\n")
```

Функция состоит из одной строки — и всё равно это полноценная функция. Зачем? Во-первых, у действия появилось **имя**: читая `text_to_lines(products_text)`, мы сразу понимаем, что происходит. Во-вторых, если завтра окажется, что в тексте бывают пустые строки в середине, мы поправим **одно место**, а не десять:

```python
def text_to_lines(text):
    result = []
    for line in text.strip().split("\n"):
        if line.strip() != "":
            result.append(line)
    return result
```

Всё, что вызывало `text_to_lines()`, продолжит работать, а теперь ещё и пропускает пустые строки. В этом и состоит польза: мы изменили реализацию, а остальной код даже не заметил.

### Проблема 2. Строка → список значений

Теперь у нас есть список строк вида `'молоко, 3, 89.9'`. Каждую из них нужно разобрать на значения: разрезать по запятым и очистить от пробелов. Это снова законченное действие:

```python
def line_to_list(line):
    parts = line.split(",")
    result = []
    for part in parts:
        result.append(part.strip())
    return result
```

Проверим:

```python
print(line_to_list("молоко, 3, 89.9"))   # ['молоко', '3', '89.9']
```

Если применить эту функцию ко всем строкам из списка, получится **список списков**:

```python
lines = text_to_lines(products_text)

rows = []
for line in lines:
    rows.append(line_to_list(line))

print(rows)
# [['молоко', '3', '89.9'], ['хлеб', '10', '45'], ['сыр', '2', '420.5'], ['масло', '5', '180']]
```

Это уже знакомая нам ситуация из задачи 2: перед нами список списков строк.

### Проблема 3. Список списков → список словарей

Остался последний шаг: из этой таблицы сделать список словарей с правильными типами. Это в точности задача 2, только теперь она оформлена как функция:

```python
def rows_to_products(rows):
    products = []
    for row in rows:
        product = {
            "name": row[0],
            "quantity": int(row[1]),
            "price": float(row[2])
        }
        products.append(product)
    return products
```

Заметьте: внутри нет ни `strip()`, ни `split()` — эту работу уже сделали предыдущие функции. Каждая функция занимается только своим кусочком цепочки типов.

### Собираем программу

Теперь главная функция — она не делает ничего сложного сама, а просто вызывает остальные в нужном порядке:

```python
def main():
    lines = text_to_lines(products_text)

    rows = []
    for line in lines:
        rows.append(line_to_list(line))

    products = rows_to_products(rows)
    print(products)


main()
```

Полная программа:

```python
products_text = """
молоко, 3, 89.9
хлеб, 10, 45
сыр, 2, 420.5
масло, 5, 180
"""


def text_to_lines(text):
    return text.strip().split("\n")


def line_to_list(line):
    parts = line.split(",")
    result = []
    for part in parts:
        result.append(part.strip())
    return result


def rows_to_products(rows):
    products = []
    for row in rows:
        product = {
            "name": row[0],
            "quantity": int(row[1]),
            "price": float(row[2])
        }
        products.append(product)
    return products


def main():
    lines = text_to_lines(products_text)

    rows = []
    for line in lines:
        rows.append(line_to_list(line))

    products = rows_to_products(rows)
    print(products)


main()
```

Сравните `main()` с версией без функций. Теперь `main()` читается как **план действий**: взять строки из текста, превратить каждую в список значений, превратить таблицу в словари. Чтобы понять, что делает программа, не нужно вчитываться в каждую строчку кода.

### Переиспользование: новые данные — минимум нового кода

Вот ради чего всё затевалось. Допустим, пришёл другой текст — с машинами:

```python
cars_text = """
Toyota, 2018, 1500000
BMW, 2020, 3200000
"""
```

Функции `text_to_lines()` и `line_to_list()` подходят **без единого изменения**. Нужно написать только последний шаг — он зависит от того, какие поля мы хотим получить:

```python
def rows_to_cars(rows):
    cars = []
    for row in rows:
        car = {
            "brand": row[0],
            "year": int(row[1]),
            "price": int(row[2])
        }
        cars.append(car)
    return cars


rows = []
for line in text_to_lines(cars_text):
    rows.append(line_to_list(line))

print(rows_to_cars(rows))
# [{'brand': 'Toyota', 'year': 2018, 'price': 1500000}, {'brand': 'BMW', 'year': 2020, 'price': 3200000}]
```

Вместо копирования всего решения мы дописали одну небольшую функцию. Именно так и работают функции: общее выносится отдельно, уникальное пишется заново.

## Часть 6. Памятка: как подходить к таким задачам

1. **Определите, что у вас есть и что нужно получить.** Запишите цепочку типов: `str → list[str] → list[list[str]] → list[dict]`.
2. **Решите задачу для одного элемента** (одной строки, одного списка), а потом повторите в цикле для всех.
3. **Помните про накопитель:** пустой список перед циклом, `append()` внутри.
4. **Данные из текста — всегда строки.** Числа нужно превращать через `int()` или `float()`.
5. **Многострочный текст:** сначала `strip()`, потом `split("\n")`.
6. **Текстовые значения чистим через `strip()`.** Для чисел это не нужно: `int()` и `float()` сами игнорируют пробелы по краям.
7. **Когда решение работает — оформляйте шаги в функции.** Вход функции — параметры, выход — `return`, а не `print`.
8. **Проверяйте каждую функцию отдельно**, прежде чем собирать их вместе.
