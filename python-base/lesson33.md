## Что такое кортеж

Кортеж (`tuple`) — это упорядоченная последовательность значений, очень похожая на список, но с одним принципиальным отличием: кортеж **неизменяем**, точно так же, как строка. Создаётся кортеж через круглые скобки:

```python
point = (10, 20)
print(point)         # (10, 20)
print(type(point))   # <class 'tuple'>
```

Обращение по индексу и срезы у кортежа работают ровно так же, как у списков и строк, — с тем же самым синтаксисом, теми же правилами отрицательных индексов и срезов:

```python
point = (10, 20, 30)

print(point[0])    # 10
print(point[-1])   # 30
print(point[0:2])  # (10, 20)
```

## Неизменяемость: главное отличие от списка

Попытка изменить элемент кортежа приводит к ошибке — в этом кортеж ведёт себя точно так же, как строка:

```python
point = (10, 20)
point[0] = 99
# TypeError: 'tuple' object does not support item assignment
```

Именно поэтому кортеж стоит использовать там, где данные по своей природе не должны меняться после создания: координаты точки, цвет в формате RGB, дата в виде набора чисел (год, месяц, день). Если список — это для данных, которые могут расти, меняться и перестраиваться, то кортеж — для фиксированного, завершённого набора значений.

## Методы кортежей: count() и index()

Поскольку кортеж неизменяем, у него нет методов вроде `append()` или `remove()` — изменять-то нечего. Но методы, которые только читают данные, не меняя их, у кортежа есть, и работают они точно так же, как у списков в уроке 16:

```python
numbers = (1, 2, 3, 2, 4, 2)

print(numbers.count(2))   # 3 — сколько раз встречается 2
print(numbers.index(3))   # 2 — индекс первого вхождения числа 3
```

`index()` точно так же, как и у списков, вызовет ошибку `ValueError`, если искомого значения в кортеже нет вообще.

## Так вот что такое пары из enumerate() и items()

Теперь можно раскрыть то, что мы откладывали несколько уроков подряд. Когда мы писали `for index, value in enumerate(fruits):` или `for key, value in prices.items():`, каждая пара, которую отдавали эти конструкции на каждом шаге, была именно кортежем — упорядоченной, неизменяемой парой из двух значений:

```python
fruits = ["яблоко", "банан"]

for pair in enumerate(fruits):
    print(pair, type(pair))
```

```
(0, 'яблоко') <class 'tuple'>
(1, 'банан') <class 'tuple'>
```

Когда мы писали `for index, value in enumerate(fruits):` с двумя переменными через запятую, происходило не что-то особенное для `enumerate()` — происходила **распаковка кортежа**, общий механизм Python, с которым мы сейчас познакомимся подробнее.

## Распаковка: раскладываем кортеж по переменным

Распаковка — это присваивание, при котором значения кортежа сразу раскладываются по нескольким переменным одной строкой:

```python
point = (10, 20)
x, y = point

print(x)   # 10
print(y)   # 20
```

Слева стоит не одна переменная, а сразу две через запятую — и Python сопоставляет их с элементами кортежа справа по порядку: первая переменная получает первый элемент, вторая — второй. Количество переменных слева должно совпадать с количеством элементов кортежа справа, иначе возникнет ошибка:

```python
point = (10, 20, 30)
x, y = point
# ValueError: too many values to unpack (expected 2)
```

## Возвращаемся к задаче из урока 2

В самом начале курса, ещё в уроке про переменные, мы меняли значения двух переменных местами через вспомогательную переменную:

```python
a = 5
b = 10

temp = a
a = b
b = temp
```

Теперь, зная про кортежи и распаковку, ту же самую задачу можно решить одной строкой:

```python
a = 5
b = 10

a, b = b, a

print(a, b)   # 10 5
```

Разберём, что здесь на самом деле происходит. Правая часть, `b, a`, сама по себе уже создаёт кортеж — да, кортеж можно создать и без круглых скобок, простой запятой между значениями. Python сначала полностью строит этот кортеж `(значение b, значение a)`, используя старые значения обеих переменных, и только потом распаковывает его обратно в `a` и `b` — то есть к моменту, когда `a` получает новое значение, `b` для построения кортежа уже было прочитано и сохранено внутри временного кортежа. Никакой дополнительной переменной `temp` заводить не пришлось — сам механизм распаковки взял на себя ту роль, которую раньше выполняла `temp` вручную.

## Итоги урока

Кортеж — упорядоченная, неизменяемая последовательность значений, создаваемая через `()`; индексация и срезы работают так же, как у списков и строк. Из-за неизменяемости у кортежей нет изменяющих методов вроде `append()`, но есть читающие — `count()` и `index()`, работающие так же, как у списков. Пары, которые отдают `enumerate()` и `items()` словаря, — это именно кортежи. Распаковка позволяет разложить кортеж по нескольким переменным одной строкой (`x, y = point`) и, в частности, обменять значения двух переменных местами без вспомогательной переменной: `a, b = b, a`.

В следующем уроке мы разберём множества — тип данных, специально созданный для хранения уникальных значений и избавления от дубликатов.
