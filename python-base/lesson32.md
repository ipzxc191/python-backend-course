# Урок 32. Работа со словарями в цикле. Словарь со значением-списком

Это самый концептуально насыщенный урок модуля — здесь сходятся сразу несколько тем: перебор словаря циклом, извлечение нужных полей из более сложных данных, и прямая параллель с вложенными структурами из модуля 3, только теперь внешней структурой оказывается не список, а словарь.

## Перебор словаря по умолчанию — это перебор ключей

Если написать `for` прямо по словарю, без вызова какого-либо метода, Python по умолчанию переберёт его ключи:

```python
prices = {"хлеб": 60, "молоко": 90, "сыр": 350}

for key in prices:
    print(key)
```

```
хлеб
молоко
сыр
```

Это то же самое, что `for key in prices.keys():` — просто более короткая запись. Если внутри цикла нужны и ключи, и значения, придётся дополнительно обращаться к словарю по каждому ключу:

```python
prices = {"хлеб": 60, "молоко": 90, "сыр": 350}

for key in prices:
    print(key, prices[key])
```

Это рабочий вариант, но не самый удобный — на каждом шаге приходится делать лишнее обращение `prices[key]`. Гораздо естественнее использовать уже знакомый метод `items()`.

## Перебор через items(): ключ и значение сразу

```python
prices = {"хлеб": 60, "молоко": 90, "сыр": 350}

for key, value in prices.items():
    print(f"{key}: {value} руб.")
```

```
хлеб: 60 руб.
молоко: 90 руб.
сыр: 350 руб.
```

Это основной, самый распространённый способ перебирать словарь в реальном коде: `items()` сразу отдаёт пару «ключ, значение» на каждой итерации, точно так же, как `enumerate()` отдавал пару «индекс, значение» для списков. Не нужно отдельно обращаться к словарю внутри цикла — оба значения уже под рукой.

## Практический пример: отчёт по складу

```python
stock = {"хлеб": 12, "молоко": 3, "сыр": 25, "масло": 1}

for item, quantity in stock.items():
    if quantity < 5:
        print(f"{item}: осталось мало ({quantity})")
    else:
        print(f"{item}: в достатке ({quantity})")
```

```
хлеб: в достатке (12)
молоко: осталось мало (3)
сыр: в достатке (25)
масло: осталось мало (1)
```

Здесь на каждом шаге перебора сразу доступны и название товара, и его количество, и на их основе можно применить уже знакомый `if`/`else`.

## Словарь словарей: извлечение нужных полей

Значением в словаре может быть не только простое число или строка, но и целый другой словарь — например, если нужно хранить несколько характеристик для каждой записи сразу:

```python
students = {
    "Иван": {"age": 20, "city": "Москва"},
    "Мария": {"age": 22, "city": "Казань"}
}

for name, info in students.items():
    print(f"{name}: возраст {info['age']}, город {info['city']}")
```

```
Иван: возраст 20, город Москва
Мария: возраст 22, город Казань
```

Здесь `info` на каждом шаге становится вложенным словарём (`{"age": 20, "city": "Москва"}` для Ивана), а `info["age"]` и `info["city"]` — уже знакомое обращение по ключу, применённое к этому вложенному словарю. Это тот же самый принцип двойного обращения, что мы видели в уроке 27 с `matrix[i][j]`, только теперь вместо двух индексов — сначала ключ внешнего словаря (через `items()`), а затем ключ вложенного.

## Словарь со значением-списком: явная параллель с модулем 3

Теперь — центральная тема урока. Значением в словаре может быть список, и это исключительно частый случай на практике — например, хранение нескольких оценок для каждого студента:

```python
grades = {
    "Иван": [85, 90, 78],
    "Мария": [92, 88, 95],
    "Дмитрий": [70, 65, 80]
}
```

Здесь стоит явно провести параллель с тем, что мы уже видели в уроке 27. Там внешней структурой был список, а внутренней — тоже список (вложенные списки), и для обхода требовался вложенный цикл. Здесь ровно тот же принцип, только внешней структурой оказывается словарь, а внутренней по-прежнему остаётся список:

```python
grades = {
    "Иван": [85, 90, 78],
    "Мария": [92, 88, 95],
    "Дмитрий": [70, 65, 80]
}

for name, student_grades in grades.items():
    for grade in student_grades:
        print(f"{name}: {grade}")
```

```
Иван: 85
Иван: 90
Иван: 78
Мария: 92
...
```

Внешний цикл, как обычно, перебирает пары словаря через `items()`; внутренний — сам список, оказавшийся значением для текущего ключа. Логика вложенности здесь та же самая, что и с вложенными списками, — просто внешний уровень теперь устроен по-другому.

## Практический пример: средний балл каждого студента

Куда чаще, чем просто выводить все значения списка подряд, требуется что-то с ними посчитать — например, средний балл:

```python
grades = {
    "Иван": [85, 90, 78],
    "Мария": [92, 88, 95],
    "Дмитрий": [70, 65, 80]
}

for name, student_grades in grades.items():
    total = 0

    for grade in student_grades:
        total = total + grade

    average = total / len(student_grades)
    print(f"{name}: средний балл {round(average, 1)}")
```

```
Иван: средний балл 84.3
Мария: средний балл 91.7
Дмитрий: средний балл 71.7
```

Обратите внимание, что переменная `total` заводится заново, с нуля, **внутри** внешнего цикла, на каждой новой итерации по студенту — иначе оценки одного студента складывались бы вместе с оценками предыдущего, и результат оказался бы неверным. Это тонкий, но важный момент: то, что должно «обнуляться» для каждого нового элемента внешнего цикла, должно находиться внутри него, а не быть заведено один раз перед обоими циклами.

## Осторожно: не меняйте словарь во время перебора

Здесь стоит предупредить об одной ловушке напоследок: если попытаться добавить или удалить ключ прямо во время перебора словаря циклом `for`, Python выдаст ошибку:

```python
prices = {"хлеб": 60, "молоко": 90}

for key in prices:
    prices["сыр"] = 350
# RuntimeError: dictionary changed size during iteration
```

Если действительно требуется что-то добавить или удалить по результатам перебора, стоит сначала собрать нужные ключи в отдельный список во время безопасного перебора, а изменения в сам словарь вносить уже после того, как перебор полностью завершён, — этот приём мы ещё увидим на практике в следующих уроках модуля.

## Итоги урока

`for` по словарю без дополнительного метода перебирает его ключи. `items()` — основной и самый удобный способ перебора, отдающий пару «ключ, значение» на каждом шаге. Если значением словаря является другой словарь, доступ к нужному полю требует двойного обращения по ключу — тот же принцип, что и `matrix[i][j]` у вложенных списков. Если значением словаря является список, для его перебора внутри внешнего цикла по словарю нужен вложенный `for` — прямая параллель с вложенными списками из модуля 3, только с внешней структурой другого типа. Изменять словарь (добавлять или удалять ключи) непосредственно во время перебора циклом небезопасно и вызывает ошибку.

В следующем уроке мы познакомимся с кортежами и множествами — типами данных, которые встречаются реже словаря, но всё равно занимают важное место в арсенале Python-разработчика.
