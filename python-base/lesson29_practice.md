### Задача 1. Меню обработки чисел

Реализуйте меню с помощью `while True`. Пользователь может ввести команду `"добавить"` (запросить число и добавить его в список), `"показать"` (вывести текущий список) или `"выход"` (завершить цикл через `break`). Используйте `elif` для разбора команд.

**Пример использования**:

```
Команда: добавить
Введите число: 5
Команда: добавить
Введите число: 12
Команда: показать
[5, 12]
Команда: выход
```

### Задача 7. Регистрация с ограничением попыток

### Задача 8. Таблица умножения в матрице

Используя вложенные циклы по индексам, постройте вложенный список — таблицу умножения размером 5x5, где элемент на позиции `[i][j]` равен `(i + 1) * (j + 1)`. В этой таблице на пересечении строки с номером N и столбца с номером M должно стоять произведение N × M. Например, в третьей строке и четвёртом столбце стоит число 3 × 4 = 12.

Начните с пустого вложенного списка и заполняйте его построчно (строка в матрице - это вложенный список).

**Пример использования**:

```
[1, 2, 3, 4, 5]
[2, 4, 6, 8, 10]
[3, 6, 9, 12, 15]
[4, 8, 12, 16, 20]
[5, 10, 15, 20, 25]
```

### Задача 9. Инвентаризация склада

Дан список товаров и список их количеств на складе (позиции соответствуют друг другу по индексу). Используя `enumerate()`, выведите отчёт вида `Товар 1: хлеб — 12 шт.` только для тех товаров, количество которых меньше 5, а в конце — общее количество товаров, требующих пополнения, посчитанное отдельным циклом `for`.

```python
items = ["хлеб", "молоко", "сыр", "масло", "яйца"]
quantities = [12, 3, 8, 1, 4]
```

**Пример использования**:

```
Товар 2: молоко — 3 шт.
Товар 4: масло — 1 шт.
Товар 5: яйца — 4 шт.
Требуют пополнения: 3
```

### Задача 10. Комплексная задача: анализ текста

Запросите у пользователя предложение. Выполните следующее:
1. С помощью `split()` разбейте его на слова.
2. С помощью генератора списка постройте список длин каждого слова.
3. С помощью `for` найдите и выведите самое длинное слово (используя паттерн «начальное предположение» из урока 22).
4. С помощью генератора списка с условием получите список только тех слов, которые длиннее среднего значения длины слова (среднее посчитайте через сумму длин, делённую на их количество).

**Пример использования**:

```
Введите предложение: Python это простой и очень мощный язык программирования
Длины слов: [6, 3, 8, 1, 5, 6, 4, 15]
Самое длинное слово: программирования
Слова длиннее среднего: ['простой', 'программирования']
```
