# Урок 3. Числа. Операции над числами

В прошлом уроке мы разобрались, как переменные хранят и переприсваивают значения. Теперь самое время дать переменным настоящую работу — займёмся числами и тем, что с ними можно делать.

## Целые и дробные числа

В Python есть два основных числовых типа, с которыми вы будете иметь дело постоянно.

**Целые числа** (`int`) — числа без дробной части: `5`, `100`, `-12`, `0`.

**Дробные числа** (`float`) — числа с плавающей точкой, то есть с дробной частью: `3.14`, `0.5`, `-7.2`. Обратите внимание: в Python дробная часть отделяется точкой, а не запятой, как принято в русском языке — `3.14`, а не `3,14`.

```python
age = 25          # int
price = 19.99      # float
```

Определить, к какому типу относится значение, можно уже знакомой функцией `type()` (Задача 4 прошлого урока):

```python
print(type(age))     # <class 'int'>
print(type(price))   # <class 'float'>
```

## Основные арифметические операции

С большинством операций вы уже знакомы из математики — Python просто записывает их через привычные символы:

```python
a = 10
b = 3

print(a + b)   # 13 — сложение
print(a - b)   # 7  — вычитание
print(a * b)   # 30 — умножение
print(a ** b)  # 1000 — возведение в степень
```

Возведение в степень записывается двумя звёздочками (`**`), а не привычным по школе `^` — этот символ в Python используется совсем для другой операции, с которой мы познакомимся значительно позже.

## Два вида деления и остаток — самая важная часть урока

Здесь начинается то, ради чего этот урок в первую очередь и задумывался: в Python не одна операция деления, а сразу три родственных, и путаница между ними — одна из самых частых ошибок у тех, кто только начинает.

**Обычное деление** (`/`) работает так, как вы ожидаете, и всегда возвращает дробное число, даже если результат делится нацело:

```python
print(10 / 2)   # 5.0
print(10 / 3)   # 3.3333333333333335
```

Обратите внимание на первый пример: `10 / 2` математически равно ровно 5, но Python всё равно вернул `5.0`, а не `5`. Это не ошибка — `/` в Python устроена так, что её результат всегда имеет тип `float`, независимо от того, делятся ли числа друг на друга нацело.

**Целочисленное деление** (`//`) возвращает только целую часть результата, полностью отбрасывая дробную:

```python
print(10 // 3)   # 3
print(10 // 2)   # 5
```

`10 // 3` было бы равно `3.33...` при обычном делении, но `//` отбрасывает всё, что после точки, и оставляет только `3`.

**Остаток от деления** (`%`) возвращает то, что осталось «лишним» после того, как целочисленное деление забрало себе все полные части:

```python
print(10 % 3)   # 1
```

10 делится на 3 нацело два раза (`3 × 3 = 9`), и `1` — это как раз то, что осталось от десяти сверх этих девяти. Не случайно `//` и `%` часто используют в паре: `//` говорит, сколько раз одно число «поместилось» в другое, а `%` — что осталось после этого.

Именно `%` лежит в основе одной из самых частых задач в программировании — проверки чётности числа: если `number % 2` равно `0`, число делится на 2 без остатка, а значит чётное; если равно `1` — нечётное. Мы ещё не раз вернёмся к этому приёму, когда дойдём до условий и циклов.

## Приоритет операций

Python вычисляет выражения в том же порядке, к которому вы привыкли по математике: сначала возведение в степень, затем умножение и деление (в том числе `//` и `%`) слева направо, и только потом сложение и вычитание.

```python
result = 2 + 3 * 4
print(result)   # 14, а не 20
```

Сначала выполняется `3 * 4 = 12`, и только потом `2 + 12 = 14`. Если нужен именно порядок сложения раньше умножения, используются скобки — точно так же, как на бумаге:

```python
result = (2 + 3) * 4
print(result)   # 20
```

Когда выражение становится длинным и в нём смешано несколько разных операций, скобки — это не только способ изменить порядок вычисления, но и способ сделать код понятнее для человека, который будет его читать (в том числе для вас самих через месяц).

## Частые ошибки, о которых стоит знать заранее

**Деление на ноль.** Python не «придумывает» результат деления на ноль — он останавливает программу с ошибкой:

```python
print(10 / 0)
# ZeroDivisionError: division by zero
```

Если в программе есть шанс, что делитель окажется нулём, об этом нужно думать заранее — позже в курсе мы разберём, как перехватывать подобные ошибки, не давая программе аварийно остановиться.

**Неожиданная неточность дробных чисел.** Следующий пример на первый взгляд выглядит как ошибка Python, хотя ей не является:

```python
print(0.1 + 0.2)
# 0.30000000000000004
```

Это не баг и не особенность именно Python — так работает представление дробных чисел в памяти практически любого языка программирования, потому что не все десятичные дроби можно точно представить в виде, который использует компьютер. Для большинства задач это не имеет значения, но полезно знать, что сравнивать дробные числа на точное равенство (`0.1 + 0.2 == 0.3`) стоит с осторожностью — к этой теме мы ещё вернёмся, когда будем разбирать сравнения.

## Итоги урока

Python различает целые числа (`int`) и дробные числа (`float`). Помимо привычных сложения, вычитания, умножения и возведения в степень (`**`), в Python есть три вида деления: обычное (`/`, всегда возвращает дробный результат), целочисленное (`//`, оставляет только целую часть) и остаток от деления (`%`, оставляет то, что не поместилось в целые части). Порядок вычисления выражений совпадает со школьной математикой, а скобки позволяют этот порядок изменить.

В следующем уроке мы познакомимся с модулем `math`, а также подробнее разберём функции `print()` и `input()`, которые до сих пор использовались как само собой разумеющийся инструмент.
