# Урок 28. Генераторы списков. Условия в генераторах. Вложенные генераторы

В уроках 24 и 27 мы несколько раз повторяли один и тот же паттерн: завести пустой список, пройтись циклом `for`, и на каждом шаге добавлять что-то в этот список через `append()`, иногда — только при выполнении условия. Этот паттерн настолько частый, что в Python для него есть отдельная, более компактная запись — генератор списка (list comprehension). Сегодняшний урок — про неё.

## От цикла к генератору списка

Вспомним пример из урока 24:

```python
numbers = [4, 15, 8, 22, 6, 30]
squares = []

for number in numbers:
    if number > 10:
        squares.append(number ** 2)

print(squares)   # [225, 484, 900]
```

Три строки кода: пустой список, цикл, условие с добавлением. Генератор списка позволяет записать всё это в одну строку:

```python
numbers = [4, 15, 8, 22, 6, 30]
squares = [number ** 2 for number in numbers if number > 10]

print(squares)   # [225, 484, 900]
```

Разберём синтаксис по частям. Внутри квадратных скобок записываются, в строгом порядке: то, что нужно поместить в новый список (`number ** 2`), затем `for` с переменной и перебираемой последовательностью (`for number in numbers`), и, при необходимости, условие фильтрации (`if number > 10`). Общая структура выглядит так:

```
[выражение for переменная in последовательность if условие]
```

Результат работает абсолютно так же, как и развёрнутый вариант через `append()`, — просто записан компактнее.

## Генератор без условия

Условие в генераторе не обязательно — можно просто преобразовать каждый элемент, без фильтрации:

```python
numbers = [1, 2, 3, 4, 5]
doubled = [number * 2 for number in numbers]

print(doubled)   # [2, 4, 6, 8, 10]
```

Это прямой аналог обычного `for` с `append()`, но без условия внутри:

```python
numbers = [1, 2, 3, 4, 5]
doubled = []

for number in numbers:
    doubled.append(number * 2)
```

## Генератор с тернарным оператором внутри

Если нужно не отфильтровать элементы, а изменить каждый в зависимости от условия — оставив все элементы в результате, но по-разному их преобразовав, — внутри генератора можно использовать тернарный оператор из урока 17:

```python
numbers = [3, 8, 12, 5, 20]
labels = ["чётное" if n % 2 == 0 else "нечётное" for n in numbers]

print(labels)   # ['нечётное', 'чётное', 'чётное', 'нечётное', 'чётное']
```

Обратите внимание на разницу в расположении условия: тернарный оператор (`"чётное" if n % 2 == 0 else "нечётное"`) стоит **перед** `for` и относится к тому, что именно попадёт в список для каждого элемента — при этом в списке окажется ровно столько же элементов, сколько было в исходном. А условие фильтрации (`if number > 10` из первого примера этого урока) стоит **после** `for` и определяет, попадёт ли элемент в результат вообще, — из-за него в итоговом списке может оказаться меньше элементов, чем в исходном.

## Генератор для строк

Генераторы списков прекрасно работают и при переборе строк:

```python
word = "Python"
letters = [letter for letter in word]

print(letters)   # ['P', 'y', 't', 'h', 'o', 'n']
```

```python
sentence = "привет как дела"
long_words = [w for w in sentence.split() if len(w) > 3]

print(long_words)   # ['привет', 'дела']
```

## Вложенные генераторы: обход вложенных списков в одной строке

В уроке 27 мы вручную собирали плоский список из вложенного, используя два вложенных цикла `for`. Тот же результат можно получить одной строкой, разместив внутри генератора сразу два `for` подряд:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

flat = [number for row in matrix for number in row]

print(flat)   # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

Порядок `for` внутри генератора точно соответствует порядку вложенных циклов, как если бы вы написали их развёрнуто: сначала внешний (`for row in matrix`), затем внутренний (`for number in row`) — ровно в том порядке, в котором они здесь и записаны, слева направо.

## Важно: краткость не должна идти в ущерб читаемости

Генераторы списков — удобный инструмент, но у него есть очевидная опасность: раз можно уместить и вложенность, и условие, и преобразование в одну строку, легко скатиться в код, который невозможно прочитать с первого взгляда. Сравните два варианта одной и той же задачи — отобрать из вложенного списка все чётные числа, которые больше 5, преобразовав их в квадраты:

**Избыточно усложнённый генератор:**

```python
matrix = [[1, 6, 3], [8, 5, 12], [7, 4, 9]]
result = [n ** 2 for row in matrix for n in row if n % 2 == 0 if n > 5]
```

**То же самое, но развёрнуто через обычные циклы:**

```python
matrix = [[1, 6, 3], [8, 5, 12], [7, 4, 9]]
result = []

for row in matrix:
    for n in row:
        if n % 2 == 0 and n > 5:
            result.append(n ** 2)
```

Оба варианта дают одинаковый результат (`[36, 64, 144]`), но первый требует от читающего удерживать в голове сразу четыре разных элемента синтаксиса одновременно (два `for`, два `if`) в одной плотной строке, тогда как второй читается по шагам, естественно, сверху вниз. Здесь однозначно стоит выбрать второй вариант — читаемость важнее компактности, особенно когда логика становится настолько многослойной. Хорошее практическое правило: если генератор списка перестаёт помещаться в одну спокойно читаемую строку без нескольких `for` и `if` подряд, лучше вернуться к развёрнутому циклу.

## Итоги урока

Генератор списка (`[выражение for переменная in последовательность if условие]`) — это компактная запись уже знакомого паттерна «завести пустой список, пройтись циклом, добавить элементы через `append()`, возможно с условием». Тернарный оператор внутри генератора (перед `for`) преобразует каждый элемент, сохраняя размер списка; условие после `for` — фильтрует, потенциально уменьшая размер списка. Несколько `for` подряд внутри одного генератора позволяют обойти вложенные списки в одну строку, в том же порядке, что и вложенные циклы. При этом краткость не должна становиться самоцелью: если генератор превращается в нечитаемую конструкцию из нескольких `for` и `if`, стоит вернуться к развёрнутому циклу.

Этим уроком завершается основной материал модуля 3 — впереди итоговая практика, объединяющая циклы `while` и `for`, работу с индексами, вложенные структуры и генераторы списков.
