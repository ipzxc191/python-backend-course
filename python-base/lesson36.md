## Фишка 1: setdefault() вместо ручной проверки

Вспомним задачу из урока 32, где мы собирали список оценок для каждого студента — если студент уже был в словаре, добавляли оценку в существующий список, если нет — создавали новый список:

```python
grades = {}
name = "Олег"
grade = 5

if name in grades:
    grades[name].append(grade)
else:
    grades[name] = [grade]
```

Метод `setdefault(ключ, значение_по_умолчанию)` делает то же самое одной строкой: если ключ уже есть в словаре, он просто возвращает существующее значение по этому ключу; если ключа нет — создаёт его с указанным значением по умолчанию и сразу же возвращает это значение. В любом случае возвращённое значение можно сразу использовать:

```python
grades = {}
name = "Олег"
grade = 5

grades.setdefault(name, []).append(grade)
```

Разберём это по шагам. Если `"Олег"` уже есть в `grades`, `setdefault` вернёт существующий список оценок, и `.append(grade)` добавит новую оценку в него. Если `"Олег"` в словаре ещё нет, `setdefault` создаст запись `grades["Олег"] = []` (пустой список), сразу же вернёт этот новый пустой список, и `.append(grade)` добавит в него первую оценку. Результат в обоих случаях совпадает с развёрнутой версией через `if`/`else`, но записан в одну строку.

## Фишка 2: объединение словарей

Если нужно объединить два словаря в один, есть два удобных способа, оба короче, чем перебор циклом:

```python
defaults = {"theme": "светлая", "language": "русский"}
user_settings = {"language": "английский", "notifications": True}

merged = {**defaults, **user_settings}
print(merged)
# {'theme': 'светлая', 'language': 'английский', 'notifications': True}
```

Синтаксис `{**словарь1, **словарь2}` разворачивает содержимое обоих словарей внутрь новых фигурных скобок. Обратите внимание на `"language"`: он присутствует в обоих исходных словарях с разными значениями, и в объединённом словаре побеждает значение из того словаря, который был указан **позже** — то есть `user_settings` в данном случае перекрывает значение из `defaults`.

Начиная с Python 3.9, то же самое можно записать ещё короче, через оператор `|`:

```python
merged = defaults | user_settings
print(merged)
```

Результат идентичен — какой из двух способов использовать, зависит только от личных предпочтений или версии Python, с которой вы работаете.

## Фишка 3: обмен ключей и значений через генератор словаря

В уроке 28 мы разбирали генераторы списков; у словарей есть точно такой же по идее генератор, только с фигурными скобками и парой «ключ: значение» вместо одного выражения:

```python
prices = {"хлеб": 60, "молоко": 90}
doubled_prices = {item: price * 2 for item, price in prices.items()}

print(doubled_prices)
# {'хлеб': 120, 'молоко': 180}
```

Одно из полезных применений этого приёма — поменять местами ключи и значения словаря:

```python
capitals = {"Франция": "Париж", "Италия": "Рим"}
by_capital = {capital: country for country, capital in capitals.items()}

print(by_capital)
# {'Париж': 'Франция', 'Рим': 'Италия'}
```

Здесь генератор перебирает пары через `items()`, но при формировании нового словаря значения и ключи в паре `capital: country` записаны в обратном порядке по сравнению с тем, как они пришли из `items()` — именно это и меняет их местами в новом словаре.

## Фишка 4: вложенные словари — не только читаем, но и меняем

В уроке 32 мы уже читали значения из вложенных словарей. Точно так же их можно и изменять — обращение по двойному ключу работает для записи так же, как и для чтения:

```python
students = {
    "Олег": {"age": 20, "city": "Москва"},
    "Мария": {"age": 22, "city": "Казань"}
}

students["Олег"]["age"] = 21
print(students["Олег"])
# {'age': 21, 'city': 'Москва'}
```

Вложенный словарь можно строить и с нуля, добавляя записи по ходу работы, а не только читая уже готовую структуру:

```python
inventory = {}

inventory["хлеб"] = {"price": 60, "quantity": 12}
inventory["молоко"] = {"price": 90, "quantity": 5}

print(inventory)
```

## Разбор примера: подсчёт слов через setdefault

Прежде чем переходить к самостоятельной практике, разберём одну задачу вместе. Нужно посчитать, сколько раз каждое слово встречается в тексте.

**Что перебираем**: каждое слово из текста, полученного через `split()`.
**Что делаем на каждом шаге**: если слово уже встречалось — увеличиваем счётчик, если нет — заводим для него запись со значением 1. Именно эта логика идеально ложится на `setdefault()`.

```python
text = "кот собака кот попугай собака кот"
words = text.split()

word_count = {}

for word in words:
    word_count[word] = word_count.setdefault(word, 0) + 1

print(word_count)
# {'кот': 3, 'собака': 2, 'попугай': 1}
```

На каждом шаге `word_count.setdefault(word, 0)` возвращает текущий счётчик слова (или `0`, если слово встретилось впервые), а затем к результату прибавляется `1`, и итог записывается обратно в словарь по тому же ключу.
