# Урок 34. Множества (set). Уникальность и удаление дубликатов. Обзор операций пересечения/объединения

Множество — ещё один тип данных, но, в отличие от словаря, у него куда более узкая и конкретная область применения. Весь этот урок можно свести к одной главной мысли: множество — это инструмент для хранения уникальных значений и избавления от повторов. Именно на этом мы сосредоточимся, а операции вроде пересечения и объединения затронем лишь бегло, для общего кругозора.

## Что такое множество

Множество (`set`) — это неупорядоченная коллекция уникальных значений. Два ключевых слова здесь — «неупорядоченная» и «уникальных», и оба заслуживают отдельного объяснения.

```python
fruits = {"яблоко", "банан", "апельсин"}
print(fruits)
```

Множество создаётся фигурными скобками, как и словарь, — но, в отличие от словаря, внутри просто перечисляются значения, без пар «ключ: значение».

## Главное свойство: дубликаты автоматически исчезают

Вот ради чего вообще существует этот тип данных:

```python
numbers = {1, 2, 2, 3, 3, 3, 4}
print(numbers)
# {1, 2, 3, 4}
```

Хотя в фигурных скобках были явно перечислены повторяющиеся числа, множество автоматически оставило от каждого значения только одну копию. Это происходит не потому, что Python «стирает лишнее» после создания, — множество по своей природе просто не способно хранить два одинаковых значения одновременно.

Самое частое практическое применение множества — избавление от дубликатов в уже существующем списке:

```python
numbers = [1, 2, 2, 3, 1, 4, 3, 5]
unique_numbers = list(set(numbers))

print(unique_numbers)
# [1, 2, 3, 4, 5] (порядок может отличаться от исходного)
```

Здесь `set(numbers)` превращает список в множество, автоматически убирая повторы, а `list(...)` превращает результат обратно в список — теперь уже без дубликатов. Это, пожалуй, самый частый однострочный приём, ради которого множества и используются на практике.

## Порядок не гарантирован

Обратите внимание на комментарий в примере выше: множество не хранит элементы в том порядке, в котором вы их добавляли, и порядок вывода может не совпадать с порядком, в котором значения перечислялись при создании. Из-за этого у множества нет обращения по индексу — `fruits[0]` для множества не сработает:

```python
fruits = {"яблоко", "банан", "апельсин"}
print(fruits[0])
# TypeError: 'set' object is not subscriptable
```

Если порядок элементов важен для дальнейшей работы, множество для этой задачи не подходит — для избавления от дубликатов с сохранением порядка потребовался бы другой, более сложный приём, выходящий за рамки этого урока.

## Пустое множество: осторожно с {}

Здесь стоит предупредить об одной путанице в синтаксисе: `{}` создаёт не пустое множество, а пустой словарь — мы уже видели это в уроке 30. Чтобы создать действительно пустое множество, нужно явно использовать `set()`:

```python
empty_dict = {}
print(type(empty_dict))   # <class 'dict'>

empty_set = set()
print(type(empty_set))    # <class 'set'>
```

## in по-прежнему работает

Оператор `in`, уже знакомый по спискам, строкам и словарям, точно так же работает и с множествами — причём для множеств такая проверка выполняется особенно быстро, что становится заметно на больших объёмах данных:

```python
fruits = {"яблоко", "банан", "апельсин"}
print("банан" in fruits)   # True
```

## Добавление и удаление элементов

Для полноты картины — множество можно изменять после создания, добавляя элементы через `add()` и удаляя через `remove()`:

```python
fruits = {"яблоко", "банан"}
fruits.add("апельсин")
fruits.remove("яблоко")

print(fruits)   # {'банан', 'апельсин'}
```

Если добавить значение, которое уже есть в множестве, ничего не произойдёт — оно попросту останется в единственном экземпляре, без ошибки и без видимого эффекта.

## Кратко об операциях над множествами

У множеств есть операции, пришедшие из математики: пересечение (общие элементы двух множеств) и объединение (все элементы обоих множеств вместе). Здесь мы дадим лишь беглый обзор — это не тема для глубокого погружения в рамках базового курса, а скорее общий кругозор, чтобы вы узнавали эти операции, если встретите их в чужом коде.

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a & b)   # {3, 4} — пересечение: общие элементы
print(a | b)   # {1, 2, 3, 4, 5, 6} — объединение: все элементы вместе
print(a - b)   # {1, 2} — разность: элементы a, которых нет в b
```

Те же самые операции доступны и в виде методов — `a.intersection(b)`, `a.union(b)`, `a.difference(b)` — они делают ровно то же самое, что и знаки `&`, `|`, `-` выше, просто в виде явного вызова метода.

## Итоги урока

Множество — неупорядоченная коллекция уникальных значений; главное практическое применение — избавление от дубликатов в списке через `list(set(список))`. Обращение по индексу для множества недоступно, а порядок элементов не гарантирован. Пустое множество создаётся через `set()`, а не `{}` — последнее создаёт пустой словарь. Оператор `in` работает с множествами так же, как со списками и строками. Операции пересечения (`&`), объединения (`|`) и разности (`-`) существуют и доступны как через знаки, так и через методы, но в базовом курсе мы их только упоминаем, не углубляясь.

В следующем уроке мы коротко познакомимся с несколькими дополнительными типами данных, которые встречаются реже, а затем закрепим весь материал модуля большой практикой на циклы и словари.
