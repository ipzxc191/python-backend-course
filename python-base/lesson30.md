# Урок 30. Словари: создание, добавление и изменение значений

Начинается модуль про словари — и не случайно словарь стоит в его названии первым. Это, пожалуй, самый универсальный и часто используемый тип данных из всех, что мы будем разбирать: он повсеместно встречается в реальном коде, от простых скриптов до серьёзных приложений, там, где данные удобнее называть по смыслу, а не помнить по позиции.

## Проблема, которую решает словарь

Вспомним задачу из урока 23, где были два отдельных списка — имена и возрасты, — и приходилось обращаться к обоим по одному и тому же индексу, чтобы связать конкретное имя с конкретным возрастом:

```python
names = ["Егор", "Мария", "Дмитрий"]
ages = [25, 30, 22]

print(names[0], ages[0])   # Егор 25
```

Это работает, но неудобно и хрупко: связь между именем и возрастом существует только благодаря тому, что оба значения стоят на одинаковой позиции в двух разных списках — если случайно перепутать порядок при добавлении нового человека в один список и забыть про другой, данные разъедутся, и никакой ошибки Python при этом не покажет.

Словарь решает эту проблему напрямую: вместо того чтобы связывать значения через совпадающую позицию в двух списках, он хранит пары «ключ — значение», где ключ явно называет, что это за значение.

## Что такое словарь

Словарь (`dict`) — это набор пар «ключ: значение», где каждому ключу соответствует ровно одно значение. Создать словарь можно с помощью фигурных скобок:

```python
person = {"name": "Егор", "age": 25}
```

Здесь `"name"` и `"age"` — ключи, а `"Егор"` и `25` — соответствующие им значения. В отличие от списка, где к элементу обращаются по числовому индексу, к значению в словаре обращаются по ключу:

```python
person = {"name": "Егор", "age": 25}

print(person["name"])   # Егор
print(person["age"])    # 25
```

## Создание словаря: два способа

Кроме фигурных скобок с парами через двоеточие, словарь можно создать функцией `dict()`, передав пары как именованные аргументы:

```python
person = dict(name="Егор", age=25)
print(person)   # {'name': 'Егор', 'age': 25}
```

У этого способа есть ограничение: имена аргументов (будущие ключи) должны быть допустимыми именами переменных, поэтому такой способ не подходит, если ключ должен быть, например, числом или содержать пробел. Литеральная запись через `{}` работает всегда и без подобных ограничений, поэтому именно она используется чаще всего.

Создать пустой словарь, чтобы заполнить его позже, можно двумя равнозначными способами:

```python
empty_dict_1 = {}
empty_dict_2 = dict()
```

## Ключом может быть не только строка

Хотя в примерах выше ключами были строки, это не единственный вариант — ключом может быть, например, и число:

```python
scores = {1: "первое место", 2: "второе место", 3: "третье место"}
print(scores[1])   # первое место
```

Для базовых задач вы почти всегда будете использовать в качестве ключей строки или числа — этого более чем достаточно на первое время.

## Обращение к несуществующему ключу — ошибка

Если попытаться обратиться к ключу, которого в словаре нет, Python не вернёт `None` или пустое значение, а остановит программу с ошибкой:

```python
person = {"name": "Егор", "age": 25}
print(person["city"])
# KeyError: 'city'
```

Это стоит держать в голове с самого начала: обращение по несуществующему ключу — это не то же самое, что обращение к несуществующему индексу списка (`IndexError`), но по своей сути очень похоже — оба случая означают «то, что вы просите, здесь отсутствует», просто с разными названиями ошибки для разных типов данных.

## Добавление новой пары

Чтобы добавить в словарь новую пару «ключ: значение», не нужен отдельный метод — достаточно присвоить значение новому ключу через квадратные скобки, точно так же, как при обращении к уже существующему:

```python
person = {"name": "Егор", "age": 25}
person["city"] = "Москва"

print(person)   # {'name': 'Егор', 'age': 25, 'city': 'Москва'}
```

Если ключа `"city"` раньше в словаре не было, эта строка создаёт новую пару. Словари, как и списки, изменяемы — здесь не требуется переприсваивание переменной, чтобы изменения сохранились.

## Изменение существующего значения

Тот же самый синтаксис используется и для изменения значения по уже существующему ключу — разница лишь в том, существовал ли ключ раньше:

```python
person = {"name": "Егор", "age": 25}
person["age"] = 26

print(person)   # {'name': 'Егор', 'age': 26, ...}
```

Стоит явно проговорить общее правило: `словарь[ключ] = значение` **либо добавляет новую пару, либо обновляет существующую** — Python сам определяет, какой из двух случаев перед ним, по тому, существует ли уже такой ключ в словаре. Никакого отдельного синтаксиса для «только добавить» и «только изменить» не требуется.

## Ключи в словаре уникальны

У каждого ключа в словаре может быть только одно значение — если попытаться создать словарь с повторяющимся ключом прямо в литерале, второе значение просто перезапишет первое, без какой-либо ошибки:

```python
data = {"name": "Егор", "name": "Мария"}
print(data)   # {'name': 'Мария'}
```

Это редко делается специально, но полезно понимать: если код случайно присваивает значение одному и тому же ключу дважды, побеждает последнее присваивание, а не первое.

## Итоги урока

Словарь хранит данные в виде пар «ключ: значение» и обращается к значениям по ключу, а не по числовой позиции — это удобнее списков там, где значения естественно связаны друг с другом по смыслу, а не по совпадающему порядку в разных списках. Словарь создаётся через `{}` или `dict()`. Обращение по несуществующему ключу вызывает ошибку `KeyError`. Запись `словарь[ключ] = значение` одновременно служит и для добавления новой пары, и для изменения значения существующего ключа — Python сам определяет нужное поведение по тому, существует ли ключ.
