# Урок 41. Синтаксис функции: def, return (включая неявный return None)

В прошлом уроке мы разобрались, зачем функции вообще нужны. Теперь — синтаксис: как объявить свою собственную функцию и как заставить её отдавать результат, который можно использовать дальше в программе.

## Объявление функции: def

Функция объявляется ключевым словом `def` (сокращение от define — «определить»), за которым следует имя функции, круглые скобки и двоеточие. Код внутри функции, как и внутри `if` или `while`, пишется с отступом:

```python
def greet():
    print("Привет!")
```

Эта запись пока ничего не выводит на экран — она лишь **объявляет** функцию, то есть сообщает Python: «вот логика, которая называется `greet`, запомни её на будущее». Чтобы код внутри функции реально выполнился, функцию нужно **вызвать** — написать её имя с круглыми скобками:

```python
def greet():
    print("Привет!")

greet()
# Привет!
```

Обратите внимание на порядок: сначала функция объявляется (`def greet():` со всем её телом), и только после этого, уже отдельной строкой, происходит вызов `greet()`. Если попытаться вызвать функцию до того, как она была объявлена, Python не найдёт её и выдаст ошибку — определение функции должно находиться в коде раньше её использования.

Функцию можно вызывать сколько угодно раз — ровно то самое переиспользование, о котором шла речь в прошлом уроке:

```python
def greet():
    print("Привет!")

greet()
greet()
greet()
```

```
Привет!
Привет!
Привет!
```

## return: функция, которая отдаёт результат

Функция `greet()` из примеров выше выводит текст на экран, но не даёт коду ничего, что можно было бы использовать дальше, — она попросту показывает что-то пользователю и на этом её роль заканчивается. Чтобы функция могла передать результат своей работы обратно в код, который её вызвал, используется `return`:

```python
def get_greeting():
    return "Привет!"

message = get_greeting()
print(message)
# Привет!
```

Здесь принципиальная разница с предыдущим примером: `get_greeting()` ничего не выводит на экран сама — она возвращает строку `"Привет!"` тому месту в коде, откуда её вызвали, и именно вызывающий код (в данном случае строка `message = get_greeting()`) решает, что делать с этим результатом дальше — вывести его, сохранить, использовать в вычислениях.

## print() внутри функции — это не то же самое, что return

Вот ключевая путаница, которую стоит разобрать сразу и подробно, потому что она встречается у начинающих постоянно. Сравните две похожие на первый взгляд функции:

```python
def show_sum():
    print(5 + 3)

def get_sum():
    return 5 + 3
```

`show_sum()` выводит `8` на экран, но если попытаться использовать результат её вызова дальше — ничего не получится:

```python
result = show_sum()
# на экране выведется 8 (это побочный эффект print внутри функции)

print(result)
# None — потому что show_sum() ничего не вернула коду
```

А `get_sum()` действительно отдаёт число `8` наружу, и это число можно использовать как угодно дальше:

```python
result = get_sum()
print(result)        # 8
print(result * 2)    # 16
```

`print()` — это способ показать что-то человеку, глядящему на экран. `return` — это способ передать значение обратно в код, чтобы программа могла продолжить с ним работать. Это две разные задачи, и путать их — источник многих проблем на старте: если функция должна дать значение, которое дальше будет использоваться в вычислениях, сравнениях, сохранении в переменную, — этой функции нужен `return`, а не (или не только) `print()`.

## Если return не написан явно — функция всё равно что-то возвращает

Вот факт, который легко упустить: даже если в функции нет ни одного `return`, она всё равно, незаметно для вас, возвращает значение — специальное значение `None`, с которым мы уже сталкивались раньше (например, у методов списков вроде `append()` в уроке 16):

```python
def greet():
    print("Привет!")

result = greet()
print(result)
# Привет!
# None
```

Функция `greet()` не содержит `return`, но строка `result = greet()` всё равно должна была чему-то присвоить `result` — и этим «чем-то» стало `None`, которое Python подставляет автоматически, если функция завершилась, так и не встретив явный `return`.

## return завершает функцию немедленно

`return` не только передаёт значение — он ещё и **немедленно** завершает выполнение функции, точно так же, как `break` немедленно завершал цикл в модуле 3. Всё, что написано в функции после `return`, уже не выполнится:

```python
def check_number(number):
    if number < 0:
        return "Отрицательное"

    return "Неотрицательное"
```

Здесь, если число отрицательное, функция сразу возвращает `"Отрицательное"` и не доходит до второй строки с `return` вообще — совсем как `break`, обрывающий цикл раньше, чем он дойдёт до конца. С аргументами функций (вроде `number` в этом примере) мы подробно разберёмся уже в следующем уроке — здесь же важно уловить саму идею немедленного завершения через `return`.

## Итоги урока

Функция объявляется через `def имя():` с телом с отступом, а вызывается через `имя()`. Определение функции в коде должно находиться раньше её вызова. `return` передаёт значение из функции обратно в код, который её вызвал, — в отличие от `print()`, который лишь показывает что-то на экране, но не даёт коду значения для дальнейшего использования. Если функция не содержит явного `return`, она всё равно возвращает значение — `None` — автоматически, при достижении конца функции. `return`, как и `break` в цикле, немедленно завершает выполнение функции, не давая коду после себя выполниться.

В следующем уроке мы разберём параметры — то, как передавать функции данные снаружи, а не работать только с уже готовыми значениями внутри.
