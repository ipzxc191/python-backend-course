# Урок 8. Работа со шрифтами и единицами измерения (`px`, `em`, `rem`, `%`, `vh`/`vw`). Google Fonts

## Зачем нужны разные шрифты

Шрифт — не просто «красивая обложка» текста. От него зависит читабельность, впечатление о продукте и восприятие бренда. Хороший шрифт облегчает чтение длинного текста; неправильно подобранный — утомляет глаза и заставляет пользователя закрыть страницу раньше времени. Шрифт — часть визуальной идентичности сайта, помогает разделять заголовки и основной текст, задавать общий тон (строгий или дружелюбный), а разные типы шрифтов лучше подходят для разного контента: моноширинный — для кода, курсив — для цитат, шрифт с чёткими цифрами — для таблиц. Шрифт — это инструмент UX и дизайна, а не просто украшение.

### Системные шрифты и подключаемые (web) шрифты

**Системные шрифты** (`Arial`, `Times New Roman`, `Georgia`) хранятся на устройстве пользователя и не требуют загрузки — плюс в мгновенном рендере и отсутствии проблем с лицензиями, минус в ограниченном выборе и небольших различиях между операционными системами.

**Подключаемые (web) шрифты** (Google Fonts, Adobe Fonts, локально подключённые `.woff2`) загружаются браузером при открытии страницы — плюс в большом выборе и едином внешнем виде у всех пользователей, минус в дополнительных сетевых запросах и весе страницы.

Практический приём — стек шрифтов с запасными вариантами (fallback):

```css
font-family: "Inter", "Helvetica Neue", Arial, sans-serif;
```

Если основной шрифт не загрузится, браузер попробует следующий по списку, а в конце — обобщённое семейство (`sans-serif`), гарантирующее хоть какой-то разумный результат.

### Типы шрифтов и где их уместно применять

**Serif** (с засечками: Georgia, Merriweather) — печатные материалы, официальные сайты, крупные заголовки.

**Sans-serif** (без засечек: Arial, Roboto, Inter) — основной текст интерфейсов, самый частый выбор для веба. 

**Monospace** (все символы одинаковой ширины: Consolas, Menlo) — код, консольные логи, таблицы с выравниванием по символам. 

**Cursive/handwritten** — декоративно, в логотипах и акцентах, плохо читается в длинных текстах. 

**Fantasy/display** — декоративные заголовки-афиши, не для основного текста.

Практическое правило: для основного текста — sans-serif, для заголовков — serif или display для создания характера, для кода — monospace, для акцентов — cursive/fantasy, но экономно.

### Основные CSS-свойства управления шрифтом

**`font-family`** задаёт семейство шрифта или стек с запасными вариантами; имена с пробелами берутся в кавычки, последним элементом всегда должен идти обобщённый generic family (`serif`, `sans-serif`, `monospace`).

**`font-size`** — размер шрифта; про единицы измерения подробно поговорим в отдельном разделе ниже.

**`font-weight`** — «жирность» начертания: ключевые слова (`normal`/`bold`) или числа от `100` до `900` (`400` — обычный текст, `700` — жирный, наиболее распространённые значения). Важно: не все шрифты содержат все веса — если подключаете web-шрифт, выбирайте только реально нужные веса (обычно достаточно `400` и `700`), чтобы не грузить лишние файлы.

**`font-style`** — наклон начертания: `normal`, `italic` (специально подготовленное курсивное начертание, если оно есть у шрифта), `oblique` (браузер сам генерирует наклон обычного начертания, если курсивного файла нет).

```css
body {
  font-family: "Inter", Arial, sans-serif;
  font-size: 16px;
  color: #222;
}

h1 {
  font-family: "Merriweather", Georgia, serif;
  font-weight: 700;
}

p {
  font-weight: 400;
  line-height: 1.6;
}
```

## Google Fonts

Google Fonts — бесплатный каталог веб-шрифтов с готовыми фрагментами кода для подключения, возможностью загрузки архива для локального хостинга, и, как правило, открытой лицензией (чаще всего SIL Open Font License). При использовании другого источника шрифтов лицензию стоит проверять отдельно.

### Как подобрать шрифт

На `fonts.google.com` можно фильтровать шрифты по категории (`Serif`, `Sans-serif`, `Display`, `Handwriting`, `Monospace`), по доступным весам и по поддерживаемому языку (важно включить кириллицу, если сайт на русском). На странице конкретного семейства можно посмотреть доступные начертания (`Styles`), подставить собственный текст в превью, и получить готовый код для подключения (`Embed`). Практический совет: не выбирайте «на пробу» десяток весов — каждый добавленный вес увеличивает сетевой трафик; для большинства проектов хватает `400` (обычный) и `700` (жирный).

### Подключение через `<link>` — рекомендуемый способ

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />

<link
  href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap"
  rel="stylesheet"
/>
```

Разбор адреса: `family=Roboto` — имя семейства (пробелы в имени заменяются на `+`); `:wght@400;700` — запрошенные веса; `&display=swap` — управляет поведением до полной загрузки шрифта. `rel="preconnect"` заранее устанавливает соединение с серверами Google, что немного ускоряет последующую загрузку самого шрифта.

`display=swap` — рекомендуемое значение: браузер сразу показывает текст запасным (системным) шрифтом, а когда webfont загрузится — плавно «переключает» на него. Без этого параметра (или со значением `block`) браузер может ненадолго оставить текст полностью невидимым, ожидая загрузки шрифта — это ухудшает восприятие страницы.

Несколько семейств или начертание italic запрашиваются через запятую и параметр `ital`:

```
family=Roboto:wght@400;700&family=Montserrat:ital,wght@0,400;1,400
```

`ital,wght@0,400;1,400` означает: обычное начертание веса 400 (`0,400`) и курсивное того же веса (`1,400`).

### Почему `<link>` предпочтительнее `@import`

`@import` внутри CSS-файла добавляет лишний шаг: браузер должен сначала загрузить основной CSS-файл, обнаружить в нём `@import`, и только потом начать загрузку шрифта — это делает загрузку заметно медленнее по сравнению с `<link>` в `<head>`, который браузер может начать загружать сразу, параллельно с остальными ресурсами страницы.

## Локальные шрифты и `@font-face`

Когда нужен полный контроль над файлами шрифта (например, для полной автономности от внешних сервисов, приватности или строгих корпоративных политик), шрифт скачивают и подключают локально.

### Форматы файлов

`.woff2` — современный формат с лучшим сжатием, используется как основной. `.woff` — более старый формат, используется как запасной вариант (fallback) для редких старых браузеров. `.ttf` — формат, который часто идёт в архиве при скачивании, но весит больше и для веба не оптимален — обычно не нужен, если есть `.woff2`/`.woff`.

### Структура папок

```
/project-root
  /index.html
  /css/styles.css
  /fonts
    /Inter
      Inter-Regular.woff2
      Inter-Bold.woff2
```

### Синтаксис `@font-face`

```css
@font-face {
  font-family: "InterLocal";
  src: url("../fonts/Inter/Inter-Regular.woff2") format("woff2"),
       url("../fonts/Inter/Inter-Regular.woff") format("woff");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "InterLocal";
  src: url("../fonts/Inter/Inter-Bold.woff2") format("woff2"),
       url("../fonts/Inter/Inter-Bold.woff") format("woff");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
```

Для каждой комбинации веса и стиля нужна отдельная декларация `@font-face` — браузер сам подберёт нужный файл, когда в обычном CSS встретит соответствующий `font-weight`/`font-style` у элемента, использующего `font-family: "InterLocal"`.

```css
body {
  font-family: "InterLocal", Arial, sans-serif;
}

h1 {
  font-weight: 700; /* браузер возьмёт файл Inter-Bold.woff2 */
}
```

`font-display: swap` в `@font-face` работает так же, как одноимённый параметр в URL Google Fonts — рекомендуемое значение для большинства случаев.

### Когда CDN, а когда локальный хостинг

Google Fonts CDN — быстрый и удобный вариант для учебных и небольших проектов: скопировали `<link>`, всё работает. Локальный хостинг стоит выбрать, если важна полная автономность от внешних сервисов, есть строгие требования к приватности/безопасности, или нужен точный контроль над версией и набором символов шрифта.

## Единицы измерения: `px`, `em`, `rem`, `%`, `vw`/`vh`

Разные единицы измерения — это про масштабируемость, наследование и контроль. Некоторые единицы фиксируют размер жёстко (`px`), другие вычисляются от родителя (`em`, `%`), третьи — от корня документа (`rem`), четвёртые — от размеров окна браузера (`vw`/`vh`). Эти единицы применяются не только к `font-size` — они работают практически в любом CSS-свойстве, где нужен размер: `width`, `padding`, `margin`, `border-radius` и многих других.

### `px` — абсолютные пиксели

Точная, неизменная единица: `16px` — это всегда ровно 16 пикселей, независимо от контекста. Хорошо подходит для мелких деталей, где важен жёсткий контроль: толщина рамок (`border: 1px solid`), иконки, тени.

```css
.icon {
  width: 24px;
  height: 24px;
}
```

### `rem` — от корневого элемента (`<html>`)

`1rem` равен `font-size` корневого элемента `<html>` — обычно одному и тому же значению для всей страницы. Если задать `html { font-size: 16px; }`, то `2rem` всегда будет равен 32px, независимо от того, в каком по глубине вложенности элементе это используется — в отличие от `em`, здесь нет эффекта накопления при вложенности.

```css
html {
  font-size: 16px;
}

h1 {
  font-size: 2rem; /* 32px, всегда, вне зависимости от вложенности */
}
```

`rem` — лучший выбор для глобальных, «системных» размеров: базовый размер текста, заголовки, отступы в общей раскладке страницы. Изменив всего одно значение (`font-size` у `html`), можно пропорционально масштабировать весь сайт разом.

### `em` — от размера шрифта родителя

`1em` равен вычисленному `font-size` родительского элемента. Полезно для **локального** масштабирования внутри одного компонента — например, чтобы внутренние отступы кнопки автоматически увеличивались вместе с размером её текста.

```css
.button {
  font-size: 1rem; /* 16px, от корня */
  padding: 0.75em 1.2em; /* отступы масштабируются от размера ШРИФТА КНОПКИ */
}
```

**Важная особенность — эффект накопления при вложенности:** если внутри элемента с `font-size: 1.2em` находится ещё один элемент с собственным `font-size: 1.2em`, второе значение вычисляется не от корня, а от уже увеличенного размера родителя — размеры «накапливаются» на каждом уровне вложенности:

```css
.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em; /* 1.5 × 20px = 30px */
}

.grandchild {
  font-size: 1.2em; /* если grandchild вложен в child: 1.2 × 30px = 36px, а не от 20px! */
}
```

Именно поэтому `em` удобен для локального масштабирования одного изолированного компонента (кнопка, бейдж), но требует внимательности при глубокой вложенности — легко получить неожиданно большой или маленький размер, потеряв счёт уровням.

### `%` — проценты от родителя

Для `width`/`height` процент берётся явно от размера родителя — классика для «резиновых» сеток:

```css
.column {
  width: 33.333%; /* три колонки в ряд */
}
```

Не самый очевидный, но полезный приём: `padding-top` в процентах считается от **ширины** родителя (а не высоты) — это позволяет создавать блоки с фиксированным соотношением сторон:

```css
.ratio-box {
  padding-top: 56.25%; /* соотношение сторон 16:9 */
}
```

### `vw`/`vh` — от размеров окна браузера

`1vw` равен 1% ширины окна просмотра (viewport), `1vh` — 1% его высоты. Удобны для полноэкранных секций и выразительных, масштабируемых заголовков:

```css
.hero {
  min-height: 100vh; /* блок высотой ровно в весь экран */
}

.hero-title {
  font-size: 8vw; /* заголовок растёт и уменьшается вместе с шириной окна */
}
```

Осторожно: `vw` не стоит применять к основному тексту статьи — при очень узком или очень широком экране размер шрифта может стать нечитаемым. Также на мобильных браузерах `vh` иногда ведёт себя не совсем предсказуемо, так как адресная строка браузера может динамически скрываться и показываться, меняя фактическую высоту окна.

### `line-height` — отдельный случай: безразмерное число

Для `line-height` лучшая практика — задавать безразмерное число, а не проценты или пиксели:

```css
p {
  line-height: 1.6;
}
```

Безразмерное значение умножается на `font-size` именно того элемента, где применяется, и корректно ведёт себя при наследовании дочерними элементами с другим размером шрифта — в отличие от фиксированного значения в `px`, которое при наследовании осталось бы неизменным независимо от размера шрифта потомка, что обычно не то, что нужно.

### Итоговые рекомендации по выбору единицы

| Единица | Когда использовать |
|---|---|
| `px` | Мелкие, некритичные детали: рамки, иконки, тени |
| `rem` | Глобальные размеры: базовый текст, заголовки, отступы в общей раскладке страницы |
| `em` | Локальное масштабирование внутри одного компонента (кнопка, бейдж) |
| `%` | Резиновая ширина колонок, блоки с фиксированным соотношением сторон (`padding-top`) |
| `vw`/`vh` | Полноэкранные секции, выразительные декоративные заголовки — не для основного текста |
| безразмерное число | `line-height` — всегда, вместо `px`/`%` |

Практическая база для старта проекта:

```css
html {
  font-size: 100%; /* обычно соответствует 16px, но уважает пользовательские настройки браузера */
}

body {
  font-family: "Inter", Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
}

.button {
  font-size: 1rem;
  padding: 0.75em 1.2em;
}
```

## Практические задания

### Задание 1. Подключение Google Fonts

1. Выбери на `fonts.google.com` два шрифта: один для заголовков, другой для основного текста (например, `Merriweather` и `Roboto`), включи в подбор веса `400` и `700`, а для одного из шрифтов — ещё и курсив (`italic`).
2. Подключи оба шрифта через `<link>` в `<head>`, с `preconnect` и `display=swap`.
3. Примени шрифты в CSS: заголовкам — декоративный, телу страницы — читаемый; используй `font-weight: 700` для заголовков и `<em>` где-нибудь в тексте, чтобы проверить курсив.

---

### Задание 2. Локальный шрифт через `@font-face`

1. Скачай архив со шрифтом с Google Fonts (например, `Inter`), выбрав веса `400` и `700`.
2. Помести файлы в папку `fonts/Inter/` своего проекта.
3. Подключи оба веса через две декларации `@font-face` и примени шрифт к странице так, чтобы заголовки автоматически брали жирное начертание.

---

### Задание 3. Единицы измерения на практике

1. Задай `html { font-size: 100%; }` и все базовые размеры текста (`body`, `h1`, `h2`) — в `rem`.
2. Создай компонент `.button` с `font-size` в `rem`, а `padding` — в `em`, чтобы внутренние отступы масштабировались вместе с размером текста кнопки.
3. Создай блок `.ratio-box` с фиксированным соотношением сторон 16:9, используя `padding-top` в процентах.
4. Создай `.hero` высотой `100vh` с заголовком, размер которого задан в `vw`.
