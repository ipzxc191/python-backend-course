# Урок 3. Свойства блочных элементов. Box-model

## HTML-страница как набор коробок

Мы уже знаем, что в HTML есть блочные и строчные элементы. Сегодня посмотрим на страницу под другим углом: каждый элемент — заголовок, абзац, картинка, `div` — можно представить как **коробку**. Эти коробки можно расширять или сужать, отодвигать друг от друга, добавлять им внутренние отступы (чтобы содержимое не прилипало к краям), и украшать рамкой.

> Даже строчные элементы (ссылка, картинка) — тоже мини-коробки, просто по умолчанию они «тонкие» и стоят рядом друг с другом в строке.

Чтобы управлять этими коробками, в CSS есть три ключевых свойства — **`padding`**, **`margin`** и **`border`**. Вместе они образуют **box-model** — модель коробки, на которой держится вся вёрстка.

---

## `padding` — внутренний отступ

`padding` задаёт расстояние **внутри** элемента — между его границей и содержимым. Представь коробку, в которую положили книгу: `padding` — это пузырчатая плёнка внутри коробки, которая не даёт книге касаться стенок.

```html
<div style="background-color: lightblue; padding: 20px;">
  <p>Это текст с отступом внутри блока.</p>
</div>
```

`padding: 20px` создаёт пространство между текстом и краем голубого блока — без него текст прилегал бы вплотную к границе.

---

## `margin` — внешний отступ

`margin` задаёт расстояние **снаружи** элемента — то, что отделяет одну коробку от другой. Если `padding` — это плёнка внутри коробки, то `margin` — пространство между самими коробками на полке, чтобы они не стояли вплотную друг к другу.

```html
<div style="background-color: lightgreen; margin: 20px;">
  <p>Блок с внешним отступом</p>
</div>
```

---

## `border` — рамка

`border` — граница вокруг элемента, у которой можно задать толщину, стиль линии и цвет. Без `border` коробка выглядит так, будто сделана из прозрачного пластика; с `border` — у неё появляются видимые стенки.

```html
<div style="background-color: lightyellow; border: 2px solid black;">
  <p>Блок с рамкой</p>
</div>
```

Здесь рамка толщиной `2px`, сплошная (`solid`) и чёрного цвета. Другие частые значения стиля линии — `dashed` (пунктир) и `dotted` (точки).

---

## Из чего состоит box-model целиком

`content` (содержимое), `padding` (внутренний отступ), `border` (рамка) и `margin` (внешний отступ) — четыре слоя, из которых состоит любой элемент на странице. Их удобно рассматривать как вложенные друг в друга уровни: контент внутри, вокруг него — padding, вокруг padding — граница, а снаружи всей коробки — margin, отделяющий её от соседей.

Чтобы увидеть box-model конкретного элемента наглядно, откройте страницу в браузере, нажмите `F12` (инструменты разработчика) и выберите любой элемент — во вкладке стилей сразу будет показана схема всех четырёх слоёв с их текущими значениями.

---

## Отдельные стороны и сокращённая запись

У каждой из трёх основных box-model-характеристик есть отдельные свойства для каждой стороны:

- `padding-top`, `padding-right`, `padding-bottom`, `padding-left`
- `border-top`, `border-right`, `border-bottom`, `border-left`
- `margin-top`, `margin-right`, `margin-bottom`, `margin-left`

```html
<div style="margin-bottom: 100px; width: 300px; height: 300px; background-color: aqua;">
  Это первый элемент
</div>
<div style="padding-top: 50px; width: 300px; height: 300px; background-color: aqua;">
  Это второй элемент
</div>
```

Для `margin` и `padding` также существует сокращённая запись (shorthand), которая позволяет задать все четыре стороны одной строкой:

| Запись | Что означает |
|---|---|
| `margin: 10px;` | Все четыре стороны — 10px |
| `margin: 5px 10px;` | Верх/низ — 5px, лево/право — 10px |
| `margin: 10px 20px 30px 40px;` | По часовой стрелке: верх, право, низ, лево |

## Свойство `display`

У каждого элемента есть поведение «по умолчанию», которое определяется свойством `display`: блочные элементы (`div`, `h1`, `p`) по умолчанию имеют `display: block`, строчные (`a`, `img`, `span`) — `display: inline`. Это поведение можно изменить.

### `display: inline` — превращаем блочный элемент в строчный

По умолчанию параграфы блочные и идут друг под другом:

```html
<p style="background-color: lightcoral;">Абзац 1</p>
<p style="background-color: lightblue;">Абзац 2</p>
```

Если добавить `display: inline`, оба абзаца встанут в одну строку, как строчные элементы:

```html
<p style="display: inline; background-color: lightcoral;">Абзац 1</p>
<p style="display: inline; background-color: lightblue;">Абзац 2</p>
```

### `display: block` — превращаем строчный элемент в блочный

Обратная ситуация: картинка и ссылка по умолчанию строчные и стоят в одной строке. Если задать им `display: block`, они встанут друг под другом, как обычные блочные элементы:

```html
<img src="https://picsum.photos/100" alt="Пример" style="display: block; background-color: lightgray;" />
<a href="#" style="display: block; background-color: yellow;">Ссылка</a>
```

### `display: inline-block` — лучшее из обоих миров

`inline-block` — промежуточное значение: элемент ведёт себя как строчный (может стоять в одной строке с другими), но при этом, как блочный, у него работают `width`, `height`, `padding`, `margin`, `border`.

Почему не подходит обычный `inline`? Если задать `display: inline` какому-нибудь `div`, он действительно встанет в строку — но у него нельзя будет задать ширину и высоту, то есть превратить его в полноценную «коробку» с нужными размерами. Именно поэтому для расположения блоков в строку обычно используют именно `inline-block`, а не `inline`.

```html
<div style="display: inline-block; width: 200px; height: 100px; background-color: lightblue; margin: 5px;"></div>
<div style="display: inline-block; width: 200px; height: 100px; background-color: lightgreen; margin: 5px;"></div>
```

Оба блока стоят в одной строке, и при этом каждый сохраняет собственную ширину, высоту и отступы.

### Свойство `float` — устаревший, но всё ещё встречающийся способ

До появления Flexbox и Grid (мы разберём их в следующих модулях) блоки часто выстраивали в строку с помощью `float`: `float: left` прижимает элемент к левому краю, `float: right` — к правому, а остальное содержимое «обтекает» этот блок.

```html
<div style="float: left; width: 200px; height: 100px; background-color: lightblue; margin: 10px;"></div>
<div style="float: left; width: 200px; height: 100px; background-color: lightgreen; margin: 10px;"></div>
```

Сегодня `float` для построения макетов используют редко — Flexbox и Grid решают эту задачу удобнее и предсказуемее. Тем не менее знать `float` полезно: он всё ещё встречается в старом коде, который вам предстоит читать и поддерживать.

## Практические задания

### Задание 1. Простая коробка

Создай `div` с текстом «Это моя коробка»:

1. Задай ширину `200px`, высоту `100px` и любой цвет фона.
2. Добавь внутренний отступ `padding: 20px` — убедись, что текст отодвинулся от краёв.
3. Добавь рамку — толщиной `5px`, сплошную, синего цвета.
4. Создай под ним второй `div` и задай между ними `margin: 30px` — убедись, что они отделены друг от друга.

---

### Задание 2. Индивидуальные отступы и сокращённая запись

Создай `div` и задай ему отступы по отдельности для каждой стороны: сверху — `10px`, справа — `40px`, снизу — `20px`, слева — `60px`. Затем создай рядом второй `div` с теми же отступами, но запиши их одной строкой через сокращённую запись `padding: 10px 40px 20px 60px;`. Сравни результат — оба блока должны выглядеть одинаково.

---

### Задание 3. Карточки фильмов — box-model в деле

Создай три блока `<div>` — карточки любимых фильмов:

1. В каждом — заголовок `<h2>` с названием фильма и абзац `<p>` с коротким описанием (1–2 предложения).
2. Каждому блоку задай: свой цвет фона, ширину `300px`, внутренний отступ `20px`, внешний отступ `15px`, рамку `2px solid black`.
3. Заголовкам — красный цвет текста, выравнивание по центру.
4. Абзацам — чёрный цвет текста, размер шрифта `14px`.

---

### Задание 4. Три карточки в ряд — сравниваем `inline-block` и `float`

Создай три блока `<div>` шириной `220px` — карточки товаров: заголовок `<h2>` с названием товара, картинка `<img>` (`200px` × `150px`), абзац `<p>` с коротким описанием. Каждому блоку — свой цвет фона, `padding: 15px`, `margin: 10px`, рамку `2px solid black`.

Сначала выстрой карточки в одну строку через `display: inline-block`. Затем сделай копию страницы и добавь то же самое через `float: left` вместо `inline-block`. Сравни результат в браузере — расположение должно быть похожим, но обрати внимание, какой из способов ведёт себя предсказуемее при разной высоте содержимого карточек.
