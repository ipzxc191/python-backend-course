# Урок 4. Вложенность. Атрибуты тегов (`src`, `alt`, `href`, `id`, `class`). Базовые селекторы в CSS

## Вложенность как дерево элементов

Когда мы пишем HTML-код, мы создаём структуру страницы, и эта структура работает как **дерево**: есть корневые элементы (`<html>`, `<body>`), внутри них — другие элементы (`<div>`, `<h1>`, `<p>`), а внутри этих элементов могут быть ещё теги. Такое расположение называется **вложенностью** — мы уже сталкивались с ней в самых первых примерах:

```html
<body>
  <h1>Заголовок страницы</h1>
  <p>Текст абзаца</p>
</body>
```

`<h1>` и `<p>` находятся внутри `<body>` — значит, они **дочерние элементы** (children), а `<body>` — их **родительский элемент** (parent).

### Первый и второй уровень вложенности

Создадим два блока с заголовком, абзацем и картинкой внутри каждого:

```html
<div>
  <h2>Заголовок первого блока</h2>
  <p>Описание первого блока</p>
  <img src="cat.jpg" alt="Котик" />
</div>

<div>
  <h2>Заголовок второго блока</h2>
  <p>Описание второго блока</p>
  <img src="dog.jpg" alt="Собака" />
</div>
```

Заголовок, абзац и картинка внутри каждого `div` — это первый уровень вложенности относительно него. Теперь обернём оба блока в общий контейнер:

```html
<div>
  <div>
    <h2>Заголовок первого блока</h2>
    <p>Описание первого блока</p>
    <img src="cat.jpg" alt="Котик" />
  </div>

  <div>
    <h2>Заголовок второго блока</h2>
    <p>Описание второго блока</p>
    <img src="dog.jpg" alt="Собака" />
  </div>
</div>
```

Теперь у структуры два уровня вложенности: внешний `div` — общий контейнер, внутренние `div` — блоки внутри него, а заголовки/абзацы/картинки — ещё уровень внутри каждого блока. Чтобы увидеть эту структуру наглядно, добавим временную рамку каждому `div`:

```css
div {
  border: 1px solid black;
  margin: 10px;
  padding: 10px;
}
```

Теоретически вложенность можно делать сколь угодно глубокой — но на практике так почти никогда не поступают. Вложенность используют только там, где она логически оправдана: отдельные секции страницы, карточки товаров, блоки меню, формы. Слишком глубокая вложенность без реальной необходимости делает код сложным для чтения и поддержки.

## Атрибуты тегов

**Атрибут** — дополнительная информация, которую мы указываем прямо внутри открывающего тега. Атрибуты задают поведение элемента, добавляют характеристики, связывают элемент с CSS или JavaScript.

```html
<a href="https://example.com">Перейти</a>
```

Тег `<a>` создаёт ссылку, атрибут `href` задаёт адрес, а текст внутри тега («Перейти») отображается на странице.

Мы уже работали с несколькими атрибутами: `href` — адрес ссылки для `<a>`, `src` — путь к файлу картинки для `<img>`, `alt` — альтернативный текст картинки, который показывается, если изображение не загрузилось, а также используется вспомогательными технологиями для незрячих пользователей.

### `class` и `id` — основа стилизации в CSS

**`class`** задаёт «класс» элемента. Один и тот же класс можно назначать сразу нескольким элементам — это основной инструмент для группировки и общей стилизации:

```html
<p class="red-text">Этот текст будет красным</p>
```

**`id`** задаёт уникальный идентификатор. Каждому элементу можно присвоить только один `id`, и он должен быть уникален на всей странице — этот атрибут используется для выделения одного конкретного элемента:

```html
<h1 id="main-title">Главный заголовок</h1>
```

Главное отличие: `class` — для группировки и общей стилизации множества элементов, `id` — для уникального выделения одного конкретного элемента.

## Базовые селекторы в CSS

Селектор в CSS указывает, к какому элементу применять стили. Мы уже сталкивались с простейшим видом — селектором тега:

```css
h1 {
  color: blue;
}
```

Есть три основных вида базовых селекторов.

### Селектор тега

Применяет стили сразу ко всем тегам одного типа:

```css
p {
  color: green;
}
```

Все параграфы `<p>` станут зелёными.

### Селектор класса

Записывается с точкой перед названием класса:

```css
.red-text {
  color: red;
}
```

```html
<p class="red-text">Этот текст красный</p>
<p>А этот — обычный</p>
```

Стиль применится только к элементам с этим классом — «обычный» абзац без класса останется без изменений.

### Селектор `id`

Записывается с символом `#` перед названием:

```css
#main-title {
  color: purple;
}
```

```html
<h1 id="main-title">Заголовок</h1>
```

### Все три селектора вместе

```html
<h1 id="main-title">Добро пожаловать!</h1>
<p class="red-text">Этот текст стилизован с помощью класса</p>
<a href="#">Это ссылка</a>
```

```css
/* Селектор тега */
a {
  color: green;
}

/* Селектор класса */
.red-text {
  color: red;
}

/* Селектор id */
#main-title {
  color: blue;
}
```

Заголовок станет синим, абзац — красным, ссылка — зелёной: каждый вид селектора нашёл «свой» элемент по разным признакам — по типу тега, по классу и по уникальному идентификатору.

## Собираем структуру страницы: header → main → footer

Любая современная страница обычно делится на несколько крупных частей: **шапка** (название сайта, логотип), **основной блок** (статьи, контент), **подвал** (контакты, копирайт). Семантические теги для этого (`header`, `main`, `footer`) мы разберём в следующем модуле — а пока построим ту же структуру через `div` с классами, используя всё, что уже знаем.

```html
<div class="header">
  <h1>My First Website</h1>
</div>

<div class="main">
  <div class="article">
    <h2>Первая статья</h2>
    <img src="https://picsum.photos/200/150" alt="Картинка статьи 1" />
    <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Integer nec odio.</p>
  </div>

  <div class="article">
    <h2>Вторая статья</h2>
    <img src="https://picsum.photos/200/150" alt="Картинка статьи 2" />
    <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Integer nec odio.</p>
  </div>
</div>

<div class="footer">
  <p>Email: example@mail.com</p>
  <p>Телефон: +1 234 567 890</p>
</div>
```

Структура получилась с двумя уровнями вложенности: `.header`, `.main` и `.footer` — первый уровень внутри `<body>`, а внутри `.main` — ещё два вложенных `.article`, каждый со своим заголовком, картинкой и текстом.

```css
body {
  font-family: Arial, sans-serif;
  margin: 0;
  padding: 0;
}

.header {
  background-color: lightblue;
  text-align: center;
  padding: 20px;
}

.main {
  background-color: #f9f9f9;
  padding: 20px;
}

.article {
  width: 45%;
  background-color: white;
  border: 1px solid #ccc;
  padding: 10px;
  margin: 10px;
  float: left; /* чтобы статьи встали в одну строку, как мы разбирали в Уроке 3 */
}

.article img {
  display: block;
  margin-bottom: 10px;
}

.footer {
  clear: both; /* чтобы подвал не «наезжал» на статьи, обтекающие float */
  background-color: lightgray;
  text-align: center;
  padding: 15px;
}
```

`clear: both` у `.footer` — важная деталь, о которой легко забыть: раз `.article` выстроены через `float`, следующий за ними блочный элемент по умолчанию попытается встать рядом с ними (обтекая их), а не строго под ними. `clear: both` явно говорит браузеру: «остановись, не обтекай элементы, использующие float ни с одной стороны, встань строго ниже них». Результат — привычная структура: шапка сверху, две статьи рядом, подвал строго снизу.

1. Создай блок `<div class="profile">`.
2. Внутри него добавь заголовок `<h2>` с текстом «Обо мне», картинку `<img>` (например, с `https://picsum.photos/200`) и абзац `<p>` с любым текстом о себе.

### Задание 2. Стилизация через `class` и `id`

1. Создай два блока `<div class="card">`, внутри каждого — заголовок `<h3>` и абзац текста.
2. Первому блоку дополнительно задай `id="first-card"`.
3. В CSS: для всех `.card` задай ширину `200px`, высоту `150px`, рамку `2px solid black`, `padding: 10px`, `margin: 15px`. Для `#first-card` дополнительно задай фон `lightblue` и цвет текста `darkblue`.
4. Убедись, что второй блок выглядит как обычная карточка, а первый — как обычная карточка, но с дополнительным оформлением поверх.

### Задание 3. Полная структура header → main → footer — объединяющая практика

Собери законченную страницу из трёх частей:

1. `.header` с названием сайта «Мой первый сайт».
2. `.main`, внутри которого — две статьи (`div.article`), в каждой: заголовок `<h2>`, картинка (`https://picsum.photos/300/150`), абзац текста из 3–4 предложений (можно использовать любой генератор lorem-текста).
3. `.footer` с контактами: телефон и email.
4. Стилизуй: `.header` — тёмный фон, белый текст, выравнивание по центру; `.main` — ширина `80%`, центрирование через `margin: 0 auto`; `.article` — ширина `45%`, `float: left`, рамка, внутренние и внешние отступы; `.footer` — светло-серый фон, выравнивание по центру, не забудь про `clear: both`, чтобы подвал не наезжал на статьи.
